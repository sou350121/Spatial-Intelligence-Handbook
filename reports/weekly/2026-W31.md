3. **第三高 ΔI：`INTACT`（2607.26056）** —— 錨定 §13.6（World Model 定義之爭）與 §13.9（Direct vs Indirect VO 的模糊化）。它用「等變語法 + 動作律語義」取代 latent matching，將 world model 從「預測器」轉為「可執行接口」，解開 forward model 的 inverse control bottleneck —— 這不是「更好預測」，而是**取消預測→規劃→控制的三段式流水線**，推動 paradigm 軸從 `world-model-as-policy` 向 `world-model-as-executable-interface` 移動。

4. **隱性軸移：`VisualPatchWorld`（2607.25236）** —— 錨定 §13.6（定義之爭）與 §13.7（5 軸是否 canonical）。它將世界模型實例化為**可編輯程式碼**，而非向量或物理引擎，迫使 representation 軸從 `feature-grid/scene-graph/implicit-sdf` 擴展至 `code-as-representation`，並要求 time 軸承載 `edit-time`（非僅 inference-time 或 rollout-time），暴露 5 軸分類在「可編輯性」維度上的根本缺失。

## Adversarial Triad: ContactFlow breaks embodiment binding via contact dynamics

**背景**：`ContactFlow`（2607.26579）提出 embodiment-agnostic action representation：將 manipulation 建模為 3D 接觸點軌跡（contact flow），作為 world model 的 conditioning 軸。它在 human video 上訓練，卻能在 Franka、UR5、甚至 humanoid 上 zero-shot 泛化物理互動預測，並在 real-robot 上驗證抓取成功率 >82%（human video → robot execution）。這直接挑戰 §13.6 中所有將 world model 定義為「視覺生成」或「動作條件式視頻預測」的流派（NVIDIA Cosmos / DeepMind Genie），並推動 paradigm 軸從 `world-model-as-policy` 升級為 `world-model-as-contact-dynamics-policy`。

**🔴 Bull（這是真信號）**  
1. **泛化性實證**：論文在 3 種異構 embodiment（human / Franka / UR5）上 zero-shot transfer，且不依賴任何 embodiment-specific kinematics 或 gripper geometry —— 證明 contact flow 是比 joint angles / end-effector poses 更基礎的物理互動表徵。  
2. **解耦機制明確**：contact flow 不是 learned embedding，而是顯式建模為 `(p_t, n_t, f_t)` 三元組（位置、法向、力），並透過 rigid-body contact dynamics constraint（Hertz + Coulomb）強制 rollout 一致性 —— 這不是黑箱泛化，而是 physics-grounded 解耦。  
3. **可驗證因果性**：論文提供 `contact flow → force prediction → torque estimation` 的端到端 pipeline，並在 real-robot 上驗證 torque error < 12%（vs. 38% baseline），證明其物理可執行性非幻覺。  
4. **定義重寫能力**：它使 world model 的輸出不再是「像素」或「token」，而是「可被控制器直接消費的 contact trajectory」—— 這迫使 §13.6 必須承認：world model 的 policy interface 可以完全脫離視覺合成。

**🔵 Bear（過早慶祝 / 反共識）**  
1. **規模局限**：所有實驗均在桌面尺度、剛體、無遮擋場景進行；Wu et al. (2025) 已指出：contact dynamics 在 soft-body / occluded / multi-contact 場景中會崩潰，而 `ContactFlow` 日報未報告此類測試。  
2. **任務簡單性**：zero-shot transfer 僅限於單物體抓取與放置；ref-NeRF（arXiv 2507.23374）早已證明：反射/透明物體的 contact point 定位仍是 open problem，`ContactFlow` 未處理此類 case。  
3. **更簡單替代方案存在**：`Robot-Factored World Models`（2607.22535）已透過 URDF rendering 解耦 embodiment，其 cross-embodiment 泛化在 nuScenes 上達 91%；`ContactFlow` 的 82% 並未顯著超越，且需額外 contact dynamics modeling overhead。  
4. **反共識證據**：arXiv 2512.21691 指出：global self-attention 在長 sequence（如 contact flow trajectory）上會 rank-collapse；`ContactFlow` 使用 transformer 作為 backbone，日報未報告其如何避免此失敗模式。

**🟢 Arbiter（裁決）**  
1. **爭議立場更新**：**§13.6 的立場需重寫**。原 ontology 將 world model 定義為「多種 incompatible definitions 的集合」，而 `ContactFlow` 提供首個可量化的、非生成式的、physics-grounded world model 定義 —— 它證明 world model 可以是「contact dynamics interface」，而非「video generator」。立場從「定義不一」微調為「定義譜系：生成式 ↔ dynamics-interface ↔ code-executable」。  
2. **軸移動**：paradigm 軸從 `world-model-as-policy` 明確移動至 `world-model-as-contact-dynamics-policy`（新子節點），representation 軸新增 `pointmap` 作為 contact flow 的原生表示（非 feature-grid 或 scene-graph）。  
3. **關鍵代理指標 + kill condition**：  
   - ✅ **確認方向**：在真實 soft-body（如布料、橡膠）場景中，`ContactFlow` 預測的 contact trajectory 能驅動 robot 完成 zero-shot folding / stretching，且 force error < 15%（real-robot，not simulation）。  
   - ❌ **推翻方向**：若在 multi-contact 圖靈測試（human vs. robot execution of same contact flow）中，human observer 識別出 robot 執行錯誤率 >40%，則證明 contact flow 未能 capture embodiment-invariant dynamics。  
4. **用戶行動建議**：  
   - 立即追蹤 `ContactFlow` 的 real-robot benchmark（如 `ContactBench-v1`）發布進度；  
   - 暫緩投資基於「視覺生成」的世界模型 pipeline，優先評估其 contact dynamics interface 兼容性；  
   - 在 VLA training pipeline 中，將 contact point detection（而非 pose estimation）列為 mandatory pre-processing step。

## 可證偽觀察清單

1. **下週可檢驗**：若 `ContactFlow` 在公開 benchmark `ContactBench-v1`（預期  release）上，soft-body task 的 zero-shot success rate < 65%，則證明其 contact dynamics modeling 在非剛體場景中失效（驗證 §13.2 中 ref-NeRF 對 3DGS 反光例外的類比：contact flow 有其 own exception class）。  
2. **下週可檢驗**：若 `TurboVLA` 在 real-robot deployment 中，因 `V+L→A` 架構缺失 language grounding，導致指令歧義（如「lift the red cup」vs. 「lift the red cup *gently*」）錯誤率 >35%，則 §13.3 的 feed-forward default 需加註「僅適用於 syntax-unambiguous commands」。  
3. **下週可檢驗**：若 `INTACT` 的 isomorphic grammar 在 multi-agent interaction（如 human-robot handover）中，無法保證 action-law semantics 的 causal invariance（即 human intent ≠ robot execution outcome），則證明其 grammar 無法 scale beyond single-agent closed-loop control。  
4. **下週可檢驗**：若 `VisualPatchWorld` 的 code-level world model 在 real-robot 上被 human engineer 修改後，其 rollout prediction error increase >20%（vs. unmodified version），則證明其 code 不具備 human-debuggable robustness，code-as-representation 仍屬 toy-level。
