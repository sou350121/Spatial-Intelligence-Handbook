## Adversarial Triad: UGG 把幾何輸出從單一 pointmap 改成生成式多假設——這是後 VGGT 的真路線，還是換皮的 per-scene 搜索？

**背景**：2611.14440 UGG 把 feedforward 幾何預測與生成式視頻合成統一成單一擴散模型。它的關鍵機制是用 per-modality / per-timestep 噪聲等級把「標註可用性」編碼進生成過程，使模型能在異質、只有部分幾何標註的數據上聯合訓練；推論時在無 GT 幾何下，以觀測 RGB 的幾何證據做 inference-time 多假設搜索。日報未報告 benchmark、FPS、memory 或 head-to-head 數字。它挑戰的是 **§13.1**（VGGT 是否 paradigm shift）與 **§13.3**（feed-forward 是否取代 per-scene optimization）。

**🔴 Bull（這是真信號）**

1. **它改的是訓練與輸出契約，不是刷點**：既有 feed-forward 幾何模型需要稠密 GT、輸出單一確定結果；純生成模型又不能直接輸出度量深度/位姿。UGG 用噪聲等級編碼標註可用性，讓「部分幾何標註」成為一等公民，這是機制層面的新能力軸，不是又一個 VGGT scaling。

2. **它把不確定性顯式化為多假設搜索**：在無 GT 幾何時用 RGB 幾何證據做 inference-time 多假設搜索，等於把「幾何預測」從單點估計改成可校準的假設集合。這對 §13.1 是支持而非反駁：VGGT 的確定性 feed-forward 只是其中一類，不是終局；也對 §13.3 的 hybrid 立場有利——feed-forward backbone 不必是唯一形態。

3. **它可能解掉幾何基礎模型的標註瓶頸**：如果異質、部分標註數據真能聯合訓練，幾何 foundation model 就不必依賴單一密集 GT 資料集。這是 scaling 幾何模型的實際瓶頸，ΔI 高於一般 +0.8 dB PSNR 的工程改良。

4. **它給「生成式」與「幾何」的對立提供第三條路**：不是 pure generative video，也不是 pure deterministic pointmap，而是 generative geometry。若成立，paradigm 軸會從「feed-forward 取代 per-scene」長出「generative geometry + inference-time search」的子類。

**🔵 Bear（過早慶祝 / 反共識）**

1. **完全沒有量化證據**：日報未報告任何 benchmark、FPS、memory、head-to-head。UGG 目前只是機制上漂亮；沒有數字，就不能說它推動了 §13.1 或 §13.3 的實證立場。相比之下，Wu 2025 對 VGGT 的批評、FastVGGT 的 quadratic memory、VGGT 518 px cap 都是有具體失效模式的反对证据。

2. **推論成本可能直接打死 deployment**：diffusion + 多假設搜索天然比單次 feed-forward 貴。§13.1 已經有 FastVGGT 記憶體爆炸與 VGGT 長序列限制；UGG 若不能報告長序列、FPS、記憶體，就只是把確定性問題換成生成式成本問題。

3. **它可能是「生成式外衣的 per-scene optimization」**：inference-time 多假設搜索仍然是 per-scene compute，不是 streaming SLAM。§13.3 明確說 feed-forward 沒取代 real-time SLAM with IMU + loop closure；UGG 沒有展示 IMU、loop closure、線上增量，所以不能拿它支持「feed-forward 全面取代 per-scene」。

4. **缺少消融，無法排除更簡單解釋**：partial-label 噪聲 schedule 可能等價於 masked multi-task training；多假設搜索的增益也可能來自更大模型/更多數據。若沒有固定模型、只改噪聲 schedule 與搜索策略的 ablation，就不能把 ΔI 歸給「生成式幾何」本身。

**🟢 Arbiter（裁決）**

1. **爭議立場更新**：  
   - **§13.1：維持**。UGG 不證明 VGGT 是 paradigm shift，反而把 VGGT 降為「確定性 feed-forward 子類」；Wu 2025 與 FastVGGT 的反對證據仍成立。  
   - **§13.3：微調**。原立場「feed-forward 取代 offline SfM/MVS，不取代 real-time SLAM」保持；新增子類「generative geometry / inference-time multi-hypothesis」屬於 hybrid，不是純 feed-forward 取代。  
   - **§13.6：不變**。UGG 不是 world model，不要混入 world model 定義之爭。

2. **軸移動**：paradigm 軸本週從「純 feed-forward」往 **generative geometry / hybrid** 微移；time 軸上 UGG 仍是 **per-scene inference-time search**，不是 streaming。真正往 streaming 移動的是 ActionCodec2、ODEAction、2611.14488 這一組 VLA 信號。

3. **關鍵代理指標 + kill condition**：  
   - 同一 RGB-only reconstruction/pose benchmark 上，與 deterministic feed-forward baseline **head-to-head**；幾何標註覆蓋率 ≤50%（本報告判準）；top-1 metric depth/pose error ≤2× dense-GT baseline；≥10 FPS 作為機器人 pilot 門檻、≥30 FPS 才配稱 real-time（本報告判準）；序列長度 >1000 frames。  
   - **Kill condition**：若只在 dense GT 或離線成立；若 top-1 不優於 deterministic baseline；若不能輸出 metric depth/pose；若 &lt;5 FPS 或記憶體隨序列爆炸——則 UGG 降回「概念記錄」，不移動 §13.3。  
   - **必要 ablation**：固定模型與資料，只改 noise schedule 與 multi-hypothesis search；若無顯著增益，ΔI 應下調。

4. **用戶行動建議**：  
   - 研究者：把 UGG 當成 **offline/async 幾何先驗與不確定性模組**，不要放進 real-time SLAM loop，直到 FPS、metric pose、長序列三項都驗證。  
   - VLA 團隊：本週就該補 **retrieval baseline（kNN）**、**event-indexed memory baseline**、**streaming decoding baseline**；這三個已從「可選」變成「不報會被質疑」。  
   - 選型/投資：看 head-to-head 與 real-robot replication，不看 demo；UGG 這類生成式幾何若沒有獨立復現，先維持觀望。

## 可證偽觀察清單

1. **UGG 方向驗證（§13.1 / §13.3）**：4 週內若出現 UGG 或其獨立復現的 head-to-head，在**同一 RGB-only reconstruction/pose benchmark** 上與 deterministic feed-forward baseline 比較，幾何標註覆蓋率 ≤50%、能輸出 metric depth/pose、top-1 error ≤2× dense-GT baseline、≥10 FPS，則 §13.3 微調為「generative geometry 子類」成立；若只在 dense GT 或離線成立、或 &lt;5 FPS，則維持原立場。以上閾值為本報告判準。

2. **Agent-as-policy 驗證（VLA specialist 爭議）**：若 2611.09892 被獨立復現於 **≥50 個 long-horizon tasks、≥3 種 embodiment、零任務特定 demo、真機而非純仿真**，且成功率 ≥70%，則 specialist VLA 的邊界顯著縮小；若 &lt;50%，則 2611.09892 更可能是 harness 工程與 task suite 偏置。

3. **kNN 即策略驗證（VLA 泛化爭議）**：在 compositional unseen tasks 上做 kNN vs VLA head-to-head；若 kNN >80% 而 VLA &lt;60%，則「VLA 泛化」敘事受重擊；若 kNN &lt;50% 而 VLA >70%，則泛化能力仍成立。此測試必須控制檢索庫大小與動作塊長度。

4. **記憶索引驗證（time 軸 / memory-augmented VLA）**：在**可變時長任務**上比較 event-indexed vs timestamp-indexed memory；若 event-indexed 成功率提升 ≥20% 且 phantom progress 顯著下降，則 2611.14488 的「時間戳是 shortcut」成立；若無差異，則該失效模式是特定任務 artifact。
