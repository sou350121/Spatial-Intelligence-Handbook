## Executive Summary

1. **本週最高 ΔI 信號：Zero-shot World Models Are Developmentally Efficient Learners（2604.10333，於 09-10 與 09-11 兩度被標 ⚡）。** 它以「時間因子化預測器解耦外觀/動力學 + 近似因果推論」從**單一兒童的第一人稱資料**學會多項物理理解，並自稱是「既有世界模型做不到的新能力」。它同時做兩件事：往 §13.6 的世界模型定義之爭**塞進第 8 個不相容的 claimant**，並直接挑戰 ontology 的隱含信念——世界模型是 Cosmos / Genie 級的「大規模影片預訓練」產物。本週唯一值得三視角辯論的就是它。

2. **第二高 ΔI：DefVINS（2601.00702，09-11 ⚡）。** 首個可變形場景 VIO，把狀態分解為「IMU 錨定的剛性分量 + embedded deformation graph 的非剛性 warp」，並用可觀性分析證明 **IMU 讓原本不可觀的變形模態變為可辨識**。它**支持** §13.3（IMU-SLAM 沒被 feed-forward 取代），但也在 paradigm 軸的幾何節點上開了一個新維度——幾何範式沒有停滯，它在擴張到 rigid 假設失效的領域。

3. **本週副軸成群出現但都是「範式內做扎實」：** CFAMs（部署後 on-device 持續學習軸）、Sound-based Multi-Person 3D Pose（純聲學感測）、TourPhysics（物理接地世界模型）、Reflection-aware Generative NVS（以生成式路徑處理 §13.2 的反射例外）。這些不動 §13 立場，只加深既有節點。

4. **整體傾向：world-model-as-policy + VLA 淹沒本週**，而世界模型軸已到尾端節點——大量 paper 在「world-model-as-policy」標籤下做改良（TourPhysics / TacPAC / HaMWPO / Persistent Robot WM / MINT 等），這是**範式鞏固**而非軸移動。幾何範式靠 DefVINS / BLASt3R / HiSfM / DCReg 續命。

## Adversarial Triad: 「零樣本世界模型從單一兒童的第一人稱資料學出多項物理理解——是數據效率的範式突破，還是又一個世界模型定義的通膨？」

**背景**：2604.10333（2026-09-10、09-11 兩度 ⚡）提出以**時間因子化預測器解耦外觀與動力學**、並用**近似因果推論**做零樣本估計，讓世界模型能從**單一兒童的第一人稱資料**學會多項物理理解能力。日報明確稱這是「既有世界模型做不到的新能力」與「新範式軸」。它落在 **§13.6 世界模型定義之爭**（NVIDIA Cosmos / Genie 3 / GAIA-3 / World Labs / AMI Labs / Verses / Runway 七方不相容定義）上，並撞上 ontology 的隱含信念——世界模型 = 大規模影片預訓練產物。日報**未報告任何量化指標、benchmark 名稱或基線**。

### 🔴 Bull（這是真信號）

1. **它把「世界模型」從形容詞變成可操作化定義。** §13.6 的七個 claimant 各自給的是行銷式定義；這篇給的是機制（時間因子化解耦外觀/動力學）+ 推論方法（近似因果估計）+ 一個可檢驗的能力主張（零樣本物理理解）。若成立，正是 §13.6 長期缺的「可判別的操作定義」。
2. **它直接挑戰「世界模型必須靠規模」的信念。** Ontology §13.6 列出的 Cosmos / Genie 3 都是 compute- 與 video-hungry 路線；本作主張從**一個**兒童的資料就夠，等於宣稱 scaling 不是唯一路徑——這對既有信念的衝擊不亞於當年 feed-forward 3D 對 per-scene 的挑戰。
3. **「零樣本」與 §13.3 是同一條邏輯軸的延伸。** Feed-forward 3D 的賣點是「無需 per-scene 優化」；本作把它延伸到世界模型——「無需 per-task 微調即可泛化到多項物理理解」。這是 paradigm 軸上一致的方向性信號，不是孤例。
4. **發展心理學式框架是可證偽的，不是純修辭。** 「從單一兒童、發展性地學會多項物理理解」是明確的能力-資料配比主張；可被「多受試者複現」與「同 benchmark head-to-head」直接檢驗。

### 🔵 Bear（過早慶祝 / 反共識）

1. **n = 1。** 日報明言資料來自**單一兒童**的第一人稱流。從單一受試者學出的「物理理解」是否泛化，本週沒有任何證據——這與 §13.6 各家的規模主張相比，是相反的樣本量極端，但同樣未證。
2. **「近似因果推論」是整篇的承重詞，也是最大破口。** 沒有識別性（identifiability）保證的近似因果，很容易把相關性當機制；「零樣本成功」可能是 overfit 到單一資料源的偽規律，而非真的物理。
3. **沒有 benchmark 名稱、沒有基線、沒有數字。** 日報完全未報告它對比了哪些「既有世界模型」、在什麼任務上、贏多少。要說「既有世界模型做不到」，前提是 head-to-head 同台——目前證據層級只是 capability demo。
4. **§13.6 的反對證據直接適用。** Ontology 立場是「the term means everything and nothing」。再加第 8 個 claimant **不會提高信心，只會加深定義通膨**；把一個未經 benchmark 共識驗證的主張放進「世界模型」傘下，是問題的一部分，不是解方。
5. **機制可能不新。** 時間因子化 latent-dynamics + 因果估計在既有 latent-dynamics 文獻已存在；本作的新意在**資料體制（developmentally efficient）**而非機制新穎性——這是一個 data-regime claim，不是範式 claim。
6. **對照組就在本週**：Compact Visuotactile WM（2609.09597）以嚴謹消融給出負面結論——觸覺預測準 ≠ 控制好、imagined RL 反而輸 reactive IQL。世界模型領域本週已有質量足夠的反例顯示「能預測」與「能用」之間的落差，這正是本作需要跨過的門檻。

### 🟢 Arbiter（裁決）

1. **爭議立場更新（§13.6）：維持，但需微調新增一條 claimant。** 這條證據**不移動**「定義不一」的判斷，反而**強化**它——本週再添一個（developmental / data-efficient）世界模型定義。建議 §13.6 新增一欄：「data-efficient / developmental WM」，並維持 ontology 對 term 的判別力折扣。**不需重寫，微調。**

2. **軸移動：** paradigm 軸**本周進一步向 world-model-as-policy 收斂**（TourPhysics / TacPAC / HaMWPO / Persistent Robot WM / MINT 等），但這是**範式鞏固而非移位**——世界模型軸已到尾端節點，多數 paper 是在該節點內做工程改良。真正的軸向擾動來自**幾何節點**（DefVINS 開出可變形 VIO），以及 **sensor 軸的聲學**（Sound-based 3D Pose）。

3. **關鍵代理指標 + kill condition（閾值為本判斷自設判準）：**
