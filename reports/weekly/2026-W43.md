## Executive Summary

1. **本週最高 ΔI 信號：`Online World Modeling Enables Real-World IRLfO`（2602.24121）**——真實世界、僅憑任務觀測 video、40 分鐘內把 pick-and-place 訓練到 82%（同等預算 RL 0%、BC 12%），並首次展示真實世界跨任務正向在線遷移。這不是又一篇「世界模型預測影片」，而是把 world model 當**回報源 / 系統辨識替代品**，直接錨定 §13.6「World Model 定義之爭」。

2. **但本週世界模型大爆發（13+ 篇觸及 §13.6）恰恰印證而非推翻 ontology 的「定義不一」立場**：Cosmos 式生成器、WorldStream 式可編輯持久世界、Physical Canvas 式視觸覺一體、PhysiCalWorld 式物理校準、μ0 式 3D 軌跡介面——每一篇都在定義自己的「world model」。收斂訊號薄，碎片化訊號厚。

3. **次高 ΔI 出現在 VLA 推理表徵的可操作化**：`Reasoning as a Distribution`（plan latent，轉向命中 0.48→0.94，且用「原生動作分佈同樣加引導無效」把增益歸因到 plan 層）、`Phenomenology of Neural Geometry`、`Flow Control`。VLA 正從「黑箱策略」往「可定址、可引導的推理狀態」移動——這是本週唯一一條在 paradigm 軸上有結構性移動的 VLA 訊號。

4. 判斷：**本週不是 paradigm 換代週，是 world-model-as-policy 的「語義通膨週」**。真正 load-bearing 的是 IRLfO 那組真機數字，其餘多數世界模型論文是「把既有範式做扎實」的 🔧。

## Adversarial Triad: 世界模型當回報源，這週拿到真機船票了嗎？

### 背景

`Online World Modeling Enables Real-World Inverse Reinforcement Learning from Observation`（2602.24121）宣稱是**首個在真實世界僅憑任務觀測（video）從零學會視覺操作**的 IRLfO 方法：以線上世界模型取代獎勵設計、模擬器建模、動作監督三項瓶頸，**40 分鐘內**把 pick-and-place 訓練到 **82%**（同等預算下 RL 為 **0%**、BC 為 **12%**），並**首次展示真實世界跨任務的正向在線遷移**。

它直接錨定 §13.6「World Model 定義之爭」——這條爭議的 ontology 立場是「同詞被 7 家實體用 incompatible definitions，用 World Foundation Models 統稱但明示定義不一」。IRLfO 把 world model 從「生成器 / 預測器」推向「**回報源 / 系統辨識替代品**」——這是 §13.6 清單之外的第八種定義。問題是：這是一條新範式的第一張真機船票，還是一個漂亮的單任務 demo？

---

**🔴 Bull（這是真信號）**

1. **比較是硬對照，且在同一預算下**：40 分鐘內 82%，而 RL 0%、BC 12%——不是「比 baseline 好一點」，是**同一預算下兩個數量級的差距**。這說明「獎勵/示範」這條常規路徑在短預算區間根本取不到信號，而 world model 的預測誤差反推 reward 取到了。
2. **三瓶頸同解，是真能力而非工程拼裝**：日報明確「以線上世界模型取代獎勵設計、模擬器建模與動作監督三項瓶頸」。這不是把既有 reward 換個損失函數，是把「怎麼知道做對了」這件事本身外包給世界模型——這是 §13.6 定義的實質擴張。
3. **首次真實世界 cross-task 正向在線遷移**：日報明講「首次展示真實世界跨任務的正向在線遷移」。跨任務正向遷移是 world model 內部表徵可復用的**最強證據**——若只是單任務 reward hack，遷移不會正。
4. **它把「需要什麼監督」這個更根本的問題擺上桌**：BC 需要高質量示範、RL 需要獎勵設計、IRLfO 只需要 video。這條路線若成立，會動搖 VLA 領域對 teleoperation 語料的依賴假設——比單一 benchmark 刷點重要得多。

---

**🔵 Bear（過早慶祝 / 反共識）**

1. **82% 是單任務 pick-and-place**：日報只報告這一個任務，未報告更多任務族。§13.6 的教訓正是「一個詞、多種定義、各自 demo」——IRLfO 目前也是「一個任務、一個漂亮數字」。單任務超強 ≠ 範式。
2. **預算口徑可能不公平**：40 分鐘 vs BC 12%——BC 的質量取決於示範分佈，video 是免費數據，二者資訊成本不對等；RL 0% 也高度依賴其獎勵設計是否被削弱。這未必是「world model 更好」，可能是「這個比較的兩邊都被設在不利位置」。
3. **世界模型仍只是預測器，reward 從預測誤差反推——這沒解 §13.6**：IRLfO 的機制本質是「用 world model 的預測殘差當 reward proxy」，它沒有回答「world model 到底是什麼」，只是又加了一種用法。§13.6 仍列出 7 家 incompatible definitions，碎片化未收斂，反而 +1。
4. **跨任務遷移的「正向」幅度日報未給數字**：只說「首次展示正向遷移」，沒有量化幅度、沒有 head-to-head 同任務對比、沒有更多真實場景。這與本週 `Scaling Online Exploration` 給「泛化隨探索量單調提升」的可量化 scaling 證據相比，證據成熟度差一檔。

---

**🟢 Arbiter（裁決）**

1. **爭議立場更新：§13.6 維持「定義不一」，微調。** IRLfO 不足以重寫「定義不一」這個元判斷——它反而新增了第八種定義（world model as reward source / system-ID substitute）。但**微調**一處：應在 §13.6 的定義清單裡補一條「world model as IRL/reward 源」，並標註「已有首個真實世界單任務驗證（82%/0%/12%，40 min）」。移動幅度 = 微調，不是重寫。

2. **軸移動：paradigm 軸本週明顯向 `world-model-as-policy` 位移**。本週 13+ 篇觸及 world model，且 physical-aware（PhysiCalWorld）、feedback-closed-loop（Feedback World Model）、code-as-stream（Agentic WAM）、skill-program（μ0）、touch-grounded（Physical Canvas）都在把 world model 從「會生成影片」推向「可執行決策的基礎設施」。但**這不是範式換代**，是同一範式內部的定義裂變——與 ontology §5.3 的「World Foundation Models 統稱但明示定義不一」一致。

3. **關鍵代理指標 + kill condition**（我設的判準，非已知事實）：
   - **確認條件**：出現 IRLfO 類方法在 **≥5 個真實任務族**（非僅 pick-and-place）、**≥1000 real episodes**、與 BC/RL **同預算 head-to-head**、並量化「跨任務遷移幅度」的報告，則可將 §13.6 中該條從「新增定義」升級為「成熟路線」。
   - **推翻條件**：若後續工作顯示 82% 在任務複雜度提升後掉到與 BC 同級，或「正向遷移」實際幅度 &lt;5 個百分點，則該條退回「單任務 demo」。
   - **旁證**：VLA 領域若出現 >3 篇「無 teleop 語料、僅 video 預訓練」在真實任務上可用的報告，則「示範依賴」假設本身受挑戰（與 `Scaling Online Exploration` 匯流）。

4. **用戶行動建議**：
   - **把 "world model" 一詞拆開讀**：預測器 / 生成器 / reward 源 / 系統辨識 / 決策基礎設施——五種語義在本週同時出現，用錯會誤判論文。IRLfO 屬第四種，別拿它去論證「生成式世界模型能當 SLAM」。
   - **對 82%/0%/12% 保持「單任務興奮、範式存疑」**：數字很硬，但它是 40 分鐘短預算區間的對照，不能外推為「world model 普遍優於 BC/RL」。
   - **優先追蹤兩條匯流線**：IRLfO（reward 源）與 Scaling Online Exploration（探索取代示範）——若兩者在同一 benchmark 上相遇，才是「不需要人類示範」的真範式信號。

## 簡評

- **Scaling Online Exploration（2610.22496）· 高 · VLA paradigm**：coding agent + 在線探索直接合成可執行程式，取代 teleop 示範語料與 value function，並給出「泛化隨探索量單調提升」的多 embodiment scaling 證據。判斷：這是本週第二個真正動搖假設的信號——「策略不再受 imitation distribution 束縛」若被獨立復現，比 §13.6 更根本；但目前是「程序合成」路線，與連續動作 VLA 的 gap 待驗證。
- **Reasoning as a Distribution（2610.28166）· 高 · VLA 推理表徵**：把 plan 從點估計改寫為可定址低維條件分佈，轉向命中 0.48→0.94，並用「原生動作分佈同樣加引導無效」的對照把增益歸因到 plan 層——這是本週 VLA 側最乾淨的因果歸因。判斷：VLA 的可控性正從「加模組」轉向「改表徵」。
- **WorldStream（2610.28827）· 中-高 · §13.6**：無界地形 + 持久可編輯世界狀態，typed decision model 產生跨 tile boundary commitments，單一 world record 支撐前向生成與語言編輯。判斷：把「生成式世界模型」的定義往「可回訪、可編輯的環境數據庫」推，是本週生成器定義擴張最強的一篇；但仍是單篇、無外部 benchmark 對照。
- **Let It Be Simple（2606.05737）· 中-高 · VLA 生成式**：用 Flow-Matching 不可約速度損失的端點塌縮 + Jacobian 最大奇異值，量化說明「一步生成不可行」只屬 T2I 不屬 VLA，免蒸餾取得單步策略。判斷：分析性論文，挑戰「生成式策略需多步採樣」的普遍假設；但需在 >1 個真實任務上復現。
- **Physical Canvas（2610.28613）· 中-高 · §13.6 / 感測軸**：視觸覺統一進同一 video VAE，Scene/Modality/State 三凍結獎勵做一致性後訓練，解「視覺似真卻誤表接觸動力學」。判斷：把觸覺從「觀測附加」提升為「世界模型的第一等模態」，是本週模態軸最有價值的一步。
- **PhysiCalWorld（2610.30125）· 中-高 · world-model 泛化**：單一 physics descriptor token 做 in-context 物理校準，免標籤免微調。判斷：把系統辨識內化進世界模型潛空間，直擊「新物理參數場景 rollout 漂移」痛點；但實驗主要在導航場景，需更多接觸任務驗證。
- **Feedback World Model（2605.15705）· 中-高 · world-model-as-policy**：把開環 rollout 改造成帶在線回饋的閉環預測器，latent observer 有收斂保證、無需重訓。判斷：解 OOD 漂移的機制乾淨，是本週「世界模型可靠性」方向最直接的一篇。
- **Momentum（2610.23423）· 中-高 · §13.6**：同步參考相機組共享世界狀態 + rig 圖傳播，視野外車輛/行人不再遺忘。判斷：把「持久記憶」做成幾何條件化的多相機同步，機制比 image-cache 硬；但仍是生成式路線的內部改良，非新範式。
- **KITE（2606.22113）· 中 · 跨 embodiment**：接觸模式作 embodiment-agnostic 交互意圖中介，僅憑目標運動學零樣本跨形態。判斷：把「跨具身」從動作重定向升級為「意圖重定向」，方向對；但只給機制，跨形態的量化對照待補。
- **PACT-VLA（2610.28019）· 中 · time 軸**：用 pre-commit 觀測對 action chunk 做 speculative 驗證，FlowRes 自評分、零額外控制步延遲。判斷：把異步推理的延遲窗口「變廢為寶」成驗證時間，是 time 軸上少見的巧思；需真機 >100Hz 控制迴路驗證。
- **BeJEPA（2610.23127）· 中 · 表徵**：世界座標共享潛在 + successor predictor 壓長時程，AMASS 全域位置誤差降 61.7% vs BFM-Zero。判斷：successor representation 接 JEPA 是乾淨的組合，但 61.7% 是相對 BFM-Zero，缺絕對基準。
- **LidarVerse（2610.19201）· 中 · LiDAR 世界模型**：reconstruction+generative 融合，universal tokenizer，32/64/128-beam 泛化。判斷：填補「統一條件生成式 LiDAR 世界模型」空白，但自駕/機器人下游增益未報告。
- **Flow Control（2606.10180）· 中 · VLA 可控性**：凍結 VLA flow-matching 動作專家初始條件寫入實時人類輸入。判斷：與 Reasoning as a Distribution 同屬「VLA 可控性表徵化」浪潮，但機制是初始條件注入、較淺層。

| 軸 | 本週偏向 | 說明（代表論文） |
|---|---|---|
| **problem** | ↑ VLA / navigation（主導）· mapping/tracking 次之 | VLA 類 40+ 篇（Robota-Embed、Flow Control、PACT-VLA、Reasoning as a Distribution…）；navigation 次之（Scaling Online Exploration、AirPlayground、CovNav）。reconstruction/occupancy 邊緣化。 |

| **paradigm** | **↑↑ world-model-as-policy（本週最大位移）** | 13+ 篇觸及 world model：IRLfO、WorldStream、PhysiCalWorld、Feedback WM、μ0、Agentic WAM、Physical Canvas、BeJEPA、LiveAct、Momentum… paradigm 軸本週確實向 world-model 傾斜，但是「定義裂變」而非「範式換代」。 |

**一句話**：本週 paradigm 軸向 world-model 移了一大步，但這一步是**語義通膨**大於**能力躍遷**；真正的能力躍遷在 time 軸（延遲窗口的再利用）與 VLA 可控性（表徵化 steering）這兩條較小的軸上。
