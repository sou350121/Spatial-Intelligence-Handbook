## Adversarial Triad: 「首個 3D-native WAM」是真表示突破，還是給 §13.6 的混亂再加一個變體？

**背景**：UNITAS（arXiv 2610.12099, cs.RO）宣稱是**首個 3D-native world action model**——把 world action model 的世界演化表徵從 2D 影片/視覺 latent，換成**共享 metric 空間的 3D point-trajectory flow**（action flow + scene flow），並以 world-aligned 3D positional embedding 與 physical-time trajectory tokenizer 打通跨 embodiment 的動作與場景預測。日報給的機制理由是：**像素距離不編碼物理距離**。標籤為 `paradigm: world-model-as-policy · time: feed-forward · problem: VLA · representation: pointmap · sensor: multi-modal`。

它直接落在 **§13.6** 的靶心：該節列出 7 個互不相容的 World Model 實體（NVIDIA Cosmos 生成式影片、DeepMind Genie 3 即時自回歸、Wayve GAIA-3 閉環駕駛、Fei-Fei Li World Labs 3D-grounded、LeCun AMI Labs 下一狀態表示學習…），現判「一個什麼都指、什麼都不指的詞」。UNITAS 主張的是：世界模型該在 **3D metric 空間**演化，不是 2D 影片。這是對 §13.6 混亂的**正面回應**，還是**第八個節點**？

**🔴 Bull（這是真信號）**

1. **§13.6 缺的正是可證偽的表示定義，UNITAS 給了。** 該節把 7 個 World Model 實體並列卻無一給「世界該用什麼表示演化」。UNITAS 給出單一具體選擇：**3D point-trajectory flow**（action flow + scene flow），而非 2D 影片 latent（Cosmos 式）。這不是又一個應用層變體，而是一個**表示層的可否證命題**。

2. **它解的是有文件記載的缺陷。** 日報明說解掉「像素距離不編碼物理距離」。這與 §13.4 記載的 Depth Anything 病（「No metric scale without Metric3D-v2」）同源——2D 表徵丟失 metric。3D-native 直接修此病，且是**機制級**的（把動作與場景放進同一 metric 空間），不是 prompt 級。

3. **本週 WAM 群自證痛點。** Cross-Embodiment WAM with Latent Actions（2610.10846）用統一 latent action 空間解「explicit action conditioning 導致跨 embodiment 分裂」；UNITAS 用 world-aligned 3D positional embedding 解同一問題的另一面。兩篇獨立工作指向**同一瓶頸**：跨 embodiment 的障礙在表示層。這使 UNITAS 的表示選擇不只是審美偏好。

4. **它是「first」，即開新軸而非刷榜。** 本週 ⚡/🔧 共計 100+ 篇論文，絕大多數自認「沿既有範式」。UNITAS 是少數自稱開新方法軸者之一——在一個 SOTA 通膨的週次裡，「開軸」本身就是可辨識信號。
