## Adversarial Triad: Latent evolving World Action Model — 拆掉 video diffusion backbone，WAM 回到 JEPA 陣營？

**背景。** WAM（World Action Model）在 2025-2026 主流實作幾乎綁死在一條 pipeline 上：**大型 video diffusion backbone + VAE latent**，動作與未來 frame 在同一個生成式骨幹上聯合去噪（本週的 AffordanceWAM / MachEmbodied-U0 / CoRe-WAM / DeltaWAM / LiMA / PointCast 幾乎都是這一支）。2609.27455 直接拒絕這個前提：改用 **JEPA 預測式 embedding 空間**同時做動作生成與環境演化預測，並主打兩個賣點——(a) 新方法軸「representation-for-action 的可控比較」，(b) 免生成式主幹的 latent world model；(c) 以 **DemoDPO** 在不需環境互動、不需人工重啟下做 offline 偏好式策略改進。日報對這篇**未給出任何成功率、延遲、參數量數字**。它觸動的是 **§13.6「World Model 定義之爭」**——本體論立場明示「同一詞被 Cosmos（generative video）/ Genie 3（autoregressive video）/ World Labs（3D-grounded）/ LeCun AMI（預測下一狀態的 representation learning）等實體用互不相容定義」。這篇是對 LeCun 陣營的一次架構級投票。

**🔴 Bull（這是真信號）**

1. **它把 §13.6 的兩條互斥定義壓到一個架構裡。** §13.6 記錄的是定義分裂；這篇的機制主張是「預測式 embedding 空間可以**同時**產動作與演化預測」——也就是說 LeCun 定義（representation learning to predict next state）不必再與「產動作」分家，這正是 Cosmos 定義裡的 "post-train as policy" 那一環。若為真，兩條定義的邊界被侵蝕，這是對 §13.6 現有「互不相容」描述的實質衝擊。

2. **解耦了「表徵選擇」與「生成主幹」兩個混淆變量。** 日報明示其新方法軸是「representation-for-action 的可控比較」。今日所有 WAM（LiMA 70.8% 成功率、MachEmbodied-U0 LIBERO 99.0%、CoRe-WAM 1.59M adapter 刷 RoboTwin SOTA）都只報 end-to-end 成功率的**結果**，沒有隔離「世界模型表徵」本身的貢獻。一個能控制的對照軸，其**方法論價值獨立於它自己的分數**。

3. **DemoDPO 正面處理了 WAM 後訓練最貴的一環。** RL-based WAM post-training 的成本主項是環境互動與 reset；「不需環境互動/人工重啟的 offline 偏好式改進」若成立，等於把 post-training 從 online 搬到 offline，是**能力解鎖**而非調參。

4. **JEPA 路線的工程槓桿天然更大。** 免 VAE 重建瓶頸、免 video diffusion 的逐步去噪，理論上參數與延遲都更低——相對於本週 Rolling-WAM（4.5× 加速）、Streaming-WAM（2.93×）這些靠工程 trick 在生成式主幹上硬搾的效率，這是**架構層**的效率，不是 trick 層。

**🔵 Bear（過早慶祝 / 反共識）**

1. **反 Bull #1：這是「新增第三種定義」，不是「壓縮定義」。** §13.6 的病根是詞被濫用；一篇 JEPA-for-action 論文只是往「不一」的堆疊裡再添一個 flavor。Cosmos 陣營不會因這篇放棄 generative video（本週 Astronex-World、ZYT-World、InternW0、PhysStream 全在擴張生成式主幹）。動 §13.6 的門檻是**收斂**，這篇是**分叉**。

2. **反 Bull #2：日報未報告任何數字。** 「可控比較」若無 head-to-head 表（同任務、同 embodiment、報成功率+延遲+參數），這個軸就只是宣稱。對比：本週同族論文都給了硬數字（LiMA 45.8% 延遲↓ / 70.8% 成功率；WM-VS 真機 7-DoF 30/30；Rolling-WAM 4.5×）。**一篇沒有數字的架構革命，其 ΔI 應被折價。** 公允地說：這是 absence of evidence，不是 evidence of absence——但在判準上就該當低信心處理。

3. **反 Bull #3：JEPA 有已知的表徵坍塌失敗模式。** §13.1 已經記錄 arXiv 2512.21691 對 VGGT 的指控：global self-attention「literally collapses to rank-1」as input length grows。預測式 embedding 方法在長 horizon 下的坍塌風險是同源問題。一個**為了預測而優化**的表徵，恰恰可能在長 rollout 下退化成 trivial state——而 DemoDPO 的 offline 偏好改進不會自動偵測這件事。

4. **反 Bull #4：DemoDPO 是 offline RL，繼承 offline RL 的全部病。** 偏好標籤便宜但噪；offline preference 的 distribution shift 是老問題；「不需環境互動」意味它**只能重加權既有行為、不能發現新行為**。把它列為「能力解鎖」需要看它對**未曾示範過的失敗模式**是否有效，日報未報告。

5. **更簡潔的替代解釋**：你也可以「拆掉生成式主幹」但**保留 action-conditioned 預測目標**——那它就退化成一個普通的 action-conditioned policy，此時 "world model" 這個標籤是架構沒有掙來的。是否真有一個「世界模型」在做事，需要消融證明。

**🟢 Arbiter（裁決）**

1. **爭議立場更新：§13.6 —— 維持，但往 JEPA 陣營微調。** 這篇沒有推翻「定義不一」的診斷（它反而加劇），所以**不需重寫**。但它是本週唯一一篇**主動為 LeCun/AMI 定義背書並產出動作**的工作，因此立場由「統稱、明示不一」微調為「統稱、明示不一，但 latent-predictive 分支本週出現一個可用的 action 實例」。這是**微調**，不是移動。

2. **軸移動：paradigm 軸維持 `world-model-as-policy`，但該節點本週裂出 fork。** 我們不新增第五條 paradigm，而是在既有節點內標記兩個子型：**generative-video-WAM**（本週主力，>15 篇）與 **latent-predictive-WAM**（2609.27455、Underwater C3-JEPA 2609.30214、Visual Representation for Navigation World Models 2609.29555）。time 軸無位移，仍然 `temporal-transformer-rolling` 主導。

3. **關鍵代理指標 + kill condition（我設的判準）：**
   - **確認條件**：出現一篇 WAM 論文，**同一 embodiment、同一任務集**上做 JEPA-WAM vs generative-video-WAM 的 head-to-head，同時報 (a) 成功率、(b) 參數量、(c) 推理延遲、(d) 真機（非僅仿真）。且 JEPA 側成功率不落後 >5pp。
   - **表征健康判準**：長 rollout（≥100 步）下，預測式表徵的有效秩/方差維持在基線之上（防坍塌）。
   - **Kill condition**：若 (i) 無任何 head-to-head 出現，或 (ii) JEPA-WAM 在某個可比的真機 contact-rich 任務上落後一個 video-diffusion WAM **>5pp 成功率**，或 (iii) 表徵在長 horizon 坍塌——則「拆掉生成式主幹」的宣稱在本 ontology 內降級為「未證實的替代架構」。

4. **用戶行動建議**：
   - **不要再用單一 "WAM" 名詞做比較。** 本週起必須區分 generative-video-WAM 與 latent-predictive-WAM，否則所有跨論文比較都無效。
   - **把 2609.27455 目前當「方法論工具」而非「結果」。** 它現階段的價值是可控變量，不是性能；任何引用它性能的結論都應標 `日報未報告`。
   - **對所有 "drop the backbone" 宣稱，先要 params/latency 表。** 沒有這張表，架構革命與行銷文案無法區分。

## 簡評

**CrossSafe (2609.28984) — ΔI 中-高 · 錨定 paradigm（hybrid）＋ §13.5 相鄰。** 把 HJ reachability 值函數搬進 morphology-aware 潛在空間、以 embodiment 為條件，開「跨具身共享安全濾波」軸——此前安全濾波器綁死單一動力學。判斷：軸是真的新，但**形式保證**是安全濾波的生命線，而 latent 抽象通常破壞 Hamilton-Jacobi 的保證；需看到「不同形態間轉移後仍具形式/可驗證保證」而非僅仿真經驗成功率（日報未報告後者）。暫列**待證新軸**。

**Compliance for Free (2609.19976) — ΔI 中-高 · 錨定 paradigm（VLA）。** 首次讓 VLA 除位姿外輸出剛度/順應性，並用四通道雙邊遙操作（leader 臂作意圖平衡點的獨立量測）解決順應性監督的可辨識性，零標註取得 per-timestep 方向相關剛度標籤。判斷：這是**解了既有示教介面原則上取不到順應性**的事，若成立即為能力解鎖。但日報只報告到「取得標籤」與機制，未報告**閉環操作任務的成功率**——需看到 contact-rich 真機閉環數字才算落地。

**Stochastic Neural Signed Swept Volume (2609.21211) — ΔI 中 · 錨定 representation（implicit-sdf）。** 把掃掠體學成帶認知不確定度的機率 signed-distance 場，使神經碰撞幾何從「只能當粗篩的確定性模型」升為**可直接產生安全約束的不確定度表徵**。判斷：這是把 §13.x 未列出的子軸（不確定度可用的隱式幾何）具體化，與 CrossSafe 同週出現，暗示「不確定度可用的幾何表徵」是本季正在自發形成的一條線。

**Free-Init (2609.29375) + FMCW-LIO (2609.29374) — ΔI 中 · 錨定 §13.3 / sensor。** 兩篇同日用 FMCW Doppler LiDAR 的點級都卜勒速度：前者免掃描匹配/免激勵運動/免地圖對應初始化，後者以運動補償＋都卜勒輔助觀測模型在幾何退化場景穩健。判斷：這是**sensor 驅動**的路線，正好落在 §13.3「feed-forward 沒取代 real-time SLAM with IMU」的縫隙裡——它不靠 feed-forward，靠新物理量。需獨立 head-to-head 才算數。

**VGGT-hybrid cluster (RegVGGT 2609.23286 / G3AR 2609.16603 / DAVIO 2609.27702 / SURE-Map 2609.15795 / AnalogDepth 2609.24312 / FOCAL-VLA 2609.21228 / StrataVLA 2609.26071) — ΔI 中（集體）· 錨定 §13.1 + §13.3。** 七篇都在把 VGGT/Pi3/DA3 當 backbone 再包一層工程：RegVGGT 用免訓練 token 顯著性調控（每幀僅留 1% token 更新 context）直攻 §13.1 記錄的「quadratic memory blows up（FastVGGT）」痛點；DAVIO、G3AR 都是 feed-forward 幾何 + 經典後端的 hybrid。判斷：**這是本 ontology §13.1/§13.3 立場（"VGGT 是重要範式信號但不是 shift"、"實際 deployment 走 3R-SLAM Hybrid"）的當週最強實證**——沒有一篇是純 VGGT 端到端，全都加了混合層。這是支撐、不是撼動。

**Visual Navigation Transformer with Pose Attention (2609.21212) — ΔI 中 · 錨定 representation（sparse）。** context 從「時序歷史」改為 pose-indexed keyframe 集，用**相機位姿差**（非時間序）作 positional encoding，無需顯式地圖即可跨軌跡融合經驗，並稱在定位噪聲下優於顯式地圖基線。判斷：這是把 "時間軸" 換成 "位姿軸" 的表徵選擇，與 WAM 陣營的 temporal-transformer 主流相反；值得追，但日報未報告跨軌跡規模與噪聲門檻。

**Shake to Learn (2609.20970) — ΔI 中 · 錨定 sensor + problem。** 以軟體手臂作物理儲備池、固定抖動的 ringdown 動力學本身為感知模態，推斷視覺不可見的隱藏物體 COM。判斷：這是**主動交互動力學**作為新感知通道，與本週 Reactive 觸覺（TacSushi、ZeroTouch、ForeTac-VLA）不同——它不是多加一個感測器，是**重新定義感測**。概念強、樣本量與泛化未報告。

**Feeling Terrain Before Crossing (2609.19863) — ΔI 中 · 錨定 §13.6 + sensor。** 首個以 proprioception 為條件的導航世界模型，預測軸從「相機會看到什麼」擴到「機器人會感覺到什麼」（未來本體態 + 失效風險）。判斷：這是 §13.6 爭議拆出的一條**模態軸分岔**（vision-predictive WM vs proprioceptive WM），與 2609.27455 同週，共同顯示 WAM 正在多方向分裂。

**REACT (2609.19204) — ΔI 低-中 · 錨定 time（filter-streaming）+ sensor（event）。** 複數脈衝神經元 C-SiLIF 讓內部狀態由事件間隔驅動、連續時間演化，端到端 4.6 ms、無時間累積。判斷：把事件相機的整合延遲壓低是真的工程價值，但屬事件感知 niche，未觸動任何 §13 爭議。記錄級。

## 可證偽觀察清單

1. **下週內（≤ 7 天）應出現 ≥1 篇 WAM 論文的 head-to-head 對比表**——同一 embodiment、同一任務集上，latent-predictive-WAM vs generative-video-WAM，同時報成功率 / 參數 / 延遲 / 真機。
