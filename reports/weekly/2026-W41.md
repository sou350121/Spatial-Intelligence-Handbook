## Adversarial Triad: UNITAS 宣稱「3D-native」為世界模型贏得定義權——但定義權不在 representation 軸上

**背景**：UNITAS（2610.12099，cs.RO）自稱**首個 3D-native World Action Model**：把 WAM 的世界演化表徵從 2D 影片/視覺 latent，換成**共享 metric 空間的 3D point-trajectory flow**（同時含 action flow 與 scene flow），並以 world-aligned 3D positional embedding 與 physical-time trajectory tokenizer 打通跨 embodiment 的動作與場景預測。它直接宣稱解掉「像素距離不編碼物理距離」的既有缺陷。這條證據挑戰的是 **§13.6「World Model 定義之爭」**——該爭議的本體論立場是「同詞被 NVIDIA Cosmos／Genie 3／GAIA-3／World Labs／AMI Labs／Verses／Runway 用**不相容**定義」，§5.3 用「World Foundation Models」統稱但明示定義不一。UNITAS 的主張等於說：定義之爭有一個「對的答案」——metric 3D。

**🔴 Bull（這是真信號）**

1. 它攻擊的是一個**被本體論自己承認的缺陷**：§13.6 明列 AMI Labs（LeCun）定義為「預測下一狀態的 representation learning」，而 2D 影片 latent 恰恰不是「物理下一狀態」。UNITAS 的 metric point-trajectory flow 把表徵換成有物理單位的物件，是往 LeCun 定義直接靠攏，而非再貼一次標籤。
2. **機制具體可審**：action flow + scene flow 共處於同一 metric 空間、world-aligned 3D positional embedding、physical-time tokenizer——這三項是可以被 ablation 的設計，不是「我們也叫世界模型」的行銷句。
3. **它是收斂訊號的一部分而非孤證**：同週 World Motion Models（2610.01742）以稀疏 SE(3) 軌跡＋flow-matching 統合多任務、Cross-Embodiment（2610.10846）以統一 latent action 解跨具身分裂——三篇獨立工作都把世界模型推向「metric/幾何 latent」，這種**跨實驗室收斂**比單篇 "first" 更有說服力。
4. 它與 §13.1 的「多任務 synergy」與 Fei-Fei Li 在 §13.6 的「3D-grounded representation」定義互相印證——3D-native 恰是能同時容納「幾何接地」與「跨具身共享」的最小公約數。

**🔵 Bear（過早慶祝／反共識）**

1. 反駁第 1 點：§13.6 的爭議**不是**「誰的表徵比較物理」，而是「**同一個詞被用來指什麼**」。UNITAS 沒有讓 Cosmos（生成式影片＋動作）或 Runway（影片生成工具）停止自稱世界模型；它只是往堆疊裡再加一個不相容實例——§13.6 的立場（fragmentation persists）**不因單篇改名而動**。"3D-native" 目前是命名邊界，不是定義裁決。
2. 反駁第 2 點：機制可審 ≠ 有效。日報未報告 UNITAS 在**真機**上的任何數字，也未報告它與既有 2D-latent WAM 的 **head-to-head 同任務對比**（同週就有 Token-World 2610.00575、Long-WAM 2610.10528、Being-M0.7 2610.11283 等可作對照）。「首個」在沒有對照前只是相對自身 baseline 的內部說法。
3. 反駁第 3 點（收斂論）：本週 WAM 類論文絕大多數被日報標為「沿用既有 WAM 範式、無新方法軸」——這更像**領域飽和**的特徵，不是收斂。三個獨立工作朝同一方向，也可能只是同一批審稿偏好的反射，而非物理正確性被證明。
4. 反駁第 4 點（物理接地）：point-trajectory flow 的「metric 空間」依賴一個 metric depth 來源，而 §13.4 明載 depth 模型「**無 metric scale（無 Metric3D-v2 時）**、在反射/薄結構/旋轉影像上脆弱」。把世界模型架在一個已知脆弱的先驗上，等於把 §13.4 的失敗模式整套繼承進 WAM——§13.2 的 3DGS 反光例外是同一類警告。
5. 附加反共識：只要「共享 metric 空間」在**遮擋、動態物件、反光**場景崩掉，3D-native 的物理優勢就會反轉成脆性劣勢——這正是 feed-forward 3D 一再被 §13.1 的 Wu et al. (2025) 與 arXiv 2512.21691（rank-1 collapse）點名的老問題。

**🟢 Arbiter（裁決）**

1. **爭議立場更新（§13.6）**：**維持 + 微調**。不重寫——行銷層的定義碎裂（Cosmos/Genie/GAIA-3/World Labs/AMI/Verses/Runway 各自不相容）本週毫無改變，UNITAS 甚至只是多加一個實例。但需在 §13.6 補一條註記：**「技術層出現往 metric/物理 latent 收斂的雛形（UNITAS 3D-native、World Motion Models SE(3)、Cross-Embodiment latent action），惟尚未有任何 head-to-head 或真機證據。」** 幅度：微調，非重寫。
2. **軸移動**：本週 **representation 軸**明顯往「pointmap / metric-3D」偏（UNITAS、Slot3R、PointVGGT、SatFix），與 **paradigm 軸**交會——世界模型不再停在影片生成，開始要求 metric 幾何。**time 軸**整體往 temporal-transformer-rolling 偏（WAM 叢集、NavGPT-3）。sensor 軸本週有微幅「非相機化」（SonarVoxNet 2610.01644、SURGE 2610.07472 聲納；event-camera VO 2610.02601；RAGNAROK 2610.11531 radar），但不足以移動主軸。
3. **關鍵代理指標 + kill condition**（閾值為**本報告自設判準**，非已知事實）：
   - **確認條件**：需看到 UNITAS 型 3D-native WAM 與 2D-latent WAM 在**同一 benchmark、同一 embodiment** 的 head-to-head，且**真機（非純仿真）episode > 1000**，並附**表徵 ablation**（把 metric point-flow 換回像素 latent 後增益消失）——若「3D-native」的增益能被容量差異解釋，方向即證偽。
   - **kill condition**：若在遮擋/反光/動態場景上相對像素空間模型**無優勢或更差**，或整體收益被歸因於 metric depth 先驗本身（而非 3D-native 架構），則 §13.6 的「技術收斂」註記應撤回。
   - **門檻**：任務成功率或 OOD 穩健性需有**清楚、非邊緣**的差距（量級差異，非 1–2 個百分點噪聲），才足以稱「軸移動」。
4. **用戶行動建議**：
   - **現在就把「3D-native WAM」當假設、不當事實**：等 head-to-head 與真機數據；看到 "first 3D-native" 標題時先問「跟誰比、在哪比、真機還是仿真」。
   - **盯 metric depth 這個瓶頸**：UNITAS 的物理接地成立與否，取決於 §13.4 早已標記的 metric scale 問題——若無 Metric3D-v2 級來源，3D-native 的優勢在部署中會打折。
   - **對 WAM 叢集的「軸」保持懷疑**：本週 20+ WAM 論文中絕大多數無新方法軸，真正的信號是少數三篇的**方向一致性**，不是數量。

## 可證偽觀察清單

1. **3D-native WAM 的 head-to-head**：未來 2 週內，若出現 ≥1 篇把 UNITAS 型（metric point-trajectory）與 2D-latent WAM（Token-World / Long-WAM / Being-M0.7 一脈）在**同一 benchmark、同一 embodiment、真機 episode > 1000** 上做對照、並附表徵 ablation 的工作，且 3D-native 有**非邊緣**優勢 → 驗證 §13.6「技術收斂」註記；若只繼續累積 "first" 標題而無對照 → **推翻**，Bear 勝。錨定：§13.6。
