# FLOAT Drone 面向物理交互：侧向气流抑制、力旋量建模与自适应控制 (FLOAT Drone for Physical Interaction: Lateral Airflow Reduction, Wrench Modeling, and Adaptive Control)

> **发布时间**：2026-07-05 (arXiv:2607.04260v1 [cs.RO])，投稿于 IEEE RA-L / T-RO 类机器人期刊（原文未明确刊物名）
> **论文 / 模型名**：FLOAT Drone（fully actuated coaxial UAV with servo-driven control surfaces）
> **核心定位**：用「同轴双旋翼 + 桨流里的伺服控制舵面」实现 6-DoF 全驱动，既避免机身/桨轴倾斜，又把指向目标方向的侧向气流大幅压低（力匹配 CFD 下质量流量 −58.5%、法向动量通量 −49.4%），并用辨识出的二阶多项式气动力模型 + 非线性分配器 + ℒ₁ 自适应把接触交互精度推到 2 cm 间隙插钩拉抽屉。

一句话导语：近距空中物理交互要求平台同时做到「多维力旋量解耦 / 机身紧凑 / 生成水平力时不把气流吹向目标」——传统全驱方案靠倾斜桨轴或倾斜机身来产生水平力，会把旋翼尾流顺带导向目标造成气动干扰。本文把控制舵面放进桨流里产生侧向力，用高保真气动模型 + 非线性分配 + ℒ₁ 自适应证明这套硬件+控制组合能兼顾紧凑、精度与抗扰。

---

## X-Ray 开场

**问题**：传统多旋翼欠驱动，产生水平力必须倾斜机身 → 力控与姿态耦合；全驱方案（固定倾斜/可变倾斜桨轴）虽然解耦，但体积大、机构复杂，且水平力由桨推力侧向分量产生，会把旋翼诱导气流吹向交互目标。

**提出**：FLOAT Drone = 同轴双旋翼（提供竖直力 F_z 与偏航力矩 τ_z）+ 四片浸在同轴桨流里的伺服舵面（提供水平力 F_x/F_y 与滚转/俯仰力矩 τ_x/τ_y）。配套：力匹配 CFD 基准证明气流优势、精密测力辨识的二阶多项式气动旋量模型、带饱和约束的非线性最小二乘分配器（CasADi+IPOPT，C 代码上机）、SE(3) 几何控制 + ℒ₁ 自适应补偿。

**对 spatial AI / 机器人研究者意味着什么**：这是一篇「本体机构 → 气动模型 → 分配 → 鲁棒控制 → 交互任务」的完整系统级论文，核心启发是——**当机构带来强非线性耦合时，把辨识出的非线性模型直接嵌进控制分配（而非只做反馈补偿）能以极小算力代价换来数量级的误差下降**（3D 跟踪位置 RMSE 49.7mm→13.8mm，姿态转换 180.2mm→11.0mm）。它不是感知/VIO 论文，而是「把动力学当先验塞进实时优化」的工程范式样本。

### 1.2 关键机制

**⚡ Eureka Moment：把「控制舵面塞进同轴桨流」——桨轴保持竖直，主尾流保持向下，只在舵面局部偏转尾流来产生水平力，于是水平力的产生不再需要把整个桨盘气流导向目标。**

配套的第二洞见：内部桨-舵耦合使执行器→旋量映射强非线性且与推力损失耦合，因此**不把它当扰动交给反馈器去压，而是辨识成多项式模型、直接写进带约束的分配优化里**；再用 ℒ₁ 自适应补掉模型残差、地效、载荷突变与接触力。

## 2 · 数学核心

📌 **Napkin Formula**：**期望旋量 → 在饱和约束下反解执行器指令，用一个辨识出的非线性多项式模型当"正向映射"**：

$$\mathbf{u}^\star=\arg\min_{\mathbf{u}}\left\|\hat{\mathbf{w}}_{\rm aero}(\mathbf{u})-\mathbf{w}_c\right\|_2^2 \quad \mathrm{s.t.}\ \mathbf{u}_{\min}\le\mathbf{u}\le\mathbf{u}_{\max}$$

**目标**：上层控制器只给「要多少力/力矩」（w_c），需要把它翻译成 6 个执行器指令（2 个油门 + 4 个舵偏），且这个过程必须实时、保饱和、能反映非线性耦合。

**公式链（从动力学到分配器）**：

刚体动力学（式 3）：
$$m\ddot{\mathbf{p}}=m\mathbf{g}+\mathbf{R}\mathbf{T}_B,\qquad \mathbf{J}\dot{\bm{\omega}}=-\bm{\omega}\times\mathbf{J}\bm{\omega}+\bm{\tau}_B$$

定义体轴系气动旋量（式 4）：$\mathbf{w}=[\mathbf{T}_B^T,\bm{\tau}_B^T]^T$

气动模型（式 5–6）：每个分量用裁剪后的二阶多项式
$$\hat{w}_i(\mathbf{u})=\sum_{k=1}^{M_i}c_{ik}\phi_k(\mathbf{u}),\quad i=1,\dots,6$$

分配（式 8）：上面 Napkin 公式。

几何控制（式 9–13）：
$$\ddot{\mathbf{p}}_d=\ddot{\mathbf{p}}_r+\mathbf{K}_v\!\left(\dot{\mathbf{p}}_r+\mathbf{K}_p(\mathbf{p}_r-\mathbf{p})-\dot{\mathbf{p}}\right),\quad \mathbf{T}_d=m\mathbf{R}^T(\ddot{\mathbf{p}}_d-\mathbf{g})$$
$$\mathbf{R}_e=\tfrac{1}{2}\left(\mathbf{R}_r^T\mathbf{R}-\mathbf{R}^T\mathbf{R}_r\right)^{\vee},\quad \bm{\omega}_d=\mathbf{K}_R\mathbf{R}_e,\quad \bm{\omega}_e=\bm{\omega}_d-\bm{\omega}$$

ℒ₁ 自适应（式 14–20）：
$$\dot{\mathbf{z}}=\mathbf{f}(\mathbf{z})+\mathbf{B}(\mathbf{R})(\mathbf{w}_c+\bm{\sigma}),\quad \mathbf{f}(\mathbf{z})=\begin{bmatrix}\mathbf{g}\\-\mathbf{J}^{-1}(\bm{\omega}\times\mathbf{J}\bm{\omega})\end{bmatrix},\quad \mathbf{B}(\mathbf{R})=\begin{bmatrix}m^{-1}\mathbf{R}&\mathbf{0}\\\mathbf{0}&\mathbf{J}^{-1}\end{bmatrix}$$
$$\dot{\hat{\mathbf{z}}}=\mathbf{f}(\mathbf{z})+\mathbf{B}(\mathbf{R})(\mathbf{w}_c+\hat{\bm{\sigma}})+\mathbf{A}_s(\hat{\mathbf{z}}-\mathbf{z}),\quad \tilde{\mathbf{z}}=\hat{\mathbf{z}}-\mathbf{z}$$
$$\hat{\bm{\sigma}}(iT_s)=-\mathbf{G}(\mathbf{R}(iT_s))\bm{\Phi}^{-1}\bm{\mu}(iT_s),\quad \mathbf{G}=\mathbf{B}^{-1},\ \bm{\mu}=e^{\mathbf{A}_sT_s}\tilde{\mathbf{z}},\ \bm{\Phi}=\mathbf{A}_s^{-1}(e^{\mathbf{A}_sT_s}-\mathbf{I})$$
$$\mathbf{w}_{\mathcal{L}_1}(s)=-\mathbf{C}(s)\hat{\bm{\sigma}}(s),\qquad \mathbf{w}_c=\mathbf{w}_d+\mathbf{w}_{\mathcal{L}_1}=\mathbf{w}_d-\mathbf{C}(s)\hat{\bm{\sigma}}(s)$$

**变量说明**：m 质量、J 惯量、R 姿态、ω 体角速度、z=[ṗ,ω] 速度级状态（ż 含加速度，**仅用于动力学模型，不作测量输入**）、σ 体轴系等效集总扰动旋量（含外力、载荷变化、分配残差、未建模气动）、C(s) 对角低通且 C(0)=I。

**直觉**：ℒ₁ 的核心是「快自适应 + 慢补偿」分离——用预测器误差把不匹配的加速度反解成等效扰动力旋量（快），再用低通滤波后才作用到控制输入（防止高频估计噪声直接注入）。负号表示补偿与扰动反向。

## 3 · 带数字走一遍（玩具设定，用于说明机制，非论文实测）

**玩具场景**：假设舵面侧向力随舵偏 δ 的真实关系是一条在 40° 达峰、之后下降的曲线（论文 CFD 观察到峰值约在 40°）。用一个极简抛物线代理：$F_x(\delta)=a\,\delta(80^\circ-\delta)$，令 a 使 δ=40° 时 F_x=5 N。

- **线性分配器（LCA）**：假设 $F_x\propto\delta$，标定点 δ=20°↔2.5 N，斜率 0.125 N/°。若上层要 F_x=5.5 N，线性解会命令 δ=44°。
  - 实际代入抛物线：$F_x(44^\circ)=a\cdot44\cdot36$。由 δ=40° 定标 $a=5/(40\cdot40)=0.003125$，得 $F_x(44^\circ)=0.003125\times44\times36=4.95\ \mathrm{N}$。
  - **结果：越要越给不出**——线性分配误以为加大舵偏就有更大侧向力，实际已经越过峰值、力在下降，还额外带来更大推力损失与力矩耦合。
- **非线性分配器（NLCA）**：同一目标 F_x=5.5 N，模型知道 5 N 是 δ∈[0°,80°] 内的可达上界（峰值 5 N），带饱和约束的最优解会卡在 δ=40°，剩余 0.5 N 缺口交给 ℒ₁ 自适应在力旋量层面补偿（若物理上确实无法产生，则表现为稳态误差被最小化，而非盲目加大舵偏）。
- **玩具结论**：在 40° 之后，**线性模型的梯度符号都是错的**。这正是论文报告 NLCA 相比 LCA 大幅降低位置/高度误差（3D 跟踪最大 z 误差 97.3mm→61.2mm）的机制来源。

> 注：以上抛物线、标定点、斜率均为演示性编造，仅用于说明"峰值型非线性使线性分配失效"这一机制；论文真实的力-舵偏曲线见其 CFD 图（δ 从 0° 扫到 90°，峰值约 40°），R²>0.93 的多项式拟合结果为其真实模型。

**Trade-off 分析**：

- **算力 vs 精度**：分配器用裁剪后的二阶多项式（去掉不显著项）+ C 代码生成 + 热启动，才把平均求解压到 2.95 ms，勉强满足 100 Hz（10 ms 周期）。若换成更高阶模型或在线辨识，实时性会崩。**这是本文工程可行性的关键约束**。
- **力域 vs 紧凑**：同轴双桨换来小水平尺寸，但代价是水平力只能靠舵面，最大 5.42 N ≈ 0.3 倍自重——**力域明显受限**，因此论文演示只能做轻量抽屉推拉而非重载操作。
- **气流优势 vs 效率损失**：舵面侧向力伴随竖直力损失（thrust loss）与舵面力矩，是"用效率换解耦 + 低侧向气流"。
- **论文未报告**：分配器求解的峰值功耗/CPU 占用；控制回路中 ℒ₁ 模块的单独耗时；端到端感知-控制延迟。

## 5 · 数据与评测

**实验环境**（论文 §VI-A）：全部实验在**室内动捕（motion-capture）环境**中完成；机载估计器融合 IMU 与动捕测量；控制器 100 Hz 机载运行。

**对比的四种控制器配置**：
1. **LCA** — 线性控制分配
2. **L1-LCA** — ℒ₁ 自适应 + 线性分配
3. **NLCA** — 非线性控制分配
4. **Proposed** — ℒ₁ 自适应 + NLCA（同车、同执行器限幅、同反馈增益）

**评测项与结果（数字逐字取自论文）**：

- **CFD 力匹配对比**（§III-C）：同 8-inch 三叶桨；舵面 200mm×100mm×2mm，中心在桨轴上、桨心下方 100mm；测量平面距桨轴 120mm；桨速固定 10000 rpm；δ 从 0° 到 45°，步长 5°；最大力匹配误差 <0.5%；代表性工况 F_x/F_z=0.35。非零侧向力工况（δ=10°~45°）平均**目标朝向质量流量降低 58.5%、法向动量通量积分降低 49.4%**。
- **桨-舵耦合 CFD**（§IV-B）：桨速 10000 rpm，~10 N 推力，−0.15 N·m 桨力矩；δ 从 0° 扫到 90°；侧向力在约 **40°** 达峰后下降；竖直力损失随舵偏增大。
- **气动模型辨识**（§IV-C）：油门 40%–60%、舵偏 0°–45°；F_z 与 τ_z 约 **600 个稳态样本**；水平力只辨识 x 轴，y 轴由几何对称得到；微分测量法分离上下舵面贡献；拟合 **R²>0.93**。

- **悬停姿态转换（±20° 俯仰切换）**：LCA 180.2 / 1.40 / 297.6；NLCA 65.4 / 1.07 / 103.6；Proposed 11.0 / 1.00 / 26.0（Pos. RMSE mm / Att. RMSE deg / Max \|e_z\| mm）。

- **突加载荷（Table III）**：磁吸 100g / 200g。100g 时四配置均成功；200g 时 **LCA 与 NLCA 失败**，L1-LCA 与 Proposed 保持稳定。Proposed 相对 L1-LCA 把最大 z 误差从 **122.0mm→34.7mm**。
- **长时悬停（§VI-D3）**：两分钟段，平均高度误差从 **−55.1mm→−3.33mm**。
- **抽屉操作演示**（§VI-E）：侧装 3D 打印钩子，手柄-前面板间隙仅 **2 cm**；全程最大姿态偏差 **3.41°**，离轴跟踪误差在 **12.2mm** 内。

> 说明：论文未给出任何公开数据集名称——所有评测均为自建实验（CFD + 室内动捕飞行 + 测力台架），无 benchmark 数据集。

## 6 · 能力与失败模式

**能做**：
- 在几乎不倾斜机身（滚转/俯仰 <2.3°）的情况下产生最大 5.42 N 水平力（≈0.3 倍自重）；欠驱动多旋翼要达到同样水平力需约 17° 机身倾斜。
- 6-DoF 全驱飞行的轨迹与姿态解耦跟踪（8 字轨迹位置 RMSE 13.8mm）。
- 拒绝地效、突加载荷、长时漂移等扰动（两分钟悬停平均高度误差 −3.33mm）。
- 2 cm 间隙内插钩、拉、推抽屉（最大姿态偏差 3.41°，离轴误差 ≤12.2mm）。

**不能做 / 失败模式**：
- **力域受限**：最大侧向力仅 5.42 N，无法做重载交互；论文演示只针对轻量抽屉。
- **末端执行器单一**：仅侧装 3D 打印钩子，作者自述非通用末端执行器、非自主任务执行。
- **依赖室内动捕**：状态估计器融合 IMU + 动捕，未展示纯机载（无外部定位）下的闭环性能。
- **模型只在窄工作域有效**：气动多项式仅在油门 40%–60%、舵偏 0°–45° 内辨识；超出该包络属于外推。
- **仅 x 轴力被实验辨识**：y 轴力靠对称假设导出。
- **接触力无传感**：不做力/力矩传感，接触载荷作为 ℒ₁ 集总扰动被"吸收"，本身不估计接触力大小。

### 隐含假设 (Hidden Assumptions)

1. **静态/准静态气动假设**：高保真气动模型由**静态测力**辨识（§IV-C），假设稳态推力-舵偏关系足以描述飞行中的气动旋量；瞬态/非定常气动效应（快速姿态转换、接触冲击）未建模，只能靠 ℒ₁ 当集总扰动去压。
2. **几何对称假设**：y 轴由 x 轴对称得到；滚转/俯仰力矩按"标称力旋量生成几何"（上下舵面竖直力臂）计算，而非直接测量——制造不对称/舵机零位偏差会破坏该假设。
3. **奇对称假设**：分离上下舵面贡献时假设 $F(\delta)\approx-F(-\delta)$（式 7）。
4. **ℒ₁ 匹配不确定性假设**：扰动被建模为体轴旋量通道内的集总匹配不确定性 σ（式 14），且分段常值（式 17）在单个自适应间隔内成立。
5. **状态可用假设**：ż 含加速度，**仅用于模型不作测量**；实际需要滤波器/微分求加速度，假设其足够干净。
6. **外部定位假设**：实验依赖室内动捕，隐含假设真实部署中也可获得高精度外部或高精度机载定位。
7. **增益一致性假设**：四配置比较时"同车、同执行器限幅、同反馈增益"，隐含假设对比对每个配置都公平（但未报告各配置增益具体数值）。

## 7 · 与相关工作对比

| 维度 | 固定倾斜桨轴 [10-12] | 可变倾斜桨轴 [13-17] | 本文 FLOAT Drone |
|---|---|---|---|
| 全驱实现 | 预设桨安装角 | 飞行中主动倾斜桨/云台 | 桨轴不动，靠桨流内伺服舵面 |
| 悬停效率 | 低（部分推力抵消） | 较高 | 同轴双桨推力功耗比高 24% |
| 体积/复杂度 | 需大桨距、体积大 | 额外舵机/倾斜机构，质量↑ | 紧凑（水平外接圆 ~312mm），仅加舵面 |
| 指向目标的侧向气流 | 存在 | 存在（桨推力侧向分量/桨流重定向） | 力匹配 CFD 下质量流量 −58.5%、法向动量通量 −49.4% |
| 控制方法 | 常规 | 常规/几何 | SE(3) + ℒ₁ 自适应 + 非线性分配（无额外力/力矩传感） |
| 力域 | 大（多桨） | 大 | 受限（5.42 N ≈ 0.3 倍自重） |

**控制侧对比**：SE(3) 几何控制 [18,19] 提供无奇异的坐标无关跟踪但不显式补偿扰动；阻抗/力控 [20,21] 常需力传感；DOB [22-24] 受估计带宽 vs 噪声灵敏度折衷；INDI [25,26] 需可靠加速度估计与执行器状态反馈；数据驱动 [27] 需高质量仿真或大量离线训练。本文选 ℒ₁ 是因为它**把快自适应与鲁棒控制用低通滤波分离，无需额外力/力矩传感器**即可快速估计扰动又不注入高频噪声。

**面试 Tip**（被问到"这篇和现有全驱方案的本质区别是什么？"时怎么答）：
> 不要只答"它用舵面不用倾斜"。要答三层：① **机构层**——桨轴竖直 + 舵面局部偏转尾流，主尾流保持向下，所以生成水平力时不会把桨流导向目标（力匹配 CFD 下质量流量 −58.5%）；② **建模层**——舵面在桨流里导致强非线性与推力损失耦合，传统"线性分配 + 反馈补偿"不够，必须辨识非线性模型并**前置**进分配器（3D 跟踪最大 z 误差 97.3→13.5mm）；③ **鲁棒层**——模型残差/地效/载荷/接触力不建模为独立项，而是统一为体轴集总扰动 σ 交给 ℒ₁（200g 突加载荷下 LCA/NLCA 直接失败，带 ℒ₁ 的配置存活）。代价是**力域受限**（5.42 N）与**依赖动捕/室内条件**。

## 8 · GitHub-validated pitfalls (atlas 联动, 2026-09-20)

**官方 repo 状态核查**：论文正文中**未给出任何 github.com 链接**（arXiv HTML 页面出现的 "Report GitHub Issue" 是 arXiv 平台模板 UI 按钮，非论文代码仓库）。因此**无官方 repo、无 issue 流可供验证**。以下 3 条 pitfall 由 §6 失败模式 + 方法约束**推导**（未经 issue 验证），标注为推断。

1. **y 轴力靠对称假设 → 实机不对称导致横向偏置与滚/偏航交叉耦合**
   - 诚实性前提：论文 §IV-C 明写"只辨识 x 轴力，y 轴由车辆几何对称得到"。
   - 机制：真实装配的舵机零位/结构公差不对称时，y 通道的模型不反映真实映射，分配器给出的 y 力与滚/俯仰力矩会系统性偏离；而分配器**没有多余的映射冗余**去在线纠正（6 执行器 ↔ 6 自由度，恰好方阵附近）。
   - 后果：水平悬停会缓慢漂移，接触推拉时横向力偏置直接表现为目标面向误差。复现时应先做 y 通道单独测力标定，而非直接采信对称假设。（推断，未在 issue 验证）

2. **气动多项式外推失效 → 超出 40%–60% 油门 / 0°–45° 舵偏包络时分配解错误**
   - 诚实性前提：模型辨识工作域为油门 40%–60%、舵偏 0°–45°（§IV-C）；约束式（8）中的 u_min/u_max 由作者设定。
   - 机制：二阶多项式在包络内 R²>0.93，但**多项式外推无物理约束**——若 u_min/u_max 未严格卡在辨识包络内，分配器在大力需求（如用力推不动的东西、需要 >5.42 N 的水平力）时会命令包络外的舵偏，模型给出错误甚至非单调的力预测。
   - 后果：接触场景下分配器可能在"舵偏越大预测力越大"的非物理区域里反复加舵偏，反而增大推力损失与姿态扰动。复现时务必把分配约束对齐辨识包络，并对超包络需求显式饱和。（推断，未在 issue 验证）

3. **静态辨识 + ℒ₁ 低通带宽 → 快速时变扰动（接触冲击）残留**
   - 诚实性前提：模型由**静态**测力辨识（§IV-C）；补偿经低通 C(s)（式 19）。
   - 机制：静态模型不含非定常气动；而 ℒ₁ 为抑制高频估计噪声用低通限制补偿带宽，快自适应与慢补偿的分工意味着**高于 C(s) 带宽的扰动分量会穿透**。突加载荷测试中 200g 下 Proposed 的最大 z 误差仍有 34.7mm（并非归零），即为此机制的定量体现。
   - 后果：与刚性环境高速碰撞/插入时，接触力脉冲可能短暂造成姿态/高度尖峰。复现交互任务时应留足姿态裕度，或额外加阻抗/力控外环（论文本身未做）。（推断，未在 issue 验证）
