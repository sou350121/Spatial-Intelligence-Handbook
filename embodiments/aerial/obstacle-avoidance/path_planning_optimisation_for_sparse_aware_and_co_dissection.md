# 稀疏感知协同网络化空中机器人团队（SpArC-NARTs）的路径规划优化：优化工具与地面感知覆盖用例
(Path Planning Optimisation for SParse, AwaRe and Cooperative Networked Aerial Robot Teams (SpArC-NARTs): Optimisation Tool and Ground Sensing Coverage Use Cases)

> **发布时间**：2026-07（arXiv:2602.14247v2 [cs.RO]，2026-07-18；投稿期刊 Robotics and Autonomous Systems）
> **论文 / 模型名**：**SpArC-NARTs**（Sparse, Aware, Cooperative Networked Aerial Robot Teams）
> **核心定位**：把"多机协同"从**硬约束（保连通 / 固定汇合时刻 / 欧氏距离通信半径）**换成**软奖励整形（VoM × CSI）**，让小队 UAV 在稀疏、间歇连通下既散开探索又自发汇合上报；比所有 cooperative baseline 的探索损失都更小。

**导语**：现有 NART 协同要么死守永久连通（小队被彻底捆死、动不了），要么用欧氏距离当"能不能通信"（完全无视电台参数与衰落）。本文做**离线**轨迹优化：用真实链路预算（Friis + 接收灵敏度）算出一个连续可导的连通度 CSI，再乘上随时间指数增长的"上报紧迫度" VoM，把协同写成奖励项塞进模拟退火的目标函数。结论是——协同必然损失一点探索性能（相对非协同 baseline），但**成对、稀疏、隐式**的协同能把探索损失压到 10% 量级，同时把上报延迟砍掉 90% 以上、群体态势感知从 19% 拉到 40–50%。

---

## 🔍 X-Ray 开场

它解决的问题：一支**只有 3 架 UAV**的小队，要在一片**远超其感知能力**的大区域里做地面感知覆盖/目标搜索，同时希望彼此能偶尔碰头交换情报——但既不能为了保连通而捆死，也不能假装"距离 &lt; R 就能通信"。

它提出的东西：一个**离线轨迹优化工具**，目标函数 = 时间折扣的 POC 收益 × (1 + Σ 协同奖励)，其中协同奖励 = `VoM(该上报了吗) × CSI(能通上吗)`；VoM 是**指数增长 + 交换后重置**的软紧迫度，CSI 是**基于 Friis 链路预算 + sigmoid 平滑**的 [−1,1] 连通度。协同是**逐时步、成对、隐式**产生的，不需要显式定义 meeting point、不需要调度、不需要指定谁当 relay。

对 spatial AI 研究者意味着什么：它给了一个**可直接抄的接口设计**——"通信可行性"应当被建模成一个**连续、带符号、可微的标量**，而不是布尔连通/固定半径；且这个标量与"任务紧迫度"相乘就构成可被任意黑箱优化器（这里是 SA，也可以是 RL/MILP）消费的整形项。同时也暴露了这种"乘性奖励"的**符号翻转隐患**（见 §8）。

### 1.2 关键机制

**⚡ Eureka Moment：把"协同"拆成"想不想报"×"能不能报"两个连续标量相乘——`C_i(s) = VoM_i(s) · CSI_i(s)`——于是硬性的汇合调度被降维成目标函数里一个可加、可导、可正可负的奖励项，SA 自己会发明出汇合行为。**

拆开看这个洞见为什么成立：

1. **VoM 被重写成时间的指数函数且带符号**（原 VoM 出自 [3]，是无符号的时间激励）：
   - 刚交换完 → `VoM ≈ -1`（**负值 = 罚**，此刻应该散开去探索）；
   - 久未上报 → `VoM` 指数上升，在 `s - s_i = τ` 时**恰好等于 +1**（正 = 奖）；
   - 过零点在 `s - s_i ≈ τ - T_sys·ln2`（见 §3 推导）——所以"罚 → 奖"的翻转发生在目标会合周期的临界点上，不是拍脑袋的常数。
2. **CSI 带符号且以 `c_min` 为中心**：`ERP ≥ c_min` → 正，`< c_min` → 负。于是"想报但报不了"= 正×负 = **负奖励（罚）**，逼 agent 往可通区域挪；"不想报且报不了"= 负×负 = **正奖励**，鼓励散开。四种符号组合正好对应 Fig.4 的四个象限，构成一个**高层行为环**（探索 ↔ 汇合 自动振荡，Fig.5 / Fig.15）。
3. **成对（pairwise）而非全局**：`CSI_i = max_j csi_ij`，任一邻居够得着就给奖励——彻底避开了"全员到齐"的刚性约束，这是它相对 Baseline B/C（global rendezvous + 固定间隔）探索损失更小的直接原因。

## 2 · 数学核心

### 📌 Napkin Formula

$$
\boxed{\;J=\sum_s e^{-\epsilon s}\,\mathrm{POC}_s(s)\cdot\Bigl(1+\sum_{i\in\mathcal{NART}}\underbrace{\mathrm{VoM}_i(s)}_{\text{该报了吗}}\cdot\underbrace{\mathrm{CSI}_i(s)}_{\text{能通上吗}}\Bigr)\;}
$$

**一句话直觉**：探索收益被"协同乘子"调制——协同乘子 > 1 时那些步的 POC 收益被放大，&lt; 1 时被压缩；SA 于是学会**在能通信的地方顺便采高 POC 的格子**，而不是专门跑去开会。

---

### 2.1 目标函数（Eq. 8）

**目标**：在有限能量下最大化"尽早采到高 POC 格子"，并顺带制造可通信的窗口。

$$
J=\sum_{s}e^{-\epsilon s}POC_{s}(s)\Bigl(1+\sum_{i\in\mathcal{NART}}C_{i}(s)\Bigr)
$$

| 变量 | 含义 |
|---|---|
| `s` | 时步（= 航点序号），上限 `max_path_len`（由能量决定） |
| `e^{-εs}` | 时间折扣：**早访问更值钱**（与 [6] 一致）。注意 ε 与 Eq.2 里的 ε **不是同一个量**（见 §8） |
| `POC_s(s)` | 第 s 步被探索者访问的格子的概率含目标度（期望覆盖增益） |
| `C_i(s)` | agent i 的协同奖励/惩罚 ∈ [−1, 1]（Eq.6 或 Eq.7） |

> 关键结构性事实：协同项是**乘性**的，它只能**调制**探索收益、不能独立产生探索激励；且当 `Σ C_i < -1` 时乘子变号（§8 会算给你看）。

### 2.2 协同项（Eq. 6 / Eq. 7）

$$
C_i(s)=VoM_i(s)\cdot CSI_i(s),\qquad
C_{i_{RB}}(s)=w_1 C_{i_{\mathcal{ETD}}}(s)+w_2 C_{i_{\mathcal{R}}}(s)
$$

| 变量 | 含义 |
|---|---|
| `VoM_i(s)` | agent i 上报紧迫度 ∈ [−1, 1]，负 = 罚（刚报完，去散开），正 = 奖（久未报） |
| `CSI_i(s)` | agent i 连通度 ∈ [−1, 1]，`CSI_i = max_{j≠i} csi_ij(s)`（最强的那条链路） |
| `w1 / w2` | 对"探索型同伴"与"上报型同伴（EE）"两套 VoM/CSI 的权重（仅 M-EE2 用 role-based） |
| `𝒯`(ETD) / `ℛ` | 探索/目标检测组、上报组 |

**直觉**：`w1=0, w2=1` → 只汇报给外部实体（S-EE 用例）；`w1=1, w2=0` → 只做机间协同（MUG 用例）；`0.3/0.7` → 偏重向 M-EE 汇报（M-EE 用例）。

### 2.3 上报紧迫度 VoM（Eq. 5）

$$
VoM_i(s)=\begin{cases}
\dfrac{2e^{\frac{s-s_i}{T_{sys}}}-1}{e^{\frac{\tau}{T_{sys}}}-1}-1, & s-s_i\le \tau_i\\[6pt]
1, & \text{otherwise}
\end{cases}
\qquad \tau_i=\frac{lifetime_i}{n_{meetings}}
$$

| 变量 | 含义 |
|---|---|
| `s_i` | agent i **上次成功数据交换**的时步 |
| `τ_i` | 允许的最大会议间隔（软约束），`lifetime_i` = 该机航点总数（≈ 能量上限） |
| `n_meetings` | 用户给的**参考会议次数**（本文 = 4） |
| `T_sys` | VoM 更新周期（本文 = 1，即时步级） |

**为什么是这个式子**：它由三条要求反解出来的——(a) 单调指数增长；(b) 交换后重置到最小；(c) 输出带符号的软约束。系数 `2/(e^{τ/T_sys}-1)` 被刻意选成让 `VoM(τ) = 1` **恰好**（见 §3 验算），于是 `n_meetings` 成为一个**语义清晰**的旋钮：调大 = 更频繁的上报激励，调小 = 更稀疏的会面。

### 2.4 通信模型 CSI（Eq. 2 + Alg. 1）

链路预算（Friis，各向同性）：

$$
ERP_{ij}(s) = P_t + G_t + G_r - \bigl[20\log_{10}d_{ij} + 20\log_{10}f + 20\log_{10}(4\pi/c)\bigr]\ \ [\mathrm{dBm}]
$$

平滑成连续可导的连通度：

$$
csi_{ij}(s)=\frac{k\bigl(ERP_{ij}(s)-(c_{\min}-\varepsilon)\bigr)}{1+\bigl|k\bigl(ERP_{ij}(s)-(c_{\min}-\varepsilon)\bigr)\bigr|}
$$

| 变量 | 值 / 含义 |
|---|---|
| `c_min` | 接收灵敏度 = `-73 [dBm]`——**用它替代"距离阈值"作为连通判据** |
| `k` | `0.4`，控制 sigmoid 陡度（越大越接近硬阶跃） |
| `ε` | `1E-6`，把过零点从 `c_min` 微移，使 `ERP = c_min` 时 `csi ≈ 0` |
| `Pt` | `0.100 [W]` = 20 dBm；`Gt = Gr = 1`（0 dBi） |
| `f` | `2.4E9 [Hz]`；`n = 2`（自由空间路径损耗指数） |

**直觉**：这就是把 `csi = tanh`-类的软阶跃套在链路预算上。它的输出不是一个"能不能"的布尔值，而是"**离通得上还有多少余量**"——正值越大余量越足，负值越负越绝望。这一点是全文最可复用的设计（见 §7 面试 Tip）。

## 3 · 带数字走一遍（玩具设定，用论文真参数）

### 3.1 用论文参数反推通信半径（验证 445 m）

取 `f = 2.4 GHz`、`c = 3E8`：

$$
20\log_{10}f+20\log_{10}(4\pi/c)=187.60-147.56=40.04\ \mathrm{dB}
$$

所以 `FSPL(d) = 20log₁₀d + 40.04`。发射 20 dBm，令 `ERP = c_min = -73 dBm`：

$$
20-20\log_{10}d-40.04=-73 \Rightarrow 20\log_{10}d=52.96 \Rightarrow d \approx 444.8\ \mathrm{m}
$$

✅ 与论文 Table 4 说明的"`approximately 445 [m]`"吻合——**这条链路预算是自洽的**，可以放心复用。

### 3.2 CSI 数值表（`k = 0.4`, `ε = 1E-6`）

令 `u = k(ERP - (c_min - ε))`，则 `csi = u/(1+|u|)`：

| `d` [m] | FSPL [dB] | `ERP` [dBm] | `u` | `csi` |
|---|---|---|---|---|
| 50 | 74.0 | −54.0 | +7.60 | **+0.88** |
| 100 | 80.0 | −60.0 | +5.20 | **+0.84** |
| 200 | 86.1 | −66.1 | +2.78 | **+0.74** |
| 380 | 91.6 | −71.6 | +0.58 | **+0.37** |
| **445** | 93.0 | **−73.0** | ≈ 0 | **≈ 0（过零点）** |
| 600 | 95.6 | −75.6 | −1.04 | **−0.51** |
| 900 | 99.1 | −79.1 | −2.45 | **−0.71** |

**读法**：从 +0.84（100 m）掉到 −0.51（600 m）只跨了 500 m，且 90% 的动态范围集中在 `ERP ∈ [-79, -66] dBm`（约 ±6.5 dB）内。这是一个**非常陡的软阶跃**——`k=0.4` 时半衰点（`csi=0.5`）出现在 `ERP ≈ -71.75 dBm`，即 `d ≈ 384 m`。

### 3.3 VoM 的时间演化（`lifetime ≈ 86`、`n_meetings = 4`、`T_sys = 1`）

$$
\tau = 86/4 = 21.5 \Rightarrow e^{\tau/T_{sys}}-1 = 2.1995\times10^{9}
$$

| `s - s_i` | 分子 `2e^{x}-1` | `VoM` | 含义 |
|---|---|---|---|
| 0（刚交换） | 1 | **−1.000**（下界） | 强罚：立刻散开 |
| 10 | 2.4E4 | **−1.000** | 罚仍在饱和区 |
| 20.81（=`τ − ln2`） | 2.2E9 | **0.000** | 零点：从"该散"翻到"该报" |
| 21.5（=`τ`） | 4.4E9 | **+1.000**（上界） | 与推导一致，`VoM(τ)=1` 精确成立 |
| > 21.5 | — | **+1.000**（截断） | 长期不报，保持满额激励 |

**验算关键点**：`VoM(τ)=1` 是**恒等式**而非巧合——`(2e^τ - 1)/(e^τ - 1) = 2 - 1/(e^τ-1) ≈ 2`，减 1 后正好 1。这解释了为什么 `n_meetings` 是个"可解释旋钮"：它直接定义了"从罚到奖"的完整时间跨度。

### 3.4 三步协同项的符号演练（A = 3）

| 情形 | `VoM_i` | `CSI_i` | `C_i = VoM·CSI` | 行为解读 |
|---|---|---|---|---|
| 刚交换完 + 已散开到 600 m | −0.9 | −0.51 | **+0.46** | 正奖励 = "散开是对的" ✅ |
| 久未报 + 靠近到 100 m | +0.95 | +0.84 | **+0.80** | 正奖励 = "现在开会是对的" ✅ |
| 久未报 + 仍在 900 m 外 | +0.95 | −0.71 | **−0.67** | 罚 = "想报却报不了"，逼它挪向可通区 ✅ |
| 刚交换完 + 又贴到 100 m | −0.9 | +0.84 | **−0.76** | 罚 = "刚聊完还赖着" ✅ |

四象限与 Fig.4 完全对齐。**但注意最后一行 × 3 架同时发生**：`Σ C_i = -2.28`，乘子 `1 + Σ C_i = -1.28` → **探索收益变负**。这是 §8 的核心 pitfall。

**部署约束的真实 trade-off**（这部分论文说了，可以直接引用）：

1. **离线 vs 在线的取舍**：作者明确把在线重规划列为 future work。工具输出的是一条**标称轨迹**，一旦先验 POC 错了或某机中途失效，计划无自愈能力（§6 隐含假设）。
2. **`n_meetings` 是"探索 ↔ 上报"的总开关**：调大 → 更频繁奖励、运动受限、覆盖下降；调小 → 更自由、上报延迟上升。论文只给了 `n_meetings=4` 这一个点，**未报告敏感度曲线**。
3. **`k` 是"通信判定硬度"的开关**：`k=0.4` 给出肉眼可见的软过渡；`k` 增大即退化为硬阶跃，reward 梯度信息消失，SA 的探索能力下降。论文未做 `k` 的消融（**论文未报告**）。
4. **`w1/w2` 是角色调优旋钮**：Table 5 显示 `w1=0.7/w2=0.3` 时 `EE` 与 `TPOC` 最优，`w1=0.3/w2=0.7` 时 `EP` 最优但 `ETR` 从 `31.33` 冲到 `71.3`；`w2=1` 则轨迹被过度约束（`EE` 掉到 `0.2187`）。工程上**必须做这套扫描**，不能取默认。
5. **一个隐藏成本**：M-EE 的路径和能量**不进优化**（Alg.3 固定绕周界 + clip/extend 到 `max_path_len`），EE 被假设"能量充足"。这意味着异构方案的实际部署成本被低估（论文未讨论 EE 的能量预算）。

## 6 · 能力与失败模式

### 6.1 能做（有证据支撑）

| 能力 | 证据 |
|---|---|
| **小队（3 机）、大环境下保持探索 + 偶发协同** | MUG 相对 Baseline A 的探索损失仅 9.9%/13%/15.2%（Env A），Env B 降到 6.7%/7.12%/6.55% |
| **把上报延迟压一个量级** | M-EE 方案 "reducing reporting latency by over 90% compared to the Baseline A" |
| **态势感知翻倍** | 单体 19% → 群体 40–50%（M-EE2 / MUG / M-EE1，Env A） |
| **把"连通"参数化到具体电台** | 445 m 半径由 `Pt/c_min/f/Gt/Gr/n` 反解得出（§3.1 已验算自洽）；换电台只改参数表，不改代码结构（模块化三步流水线） |
| **同构 / 异构统一** | 同一 `J` 通过 `w1/w2` 覆盖 MUG、S-EE、M-EE1、M-EE2 四种编成 |
| **自动涌现角色分工** | 无硬编码角色；`VoM` 于探索↔上报之间"desynchronised pattern"地切换（Fig.15a） |

### 6.2 不能做（明确的能力边界）

- **不能在线重规划**：本文只做离线；作者把"用交换机会触发 replanning"放在 conclusion 的 future work。所以它**不解决**动态障碍、目标移动、先验错误。
- **不能保证连通**：`c_min` 是软判据，`EIK` 在 S-EE 用例只占 `ETAK` 的 45%——**信息不保证传遍全队**。要全员一致就得用 Baseline B/C 那种全局汇合，代价是探索崩掉（`EP` 落后 32%/18.89%）。
- **不能处理多跳**：只算直接成对链路（`CSI_i = max_j csi_ij`），无 relay chain。作者在 related work 里把 relay/data mule 作为**替代路线**讨论，但本文工具不建模多跳。
- **不能处理连续动力学**：只在相邻格中心间跳，`ψ` 只用于能量代价，不做姿态/加速度约束。
- **小环境失效**：`V ≫ A³` 是复杂度论证的前提；若环境不比机群能力大，`C_i` 的空间约束会主导目标函数，"稀疏"前提破掉，行为退化为 Baseline B/C 式的挤在一起。

### 6.3 具体失败模式（每条都能对上一个机制）

| 失败模式 | 触发条件 | 机制根源 |
|---|---|---|
| **S-EE 放在低 POC 区 → 探索被拖死** | 静态实体位置差 | `w1=0, w2=1`，全部奖励指向 EE；论文逐字承认 "reporting exclusively to a static entity resulted in an increased UAV motion restriction when the entity is located in an area of low probability of containing a target" |
| **role-based loop 反而最差** | M-EE2 在 Goal 1 上垫底 | 双 `VoM` 放大了上报收益，`E` 的 gap 从 M-EE1 的 9.9% 恶化；`E` 带时间折扣，被"先去开会"挤掉了"先采高 POC" |
| **Env B（簇状先验）下协同收益反转** | 高 POC 区变小 | 轨迹本就收拢 → 全局汇合成本下降 → Baseline C 的 `ETR` 反超 M-EE2 46.97%；说明本文方法的优势**依赖于"环境大到必须先散开"** 这一前提 |
| **只优化连通度 → 覆盖崩溃** | 消融 Test 2 | `C_i` 对 `CSI` 单调 → 全员贴脸换满额；`EP` -43.33% |
| **只优化紧迫度 → 零上报** | 消融 Test 3 | `VoM` 单独无空间方向性，`EIK = 0` |
| **`Σ C_i < -1` 时目标函数符号翻转** | 3 机同时"想报但报不了" | 见 §8 P1 |
| **结果高方差** | `EP` 在 w 扫描中出现 `68.3 (± 21.22)`、`77.0 (± 3.46)`、`80.3 (± 1.54)` | 随机初始解 + 多线程 SA + 仅 3–5 trials；标准差可以**超过**被宣称的方法间差距 |

### 6.4 隐含假设（Hidden Assumptions）

1. **先验 POC 是对的，且全程不变**。`J` 里的 `POC_s(s)` 是固定的先验，不含任何"探索后更新 PoC"的贝叶斯项。→ 先验错 = 优化错，且离线无补救。
2. **一次时步完成一次完整数据交换**。原文："A data exchange, and therefore a rendezvous, is considered to occur in a single timestep `s`." → 无带宽限制、无丢包、无握手延迟、无部分同步。**`history_cell` 全量互换**在这个假设下才成立（`V×A` 个计数器的瞬时广播）。
3. **`pod` 与几何无关**。`pod = 63%` 是常数，不随高度、斜视角、驻留时间、地物变化。→ 实际部署中 `pod` 强烈依赖这些量。
4. **`P_detect = 1 - (1-pod)^v` 假设重复观测独立**。同一格被同一机看两次，用二项式叠加；忽略了相关误差（同一视角重复看不会真降不确定度）。
5. **Friis 有效**（`n = 2`，无遮挡、无多径、无阴影、各向同性天线）。论文承认可以通过把 `n` 调到 2–6 或加 log-normal shadowing 来近似建筑，**但 Table 4 固定 `n = 2` 且未加 shadowing**。→ 实际城区里 445 m 是**严重乐观**（§8 P3 会算）。
6. **EE 能量无限、路径固定**。Alg.3 用 Dijkstra 串 AoI 顶点绕周界，clip/extend 到 `max_path_len`；EE 不参与优化。→ 异构方案的真实成本被外部化。
7. **UAV 高度由索引决定**（`z_i = Δz_agent·(i+1)`，`Δz_agent = 2 m`）。这是**空域去冲突的替代品**，不是优化结果；机数一多（`A·2 m`）就不合理，且与真实空域规则无关。
8. **链路活跃 = 双方都还有电**。`link_active(agent_i, agent_j, s)`；一旦某机能量耗尽即退出 `𝒩𝒜ℛ𝒯`，但**离线计划并未为"中途损失一架"预留任何结构**。
9. **`Alg.2` 的 `max` 合并是正确的**。只有当每个计数器单调不减、且"最新信息"总是不小于旧信息时才成立；任何计数重置/回绕都会让 `v_{i,c,s}` 偏低 → `EAK/EIK` 系统性低估。
10. **`ε` 在两个地方指两个不同的东西**（Eq.2 的 `1E-6` 平滑偏移 vs Eq.8 的时间折扣系数），且 Eq.8 的 `ε` 数值**论文未报告**。

### 🎯 面试 Tip

被问"**为什么不用 RL / 不用 MILP，非要用模拟退火？**"这样答：

> "这是**离线一次性规划**问题，不是序贯决策问题——`J` 的梯度不可用（`POC_s(s)` 来自离散网格、`CSI` 里有 `max_j`、时间折扣让相邻步耦合），而候选解的评估成本是 `O(P·A³·V)` 级的黑箱。MILP 需要把 `e^{-εs}` 和 `sigmoid` 线性化，且 `VoM` 本身依赖 `s_i`（上次交换时刻）形成**路径依赖**，线性化后要么丢掉反馈结构、要么规模爆炸。SA 在这个场景有三个实际优势：(1) 与单机 IPP 的既有实现（[6] 的 Attraction 初始解 + 条件接受）**共用代码**，可以直接做消融；(2) 乘性奖励项的符号翻转（`Σ C_i < -1`）会让梯度类方法直接崩，但 SA 的条件接受对局部负值有容忍；(3) 多起点 + 15 线程能覆盖非凸性。**但**要老实承认代价：多线程随机初始解导致结果不可复现，论文里 `EP` 的标准差能到 ±21.22，比它宣称的方法间差距还大——这是这套方法最该被批评的地方。"

若被追问"**那你会怎么改？**"：把 `VoM` 的状态空间（`s_i`、`history_cell` 合并）交给 MARL 做在线策略，离线 SA 只产出**先验/课程**——这恰好是作者自己在 conclusion 里写的 future work。

## 8 · GitHub-validated pitfalls (atlas 联动, 2026-10-26)

> **溯源说明**：论文全文（arXiv:2602.14247v2）中**未出现任何 `github.com` 链接**，也未给出代码/数据仓库地址、commit 或 issue 编号。因此本节**无法做 issue 级验证**：以下 4 条 pitfall **全部由 §6 的失败模式 + §1/§2 的方法约束机械推导**，未经社区验证。凡涉及实现细节者均为**结构性推断**，落地前必须自查。

### P1 · 乘性奖励在 3 机同时"想报但报不了"时让目标函数变负

- **失败模式来源（§6.3）**：`Σ C_i < -1` 时探索收益变负。
- **方法约束来源（§2.1 + §2.2）**：`J = Σ e^{-εs} POC_s(s) · (1 + Σ C_i)`，其中 `C_i = VoM_i·CSI_i`，`VoM ∈ [-1,1]`、`CSI ∈ [-1,1]`。
- **机制**：`C_i` 的理论下界是 `-1`（`VoM→+1` 且 `CSI→-1`，即"最想报 × 最通不上"）。3 机同处此状态 → `Σ C_i = -3` → 乘子 `= -2`。**此时访问高 POC 格子反而降低 `J`**，SA 会学着在这几步"绕开"高价值格。
- **复现路径**：把 3 机全部置于远离 445 m 半径的三角位置，`n_meetings` 调小以拉长"想报"窗口，跑一次解，打印每步的 `(1 + Σ C_i)` 符号序列——预期出现成段负值。
- **修法**：`1 + Σ C_i` 换成 `exp(λ Σ C_i)` 或 `max(1 + Σ C_i, β)`（`β > 0`），牺牲一点表达力换符号安全性。**论文未讨论此风险**。

### P2 · `csi` 的连通判据在两处阈值不一致（`c_min` vs `0`）

- **失败模式来源（§6.4 假设 10 / §6.3）**：连通性判定与上报计数口径分裂。
- **方法约束来源**：
  - Eq.2 输出 `csi ∈ [-1, 1]`（**无量纲**）；
  - §3.3 正文："Link connectivity is thus associated with links with a `csi_ij ≥ c_min`"；
  - Eq.3 / Alg.1 / Fig.4：`CSI_i ≥ c_min`；
  - 但 Eq.13（`ETR` 的 `Rp_i(s)`）用的是 **`csi_ij(s) ≥ 0`**。
- **机制**：`c_min = -73`（dBm 量纲）被拿来跟无量纲的 `csi ∈ [-1,1]` 比较 → **字面实现时任何链路都"连通"**，`ETR` 爆炸、`C_i` 全正、退化成"无脑抱团"（即消融 Test 2 的病态行为，`EP` 崩 43%）。正确口径必然是 `csi ≥ 0`（对 `d ≲ 445 m` 成立）。
- **自查**：grep 代码里对 `c_min` 的所有引用，确认它**只出现在 Eq.2 内部**（作为 dBm 偏移），不进比较式。

### P3 · `n = 2`（Friis）让 445 m 半径在城区场景下乐观 ~20 倍

- **失败模式来源（§6.4 假设 5）**："Friis 有效，但 Table 4 固定 `n = 2` 且未加 shadowing"。
- **方法约束来源（§2.4）**：`ERP = Pt + Gt + Gr - [20log₁₀d + 20log₁₀f + 20log₁₀(4π/c)]`，指数由 `n` 参数控制（论文称可 2–6 近似建筑，但不做）。
- **机制（算术）**：把路径损耗改成 `n = 4`（城区典型）：`PL = 40.04 + 40log₁₀d`。令 `ERP = -73 dBm`（`Pt = 20 dBm`）→ `40log₁₀d = 52.96` → `d ≈ 21 m`。**445 m → 21 m，缩水约 21 倍**。
- **连锁后果**：`n = 2` 的模型会把 Baseline B 的 `10 m` 欧氏距离判为**过度保守**（真实 `n=4` 下 10 m 反而是合理的），从而**反转论文的核心结论**（"抽象电台参数会毁掉性能"）。这是全文最脆弱的一环。
- **自查**：任何部署环境先做路测标定 `n` 与 shadowing σ，再重跑优化；不要把 445 m 当配置常数抄走。

### P4 · 结果方差 > 被宣称的方法间差距（多线程 SA + 随机初始解 + 3–5 trials）

- **失败模式来源（§6.3 最后一行）**：`EP` 在 Table 5 出现 `68.3 (± 21.22)`、`77.0 (± 3.46)`、`80.3 (± 1.54)`。
- **方法约束来源（§1.1 / §4）**：SA 用 `15 threads` + "randomly generated initial configurations"（引 [28]）+ 每个设定仅 `3 trials`（w 扫描/消融）或 `5 trials`（用例）。
- **机制**：多线程 SA 的接受顺序不确定 → 同一超参两次运行的轨迹不同；同时初始解随机化进一步放大方差。把 `± 21.22` 与论文宣称的 MUG-vs-Baseline A 差距（`EP` 6.55%–15.2%）相比，**噪声大于信号**。Table 5 中 `w1=0.7/w2=0.3` 的 `EP = 68.3 ± 21.22` vs `w1=0.5/w2=0.5` 的 `77.0 ± 3.46`，从统计上无法判定优劣。
- **自查**：固定 seed 或固定初始解（只用 Attraction Algorithm，去掉 random init）做重跑对比；把 trials 提到 ≥ 20 再算置信区间；报告 per-trial 曲线而非仅 mean±std。
- **注意**：`Table 6` 的消融只有 `3 trials`，但标准差极小（`TPOC 33.66 ± 0.95`）——说明**消融用的是固定初始解**，而 Table 5 用了随机初始解。两组实验的可比性需要确认。
