# 面向随机对抗环境的多目标动力学规划 (Stochastic Multi-Objective Kinodynamic Planning Against Adversaries)

> **发布时间**：2026-07-21（arXiv:2607.19284v1 [cs.RO]）
> **论文 / 模型名**：SMO-RRT / SMO-SST（Stochastic Multi-Objective RRT / Stable Sparse RRT）
> **核心定位**：把概率约束（chance-constrained）动力学规划的搜索空间从"开环轨迹"换成"闭环策略序列"，用 Monte-Carlo 粒子 rollout 在树扩展里直接评估风险，从而消除开环风险传播在**反应式对手**面前的人为保守性，并给出有限样本风险证书。

已有 chance-constrained 动力学规划器把风险解析地传播到**开环标称轨迹**上：对静态障碍或非反应式高斯扰动可行，一旦对手会对 ego 状态做反应，开环估计就把约束违反概率**人为放大**，产出过度保守的路径。本文的结论是：只要把风险改成对闭环策略做粒子仿真，就能在保持概率保证的前提下拿到风险-代价双目标的 Pareto 前段；代价是单节点评估极贵、且剪枝版本丢掉完备性。

## X-Ray 开场

这篇论文要解决的是"ego 用闭环反馈飞行、对手（如追踪弹）会根据 ego 位置以一定概率从 Idle 切换到 Active"这类场景下的规划问题。它提出的做法是把规划解从一条轨迹改成**一串反馈策略 + 每段执行时长**，在树的每次扩展中让 256 个粒子按闭环动力学滚一遍，用存活粒子比例当风险估计、再用二项分布反解出风险上界 `q̄` 决定该节点能否入树。对 spatial AI 研究者的意义在于：它给出一条不依赖高斯/凸性假设的"采样式风险证书"路线——风险不再是协方差传播的产物，而是可被有限样本界定的仿真统计量。

### 1.2 关键机制

**⚡ Eureka Moment：风险不是轨迹的属性，而是"策略序列 + 执行时长"这一对变量的属性——所以把策略本身当作搜索空间的元素，用闭环粒子仿真在树里直接量它。**

配套的三个机制：

1. **策略序列即决策变量**。`(𝝅,𝒯) = ({π^(i)}_{i=1}^K, {τ^(i)}_{i=1}^K)`，`τ^(i)∈ℕ(1,τ_max)`，累积切换时刻 `T_k=Σ_{i≤k}τ^(i)`。执行时 `t∈[T_{k_t−1},T_{k_t})` 用 `π^(k_t)`。这样就允许"前段激进、后段保守"这种开环轨迹表达不出来的结构。
2. **粒子集是节点的状态**。每个节点 `v` 携带 `𝒫_v={y_v^(i)}_{i=1}^{N_parts}` 与空间坐标 `x=𝔼[h_x(𝒫)]`。风险估计就是 **存活计数**：`J_η = 1 − |𝒫_new|/N_parts`。粒子违反安全集 `x_{t+1}∉𝒮(ξ_{t+1})` 立即被剪，全灭则 `Ĉ=∞`。
3. **上界闸门而非经验均值闸门**。用 `q̄ = max{q'∈[0,1] | Bin(k; N_parts, q') ≥ δ_c}`（`k` 为失败数）得到 `ℙ(q ≤ q̄) ≥ 1−δ_c`，只有 `q̄ ≤ η_max` 的候选才入树。这是把 Monte-Carlo 估计升级成"证书"的那一步，也是全部保守性的来源（见 §3）。

### 1.3 信息流

```
x_init ─► v_0 (粒子集 𝓟_0, J=[0,0])
            │
            ▼
   ┌──────────────── 每次迭代 n=1..N_iter ────────────────┐
   │ 1. 采样空间点 ─► v_near                                │
   │      SMO-RRT: ε-greedy 均匀选 / Nearest                 │
   │      SMO-SST: ParetoBestNear(δ_v) 内随机取              │
   │ 2. 采样 π ~ μ_π , τ ~ U(ℕ(1,τ_max))                     │
   │ 3. Simulate(𝓟_near, π, τ):                            │
   │      for t=1..τ:                                       │
   │        u^(i)=π(x^(i),ξ^(i))                            │
   │        x^(i) ← f_e(x,u,w)   ξ^(i) ← f_ξ(x,ξ,ν)         │
   │        if x^(i) ∉ 𝒮(ξ^(i)) : 剪掉该粒子                 │
   │      return 𝓟_new, Ĉ = (1/|𝓟_act|)Σ C_τ^(i)            │
   │ 4. J_new = [1 − |𝓟_new|/N_parts , Ĉ]                   │
   │ 5. 二项反解 q̄ ；若 q̄ > η_max ─► 丢弃（不入树、无边）     │
   │ 6. [仅 SST] witness 归属 → δ_J-支配判定 → 剪旧节点      │
   └───────────────────────────────────────────────────────┘
            │
            ▼
   𝒢=(𝒱,ℰ) ─► 取非支配 J 向量 ─► Pareto 前段（风险 vs 代价）
```

## 2 · 数学核心

📌 **Napkin Formula**

```
J(𝝅,𝒯) = [ 1 − |𝒫_survive| / N_parts ,  Ĉ ]  ∈ [0,1] × ℝ≥0
                    ↑ 闭环粒子存活率             ↑ 存活粒子平均累积代价
约束：q̄(k=失败数, N_parts, δ_c) ≤ η_max
```

一句话直觉：**把"这条路的失败概率"换成"这条反馈策略在 256 次闭环仿真里活下来几次"，再用二项分布把"活下来几次"翻译回一个保守的真风险上界。**

**（a）目标函数**（式 5、6）

```
J_η(𝝅,𝒯) = 1 − ℙ( ⋀_{t=0}^{T} (x_t ∈ 𝒮(ξ_t)) ∧ (x_T ∈ 𝒳_g) )
J_c(𝝅,𝒯) = 𝔼_{𝐰,𝝂}[ Σ_{t=0}^{T−1} ℓ(x_t, π^(k_t)(y_t)) + ℓ_T(x_T) ]
```

- `𝒮(ξ_t) = 𝒳 \ ⋃_{i∈𝒩} 𝒮_i^unsafe(ξ_{i,t})`：安全集随所有对手的混合态时变。
- `𝐰`、`𝝂`：连续过程噪声序列与离散模式切换序列，二者在期望里都被边缘化。
- 注意 `J_η` 同时惩罚"撞上"和"到不了目标"，因此 `Ĉ=∞`（全灭）与"超时未达目标"是同一类失败。

**（b）优化问题**（式 7）

```
min_{(𝝅,𝒯) ∈ Σ} J(𝝅,𝒯)   s.t.  y_0 = y_init ,  J_η(𝝅,𝒯) ≤ η_max
Σ = 𝚷_𝒯 × ℕ(1,τ_max)^K
```

求的是**整条 Pareto 前段**而非单点解，因为 `J_η` 与 `J_c` 天然冲突（绕远路降风险）。

**（c）有限样本证书**（Theorem 3，引自 [16] Thm 4）

```
Z_i = 1_fail(𝝅, M^(i), 𝐰^(i)) ∈ {0,1},  i.i.d. Bernoulli(q)
q̄ = max{ q' ∈ [0,1] | Bin(k; n, q') ≥ δ }   ⇒   ℙ(q ≤ q̄) ≥ 1 − δ
```

- 二项 CDF 对 `q'` 单调递减，故集合 `{q' : CDF ≥ δ}` 是一个区间 `[0, q̄]`，取上端点即 Clopper–Pearson 风格的单侧上界。
- `n` 越大 `q̄` 越贴 `k/n`；这就是"证书保守性"的可调旋钮，也是本文算力开销的来源。

**（d）连续性链条**（§V-A，是完备性证明的地基）

```
Lemma 1 (轨迹散度)   e_{t+1} ≤ L e_t + L_u δ , L = L_y + L_u L_π
                     ⇒ d_𝒴(y_t(𝝅_A), y_t(𝝅_B)) ≤ C_t δ , C_t = √(2N+1)·L_u Σ_{i<t} L^i
Lemma 2 (模式概率)   |ℙ(M|𝝅_A,𝐰) − ℙ(M|𝝅_B,𝐰)| ≤ K_M δ
Lemma 3 (期望代价)   由 Lemma 2 + 控制收敛定理（`𝒴,𝒰` 紧）
Lemma 4 (chance 约束) 需 Assumption 1（`G(x)` 行满秩 ⇒ 绝对连续）+ Assumption 3（危险集边界 Lebesgue 零测）⇒ 边界命中概率为 0
Theorem 1           J(𝝅,𝒯) 在度量 D 下连续
```

**（e）SST 的多目标剪枝**（Definition 4）

```
J_A ≺_{δ_J} J_B  ⟺  ∀k: J_A[k] ≤ J_B[k] − δ_J[k]  且  ∃k: J_A[k] < J_B[k] − δ_J[k]
```

`δ_J` 是**加性松弛裕度**：允许"差不多好"的节点共存，以换取 witness 集合的稀疏性与前段多样性；`δ_J→0` 退化为严格 Pareto 支配。

## 3 · 带数字走一遍

> 以下是**玩具设定**：用论文真实参数 `N_parts=256`、`δ_c=0.05`、`η_max=0.5`，`q̄` 由我按二项分布手算（正态近似反解），**不是论文报告的数字**。

一次 `Simulate` 返回 256 个粒子的存活情况。设失败数 `k`，则 `|𝒫_new| = 256 − k`：

| 场景 | 失败数 `k` | 存活 `|𝒫_new|` | 经验失败率 `k/256` | 证书上界 `q̄`（自算 ≈） | `q̄ ≤ 0.5`? |
|---|---|---|---|---|---|
| A：顺利绕开 | 40 | 216 | 0.156 | ≈ 0.197 | ✅ 入树 |
| B：擦边 | 100 | 156 | 0.391 | ≈ 0.443 | ✅ 勉强入树 |
| C：被追 | 120 | 136 | 0.469 | ≈ 0.522 | ❌ **丢弃** |

场景 C 是整个方法的性格写照：**经验失败率 46.9% 明明低于阈值 50%，但仍被拒**——因为 256 个样本不足以把 46.9% 与 50% 区分开，上界 0.522 越过了 `η_max`。要么把 `N_parts` 加大，要么接受"贴近阈值处一律保守"。这也解释了为什么表 I 里 `J_η,min` 是 `0.14`（SMO-SST）而不是贴着 `0.5`——真正的最优解远在阈值内侧。

接着看代价维度。`Ĉ = (1/|𝒫_act|) Σ_i C_τ^(i)`，即**只对存活粒子求均值**。假设场景 A 的 216 个存活粒子累积代价均值是 `112.59`，则 `J_new = [0.156, 112.59]`。注意这里的偏置：粒子越危险越早被剪，存活集天然偏向低代价轨迹，`Ĉ` 因此是"条件于存活"的期望，而不是无条件期望——这正是 `J_c` 与 `J_η` 耦合的地方，也是 Pareto 曲线形状的来源。

最后一次 `Simulate` 的开销（推导，`τ_max` **论文未报告**）：每个粒子每步要跑一次 MPPI（`K=64` 采样、`H=20` 时域），故

```
单次 Simulate ≈ N_parts × τ × (1 + K·H) = 256 × τ × 1281
τ=20 时 ≈ 6.6×10⁶ 次动力学步进
```

再乘 `N_iter`（论文给的预算是 `200,000` 次迭代）会得到天文数字，因此实际实现必然对 MPPI 做了复用/缓存（论文未报告实现细节）。此处只做量级提示，标 `UNVERIFIED`。

## 4 · 工程视角

| 项 | 论文报告 | 说明 |
|---|---|---|
| 语言 / 硬件 | C++，Apple M2，16 GB RAM | 逐字来自 §VI-A |
| 迭代预算 | `200,000` 次迭代（`N_iter`） | 固定预算，非收敛判据 |
| 每节点粒子数 | `N_parts = 256` | 风险估计的分辨率上限 ≈ 1/256 |
| 首次可行解迭代 | SMO-RRT `6610 ± 4042`；SMO-SST `8040 ± 4481` | SST 更慢才出解（要攒 witness、要激进剪枝） |
| MPPI 内层 | `K=64`, `H=20`, `σ_a=2.0`, `σ_ω=1.0`, `λ=1.0` | 每次策略评估都带这层开销 |
| 策略参数空间 | `x_ref ∈ [0,64]²` | 4096 个离散参考点，是 `Π` 的可采样近似 |
| 墙钟时间 / FPS / 吞吐 | **论文未报告** | 全文无任何秒数、Hz、节点/秒数据 |
| 峰值内存 | **论文未报告**（仅给出机器 16 GB） | 树规模未报告，无法估 |
| 置信参数 | `δ_c = 0.05`，`η_max = 0.5` | 证书置信度 95% |

**Trade-off 读者笔记**：

1. **`N_parts` 是"风险分辨率 × 算力"的总旋钮**。它同时决定 (i) 存活率的量化粒度、(ii) 二项上界的松紧、(iii) 单次 Simulate 的成本。要认证 `η_max` 附近的风险，样本量必须 ≥ O(1/η_max²) 量级，否则像 §3 场景 C 那样"好解被误杀"。
2. **SST 的剪枝是"用首次解速度换最终解质量"**：`N_iters,sol` 从 `6610` 涨到 `8040`，但 `J_c,min` 从 `171.04` 掉到 `112.59`。如果任务是"2 秒内必须出可行解"，SMO-RRT 仍是更稳的选择。
3. **`τ_max` 与 `N_parts` 都是线性放大因子**，且未被论文给出数值——复现时这两个数是第一优先要试探的超参。
4. **策略族是唯一可插拔的"模型"**：MPPI 换成 LQR 增益采样、NN 权重采样（Remark 3 明说可行）不需要改树结构，只需满足 Assumption 4 的 Lipschitz 与可分性。这是本方法最容易工程落地的接口。

## 5 · 数据与评测

本文**没有数据集**，全部是自建仿真环境。逐字记录设置：

- **环境**：`64 × 64` 的空间域，`[0,64]²`；`8` 个静态对手安装点均匀分布（"Eight static adversary installations are uniformly distributed across the environment"）。
- **ego**：2D 离散时间 unicycle，`x_t=[p_x,p_y,θ,v]ᵀ`，`u_t=[a,ω]ᵀ`，`a_max/ω_max` 有界；`v_{t+1}=clip(v_t+a_tΔt, −v_max, v_max)`。
- **策略族**：MPPI，参数为参考目标 `x_ref ∈ [0,64]²`；`K=64` rollouts，`H=20`，`σ_a=2.0`，`σ_ω=1.0`，温度 `λ=1.0`；stage cost 追踪 `x_ref` 并惩罚接近活跃威胁。
- **对手**：Idle 时以 `p_fire(d)=p_max·clip((r_max²−d²)/(r_max²−r_min²),0,1)` 发射追踪弹，`p_max=0.3`，`r_max=8.0`，`r_min=3.0`；弹速 `v_adv,max=1.5`；捕获判据 `‖h_x(x_t)−h_z(z_proj,t)‖_2 ≤ 0.25`。
- **规划参数**：`N_parts=256`，`200,000` 迭代预算，`η_max=0.5`，`δ_c=0.05`；SMO-SST `δ_v=0.5, δ_s=0.25, δ_J=[0.01,1.0]ᵀ`；SMO-RRT `ε=0.01`。
- **验证**：最终轨迹用**样本外** Monte-Carlo 复核，`N_eval=1000`。
- **指标**：Hypervolume（HV，相对最差参考点 `J_ref=[0.5,256]`）、`J_η,min`、`J_c,min`、`N_iters,sol`。`10` 次独立 Monte Carlo 试验。

**表 I 结果（逐字）**

| 指标 | SMO-RRT | SMO-SST |
|---|---|---|
| Hypervolume (HV) ↑ | `17.91 ± 20.48` | `51.72 ± 24.79` |
| Min. Risk `J_η,min` ↓ | `0.32 ± 0.15` | `0.14 ± 0.15` |
| Min. Cost `J_c,min` ↓ | `171.04 ± 29.21` | `112.59 ± 15.62` |
| Iters to Sol. `N_iters,sol` ↓ | `6610 ± 4042` | `8040 ± 4481` |

**讲条件的四个提醒**：

1. **无外部 baseline**。作者的理由是"标准 chance-constrained 规划器要求 LTI 系统与高斯噪声，其风险评估与本文的反应式闭环对手模型在数学上不一致"，因此拒绝比较。所以上面的提升量**只在 SMO-RRT vs SMO-SST 之间成立**，不能读成"SOTA 提升"。
2. **方差极大**。HV `51.72 ± 24.79`，标准差接近均值的一半；`N_iters,sol` 也是 `8040 ± 4481`。10 次试验的样本量支撑不了强结论。
3. **没有报告求解成功率**。`200,000` 迭代预算下多少比例试验真正找到 `q̄ ≤ η_max` 的解，论文未报告。
4. **没有报告任何计时数据**。所有"性能提升"都是目标空间里的量，不是时间维度上的量。

## 6 · 能力与失败模式

**能做（有证据）**

- 在**非高斯、状态相关**不确定性下给出风险上界：`q̄` 只依赖 Bernoulli 计数，不需要噪声分布形状（Theorem 3）。
- 表达"分段换策略"的解：`(𝝅,𝒯)` 允许前段冲、后段苟，这是开环轨迹参数化不了的。
- **存在性**保证：SMO-RRT 概率完备（Theorem 2），只要存在严格可行解（Assumption 6 的裕度 `σ>0`），迭代数趋于无穷时找到它的概率趋于 1。
- 多目标：SMO-SST 维持 `δ_J`-近似 Pareto 前段而非单点解。

**不能做（同样有证据）**

- **不保证最优性**。是 RRT 而非 RRT*，没有渐近最优声明；只有"找到一条可行序列"的完备性。
- **SMO-SST 不完备**。Remark 4 说得很直白：剪枝只比较 `x=𝔼[h_x(𝒫)] ∈ ℝ^{n_p}`，丢掉分布形状与对手状态，`δ_s=0.25` 半径内"均值相同、风险迥异"的节点会被误判。
- **证书是逐节点的、不是全局的**。Theorem 3 针对**一条固定策略序列**给 `1−δ_c` 置信；树里有 `O(10⁵)` 个候选被逐个检验，论文未做多重比较校正（Bonferroni / union bound 均未出现），所以"最终返回的 Pareto 前段整体风险 ≤ η_max"这一更强的陈述**没有在文中被证明**。
- **只有 2D unicycle**。高维 kinodynamic（无人机、车-人交互）的可扩展性完全未验证。

### 隐含假设 (Hidden Assumptions)

| # | 假设（原文出处） | 一旦不成立会发生什么 |
|---|---|---|
| 1 | **噪声 i.i.d.、PDF 有界局部 Lipschitz、支撑紧**（Assumption 1） | 相关噪声/重尾噪声下 Lemma 1 的 `e_t ≤ C_tδ` 递推失效，定理链断在第一环 |
| 2 | **`G(x)` 行满秩，`w ≥ n`**（Assumption 1） | 存在无噪声的退化状态维时，Lemma 1 的 `d_𝒴` 上界退化为 0/不可控；Lemma 4 依赖的绝对连续性也失效 |
| 3 | **危险集边界 Lebesgue 零测**（Assumption 3） | 若安全边界是厚区域（如带容差的软约束带），"边界命中概率为 0"不再成立，`1_succ` 的几乎处处收敛性丢失 |
| 4 | **`ρ_act` 局部 Lipschitz、`ρ_term` 全局 Lipschitz**（Assumption 2） | 阶跃式激活（如硬阈值 `d<3` 就开火）使 `K_M` 无界，Lemma 2 失效 |
| 5 | **策略空间可分 + 采样测度满支撑 + 一致 Lipschitz**（Assumption 4） | 用离散动作集或确定性策略参数化会使 `p_π=0`，Lemma 5 的调和级数下界消失，完备性不成立；论文实际把 `Π` 限制在 4096 个 `x_ref` 网格点上，是这一假设的工程近似 |
| 6 | **存在带裕度 `σ` 的严格可行解**（Assumption 6） | 若最优解恰好贴着 `η_max`（`σ→0`），可行邻域半径 `r→0`，完备性证明里的 `p_π>0` 变得实际不可采样 |
| 7 | **对手之间独立、单跳 Markov、只依赖 ego 状态**（式 2 的独立 Bernoulli） | 协同围堵（多弹协同封路）会让联合模式空间 `|ℳ|` 的因子化假设破裂，采样效率骤降 |
| 8 | **粒子独立同分布**（Theorem 3 前提） | 若粒子共享随机种子或复用公共随机数做方差缩减，`Z_i` 不再 i.i.d.，二项上界不再有效 |
| 9 | **节点等价 ⇔ 期望位置接近**（SMO-SST 剪枝的设计选择） | 这是 Remark 4 承认的假设；分布双峰但均值相同的节点会被合并 |
| 10 | **`Ĉ` 是存活条件下的均值**（式 5 的仿真化） | 该估计器有选择偏置，跨节点比较 `J_c` 时并非同一条件分布下的期望 |

## 8 · GitHub-validated pitfalls (atlas 联动, 2026-11-02)

论文脚注给出了一行**纯文本**链接 `https://github.com/MarshallVielmetti/cdc_2026_stochastic_rrt_code`，但在我可见的文本中它并非可点击超链接，也无法核对是否存在活跃的 issue 流。因此本节按"**官方 repo 未经验证、无 issue 证据**"处理：以下 3 条 pitfall 全部由 §6 失败模式 × 方法约束**推导**而来，未引用任何 issue 编号/commit/用户报告。

**P1 · `N_parts` 与 `η_max` 的相对尺度会让"好解"被静默丢弃**
- 失败模式来源：§6 "证书是逐节点、且保守"。
- 方法约束来源：Algorithm 1/2 第 7 行的闸门 `if q̄ ≤ η_max then`，其中 `q̄` 由 `Bin(N_parts−|𝒫_new|; N_parts, q') ≥ δ_c` 反解。
- 机制推导：`N_parts=256` 时，失败率 46.9% 对应的上界已到 ≈0.52 > `η_max=0.5`（§3 场景 C）。**症状**：日志里看到候选"看起来明明不错"却始终没有新节点入树、树规模停滞，而 `q̄` 与 `η_max` 只差零点几。**对策**：把 `q̄ − η_max` 打成监控量，或按 `η_max` 反推所需 `N_parts`；不要靠调 `δ_c` 硬压过去（那会削弱证书语义）。

**P2 · SST 剪枝用 `𝔼[h_x(𝒫)]` 作节点坐标，会让"同均值、异风险"节点互相坍缩**
- 失败模式来源：§6 "SMO-SST 不完备"、§6 隐含假设 #9。
- 方法约束来源：`v_new ← Node(𝔼[h_x(𝒫_new)], …)` 与 `Nearest(𝒲, v_new)`、`dist(v_new.x, w_new) > δ_s`（`δ_s=0.25`）。
- 机制推导：witness 归属只比较 `x∈ℝ^{n_p}`（2D 场景下就是 2 个数），分布形状与对手混合态 `ξ` 全被投影掉；`δ_s=0.25` 在 `64×64` 域里是可见的空间尺度。**症状**：Pareto 前段"少了一截"——某段风险区间的解永远不出现，且加迭代数也没用（因为节点根本进不了 `𝒱_active`）。**对策**：复现时先在 `δ_s` 上做敏感性扫描；要恢复多样性需按 Remark 4/未来工作换成分布级度量（Wasserstein），或把 `ξ` 的统计量并入节点键。

**P3 · `q̄` 的 `1−δ_c` 置信是"单条策略序列"语义，跨 200,000 次候选检验会累积失效**
- 失败模式来源：§6 "证书不是全局的"、§6 隐含假设 #8。
- 方法约束来源：Theorem 3 明确限定 "For a fixed policy sequence `(𝝅,𝒯)`"，且 `Simulate` 内 `Z_i` 必须 i.i.d.；算法外层无任何多重比较校正或 union bound。
- 机制推导：树里每个被接受的节点都消费掉一次 `δ_c=0.05` 的置信预算；若同一随机种子/公共随机数被粒子复用，`Z_i` 相关性还会让单节点界本身失真。**症状**：`N_eval=1000` 的样本外复核里，某些"入树时 `q̄` 很低"的路径经验失败率明显偏高。**对策**：把 `δ_c` 按候选数做 Bonferroni 收缩，或对最终输出的每条 Pareto 路径用独立种子重跑 `Theorem 3` 复核（论文本身已用 `N_eval=1000` 做了这类样本外检查，值得照抄）；同时确保每个粒子的噪声流独立。
