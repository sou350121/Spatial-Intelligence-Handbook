# 尾座式无人机的协调增量轨迹跟踪 (Coordinated Incremental Trajectory Tracking of a Tailsitter Drone)

> **发布时间**：2026-07-13（arXiv:2607.11651v1 [cs.RO]；已投 IEEE，标注 copyright may be transferred）
> **论文 / 模型名**：Coordinated Incremental Trajectory Tracking of a Tailsitter Drone（TU Delft，Evangelos Ntouros & Ewoud J. J. Smeur）
> **核心定位**：为四旋翼尾座机（quadrotor tailsitter）在**协调飞行（coordinated flight）**条件下给出**闭式解析**的微分平坦变换，覆盖原 SOTA（[3] 的非协调变换）在**存在显著垂直速度分量**时直接奇异失效的飞行区段。

尾座机要在大迎角、大垂直速度的过渡段飞得又快又稳，控制器必须能把"位置的四阶导数"翻译成姿态与转速指令。已有的解析变换要么假设平飞（yaw 参考无意义），要么依赖 π-theory 气动模型而**只能在悬停附近奇异、且必须数值求解**。本文用 φ-theory 把这件事重新做成闭式几何：**协调飞行约束直接钉死机体 y 轴，只剩一个绕 y 的标量角待解**。

## X-Ray 开场

尾座机在过渡飞行时速度矢量与推力矢量会同时大幅倾斜，传统做法需要外部指定一个 yaw 参考——而当飞行路径从"平飞"变成"垂直俯冲/半滚"，yaw 就失去了物理意义，公式在 `i_zᵀf = 0` 处发散。本文的做法是：把协调飞行（零侧滑）当作**几何构造条件**，令体轴 y 必须垂直于 `v_a` 与 `f` 张成的平面，于是姿态只剩一个绕 `b_y` 的旋转角 `θ_e`，由 `tan θ_e = σ_x/σ_z` 一步解出，全程只用旋转矩阵与四元数。对 spatial AI / 机器人研究者，它的意义不在"又一个控制器"，而在示范了一种**用表示选择消除奇异性**的范式：换参数化（φ-theory + 旋转矩阵）比换控制器更能扩大可行飞行域。

### 1.2 关键机制

⚡ **Eureka Moment**：协调飞行（零侧滑）等价于"`v_a` 与 `f` 同处机体 XZ 平面"，于是 **`b_y` 的正交补平面被这两个矢量唯一确定**（`b_y ∝ v_a × f`），姿态自由度坍缩为一个绕 `b_y` 的标量角 `θ_e`——`yaw` 参考整个消失，`i_zᵀf = 0` 的发散也随之消失。

三个配套设计决定成败：
1. **符号连续性因子 `s`**：`b_y = s (v_a × f)/‖v_a × f‖`，`s` 由与上一时刻叉积的点积符号决定。半滚中 `v_a × f` 会变号，靠 `s` 保持姿态连续——**飞机选择倒飞而不是偏航 180°**。
2. **只用旋转矩阵**：规避 Euler 角的歧义与万向锁，角速度/角加速度全部经由 `[Ω]× = −Ṙ_i^b (R_i^b)ᵀ` 反解，再由反对称矩阵取分量。
3. **κ 的二选一**：`θ_e = atan2(σ_x, σ_z) + κπ`，`κ ∈ {0,1}`，选使 `i_zᵀτ < 0` 的那支（推力沿 −b_z，因为 `c̃_τ` 为负）。

## 2 · 数学核心

📌 **Napkin Formula**

```
协调飞行 ⇒ b_y ∥ (v_a × f)   ⇒   姿态 = 绕 b_y 的一个标量角 θ_e
tan θ_e = σ_x / σ_z ,  σ_x = −i_xᵀf^e + c_x‖v_a‖ i_xᵀv_a^e ,  σ_z = −i_zᵀf^e + c_x‖v_a‖ i_zᵀv_a^e
```

**目标**：给定四次连续可微的位置参考 `p(t)`，解析地反解出使机体保持零侧滑的姿态 `R_i^b`、前馈角速度 `Ω_ff`、前馈角加速度 `Ω̇_ff`，以及控制量 `u`。

**第 1 步（几何钉死 y 轴）**(7)：
`b_y = s · (v_a × f)/‖v_a × f‖`，其中 `v_a = ṗ − v_w`、`f = p̈ − g`（本文无风，`v_w = 0`）。

**第 2 步（构造中间系 E）**(8)(9)(10)：取任意常矢量 `r`（不平行于 `e_y`），
`e_y = s(v_a × f)`，`e_z = r × e_y`，`e_x = e_y × e_z`，归一化后 `R_i^e = [ê_xᵀ; ê_yᵀ; ê_zᵀ]`。
几何意义：`e_z` 落在 `b_y` 的正交平面内，从而 `E` 与 `B` 只差一个绕 `b_y` 的转角。

**第 3 步（解唯一未知角）**(11)–(16)：`R_e^b` 是绕 `b_y` 转 `θ_e` 的旋转；把 (3) 代入 `f^b = R_e^b f^e` 后对 `x`、`z` 两轴分别投影，消去推力项即得
`tan θ_e = σ_x/σ_z`，`θ_e = atan2(σ_x, σ_z) + κπ`；
再回代得推力投影 `i_zᵀτ = sinθ_e · i_xᵀf^e + cosθ_e · i_zᵀf^e − c_z‖v_a‖(sinθ_e · i_xᵀv_a^e + cosθ_e · i_zᵀv_a^e)`。
`κ ∈ {0,1}` 选使 `i_zᵀτ < 0`。**最终姿态**：`R_i^b = R_e^b R_i^e` (17)。

**第 4 步（一阶/二阶微分）**：`[Ω]× = −Ṙ_i^b(R_i^b)ᵀ` (18) → `Ω` (19)；`[Ω̇]× = −R̈_i^b(R_i^b)ᵀ − Ṙ_i^b(Ṙ_i^b)ᵀ` (29) → `Ω̇` (30)。其中 `Ṙ_i^e`、`R̈_i^e` 需要 `v̇_a = p̈`、`ḟ = p⁽³⁾`、`v̈_a = p⁽³⁾`、`f̈ = p⁽⁴⁾`——**这就是"位置必须四阶可微"的来源**。

**第 5 步（分配）**(40)(41)：`[m; i_zᵀτ] = G u^{∘2}` ⇒ `u = (G⁻¹[m; i_zᵀτ])^{∘1/2}`，`(·)^{∘2}`、`(·)^{∘1/2}` 为逐元素平方/开方。

**变量速查**：`c_x`=升力系数、`c_z`=阻力系数、`c̃_τ`=有效推力系数、`μ_{x,y,z}`=把转动惯量吸收进去的三轴力矩系数（因此**不需要单独知道 J**）、`ω_c`=执行器截止频率、`σ_x, σ_z`=消去推力后的两个中间标量、`s`=姿态连续性符号、`r`=构造中间系的任意常矢量。

**直觉**：整条链路里唯一"非线性求解"的地方是那个 `atan2`；其余全是叉积、归一化和矩阵乘法。这就是"解析"的全部含义——**没有迭代、没有数值求根**，与 [6] 必须数值求解的平坦变换形成对比。

## 3 · 带数字走一遍（玩具设定）

> 下面用论文 Table I 的真实系数，但轨迹点是我构造的玩具值，只为演示 `θ_e` 与推力投影怎么算出来。取中间系 `E` 与惯性系同向（`R_i^e = I`）以简化书写。

**系数（逐字）**：`c_x = −1.11×10⁰ 1/m`，`c_z = −1.54×10⁻¹ 1/m`，`c̃_τ = −4.42×10⁻¹ m/s²`。

**玩具状态**：`v_a^e = (0, 0, −5)`（沿 `e_z` 下降 5 m/s，即半滚中出现的大垂直速度分量），`f^e = (2, 0, −7) m/s²`（含水平 2 的转弯/抬头需求）。因 `b_y` 垂直于两者，`y` 分量为 0，协调约束在 E 系中自动成立。

1. `‖v_a‖ = 5`。
2. `σ_x = −2 + c_x‖v_a‖·0 = −2`；`σ_z = −(−7) + c_x·5·(−5) = 7 + 27.75 = 34.75`。
3. `θ_e = atan2(−2, 34.75) ≈ −0.0575 rad ≈ −3.3°`。
4. 验证：`R_e^b v_a^e ≈ (−0.288, 0, −4.992)`，气动项 `f_a^b = [c_x‖v_a‖v_a^b_x, 0, c_z‖v_a‖v_a^b_z] ≈ (1.596, 0, 0.384)`；而 `R_e^b f^e` 的 x 分量 `≈ 1.595`——**与气动项一致**（说明 `θ_e` 确实消掉了 x 通道），z 分量 `≈ −7.103`，故 `i_zᵀτ = −7.103 − 0.384 ≈ −7.49 < 0`，与 κ 的选取准则吻合。
5. 反推转速：`Σω_i² = i_zᵀτ / c̃_τ ≈ 16.9`。作为量级自检，悬停需 `|g|/|c̃_τ| = 9.81/(4.42×10⁻¹) ≈ 22.2`——同量级，说明玩具点处于"略低于悬停推力"的减速段，符合半滚出口的物理图像。（**此段全部为本笔记自算，非论文数据。**）

**退化对照**：把 `v_a` 换成 `(0, 0, −0.3)`（近悬停），`‖v_a‖ < 1 m/s` 触发 §III-E 的切换，改用 [3] 的非协调变换并把 yaw 设为 `atan2(i_yᵀv_a, i_xᵀv_a)`；把 `f^e` 换成平行于 `v_a`（如 `(0, 0, −7)`），则 `‖v_a × f‖ = 0`，`b_y` 无定义，只能冻结上一时刻值——这正是原文 V-B 中橙色区（`t = 4.4 s` 附近 `i_zᵀf_c → 0` 与 `v_a ∥ f`）发生的场景。

**可推导的部署 trade-off（均为结构性的，不含虚构数字）**：

- **计算前移**：`Ω̇_ff` 需要 `p⁽⁴⁾`（snap），而 `(33)(34)(37)(38)` 涉及两次归一化矢量的二阶导——这是整条链路计算最重的部分。若把轨迹生成放在地面站（本文即如此，轨迹"手工参数化并调参"），机上只需承担代数求值；若未来做**在线轨迹生成**，这部分会成为主循环的瓶颈。
- **微分噪声放大**：位置来自 mocap，速度是差分估计。二阶导链把离散/噪声的速度估计直接放大进姿态指令——作者本人把 V-B 中的指令尖峰主要归因于"定位系统的离散且带噪的速度估计"。工程含义：平坦变换的输入端必须有一致性滤波，否则噪声不在环路里而在**前馈通路**里，反馈增益调不回来。
- **可行性锥（分配层）**：`u = (G⁻¹[·])^{∘1/2}` 是逐元素开方，要求 `G⁻¹[m; i_zᵀτ]` 每项非负；而第 4 行由 `c̃_τ` 构成且 `c̃_τ` 为负（`−4.42×10⁻¹`），所以 κ 必须选在 `i_zᵀτ < 0` 的一支，否则开方直接非法。同时 `G` 的条件数与 `μ_x : μ_y : μ_z` 的比例（`3.56×10⁰ : 8.05×10⁰ : 7.84×10⁻¹`）强相关——**偏航通道最弱**，这与 Parrot Swing 内倾电机"降低总推力、增大偏航权限"的设计描述相互印证。
- **平台约束**：原文明确指出平台"significantly underpowered"，加上 `10×10×5 m` 的受限空域，导致**轨迹必须手工设计以避免执行器饱和**（半滚入口速度因此压到 2 m/s）。这类"控制可行但激励不够"的瓶颈，在真机落地时往往比算法本身更卡进度。

## 5 · 数据与评测

**没有数据集，没有 benchmark，没有 baseline 数值对比。** 评测是两条真机轨迹的案例展示。

**平台与设置（逐字）**：Parrot Swing 四旋翼尾座机（X 形升力翼 + 四个内倾电机）；室内场地 `10×10×5 m`，配 motion-capture 系统；算法在 Paparazzi 框架内实现并直接跑在机体硬件上；控制结构为 [3] 的 INDI。模型系数由**室内飞行数据**辨识（Table I：`c_x = −1.11×10⁰`、`c_z = −1.54×10⁻¹`、`c̃_τ = −4.42×10⁻¹`、`μ_x = 3.56×10⁰`、`μ_y = 8.05×10⁰`、`μ_z = 7.84×10⁻¹`），`ω_c = 15 rad/s` 由台架测试辨识。作者说明：室内飞行限制了机动范围与部分状态相关动态（如空速与角速度诱导的力矩）的激励，因此忽略了小项/不一致项，依赖 INDI 的增量特性吸收这些慢变未建模效应。

**与 [3] 的对比是分析性的，不是实验性的**：论文用"图 3c 绿色区 / 图 4c 中 `t = 4.4 s` 的奇异性"论证 [3] 在该区段不可用，但**没有**在同一轨迹上让 [3] 飞一遍并给出误差对比。RMSE / 平均误差 / 控制能量 / 环路频率——**「论文未报告」**。

## 6 · 能力与失败模式

**能做**：
- 在**存在显著垂直速度分量**的协调飞行中给出有定义、闭式的姿态/前馈指令（半滚、俯冲拉起、带横侧补偿的机动）。
- 姿态表述全程旋转矩阵/四元数，无 Euler 奇异与 `±180°` 歧义；`s` 因子保证倒飞而非掉头。
- 覆盖过渡与失速后（post-stall）区段的建模（φ-theory 的全局性），且变换是**解析**的——不需要像 π-theory 方案那样做昂贵的风洞辨识与数值求根。
- 框架可迁移到双电机尾座机：只需替换 `θ_e` 及其导数的计算（即 `E → B` 的旋转）与控制量反解，`I → E` 部分不变。

**不能做 / 明确不覆盖**：
- **不处理非协调飞行**（带侧滑、需要 yaw 作为独立平坦输出的机动）——作者定位为与 [3] **互补**，而非取代。
- **不做轨迹生成/优化**：轨迹手工参数化调参，"trajectory optimization is considered outside the scope"。
- **不做风估计**：`v_w` 在推导中保留符号但实验无风。
- **不做奇异性系统处理**："A thorough treatment of singularity handling is considered outside the scope"，只用启发式。
- **未做室外验证**、未做与 [3] 的实飞定量对比。

### 隐含假设 (Hidden Assumptions)

1. **零侧滑**：协调飞行约束等价于 `v_a` 与 `f` 严格共面于机体 XZ 平面。真实阵风、舵面偏转引起的侧力、非对称机翼都会破坏这一条——而文中没有侧滑估计器来闭环纠正。
2. **`v_a` 可直接由状态估计得到**：本文 `v_w = 0` 故 `v_a = ṗ`。一旦有风，`v_a` 必须靠空速管/风估计获得，而论文的传感器方案（mocap）根本不测空速。
3. **气动系数为常数**：`c_x, c_z` 不含迎角依赖、不含角速度项；模型被明确称为 φ-theory 的"简化表示"，辨识数据来自受限的室内机动。
4. **执行器同构且一阶**：四电机共用单一 `ω_c = 15 rad/s`；**转速无法直接测量**，`u` 由 `u̇ = −ω_c(u − u_c)` 估计得到——所有前馈与分配都建立在"估出来的 `u`"之上。
5. **转动惯量对角**：`J` 为对角阵，且被吸收进 `μ_j`（因此模型精度受这一结构假设约束）。
6. **INDI 的时间尺度分离**：增量式 `f_c = (a_c − a_f) + f_f` 依赖"执行器动态快于外环"，且 `a_f / f_f` 需低通滤波（截止频率未报告）。这一假设直接由 `ω_c = 15 rad/s` 的有界性给出上界。
7. **参考轨迹 C⁴ 且可行**：`p⁽⁴⁾` 必须存在且有界；`r`（中间系构造向量）被当作"任意常矢量"，但隐含要求它不平行于 `e_y`（论文未把这一条列入 §III-E 的奇异清单）。
8. **室内 mocap 状态质量**：位置/速度的离散性与噪声被作者确认为 V-B 尖峰的主要来源，即算法对该噪声**没有专门抑制机制**。

## 8 · GitHub-validated pitfalls (atlas 联动, 2026-10-18)

**repo 状态说明**：论文正文出现代码链接字符串 —— `Autopilot code: https://github.com/tudelft/paparazzi/tree/swing`（Paparazzi 的 `swing` 分支）。本次解析**未验证该分支的 issue 流 / commit 历史**，且该链接在 arXiv 文本中以纯文本形式出现，不构成可核验的 issue 信号。因此**以下 pitfall 全部由 §6 失败模式 + 论文方法约束推导，未经任何 issue 验证，不含任何 issue 编号或引文。**

**P1 · 控制分配矩阵 `G` 的印刷不一致（照抄即偏航错配）**
- 来源约束：(41) 第三行印为 `[−μ_z, μ_x, −μ_z, μ_z]`，而 (6) 给出的 `m_z = μ_z(−ω₁² + ω₂² − ω₃² + ω₄²)` 要求第二项为 `+μ_z`。
- 对应失败模式：§6 隐含假设 5（`J` 对角、`μ_j` 为常数）下的控制分配；偏航通道权重最弱（`μ_z = 7.84×10⁻¹` vs `μ_x = 3.56×10⁰`），错项会让偏航力矩计算偏差一个数量级。
- 处置：实现时以 (6) 为准重建 `G`，把 (41) 视作排版笔误；分配后用 `G·u^{∘2}` 回代校验 `[m; i_zᵀτ]`。

**P2 · 中间系构造向量 `r` 的未声明奇异**
- 来源约束：(8) `e_z = r × e_y`，`r` 被描述为"任意不平行于 `e_y` 的常矢量"；随后 (9)(10) 要做归一化。
- 对应失败模式：§III-E 只列了 `‖v_a × f‖ = 0` 的三类奇异，未覆盖 `r ∥ e_y`；一旦 `e_y` 旋转扫过 `r`（大机动中完全可能），`e_z = 0`，归一化除以零，姿态指令直接 NaN。
- 处置：`r` 不要取固定基矢量，改为**逐时刻选取与 `e_y` 夹角最大的基矢量**（或直接用 `e_y × 上一时刻 e_z` 做平行传输），并加 `‖e_z‖` 下限保护。

**P3 · 近悬停硬门限 `‖v_a‖ < 1 m/s` 带来的双变换切换不连续**
- 来源约束：§III-E 明确"for `‖v_a‖ < 1 m/s` 采用 [3] 的非协调变换，yaw 取 `ψ = atan2(i_yᵀv_a, i_xᵀv_a)`"；同时 `‖f‖ = 0` 与 `v_a ∥ f` 用"冻结上一时刻 `b_y`"的启发式。
- 对应失败模式：§6 隐含假设 2（`v_a` 由状态估计得到、无风）——门限是**绝对空速模长**，在有风或速度估计抖动的场景下会在阈值两侧反复穿越，两套变换输出的姿态指令不保证连续，冻结 `b_y` 又与 `s` 的符号连续性逻辑相互耦合。
- 处置：把门限做成带迟滞的软过渡（按 `‖v_a × f‖` 的条件数做混合权重），并在切换瞬间对 `q_c` 做最短弧插值限速。

**P4 · 四阶导数链在 mocap 差分输入下的噪声放大**
- 来源约束：(34)(37)(38) 需要 `f̈ = p⁽⁴⁾` 与 `v̈_a = p⁽³⁾`，而输入位置来自离散、带噪的定位估计。
- 对应失败模式：作者在 V-B 中把指令尖峰主要归因于"定位系统的离散且带噪的速度估计"（即 §6 隐含假设 8）。
- 处置：不要对原始 mocap 位置直接做四阶数值微分；应使用轨迹生成端解析给出的 `p⁽³⁾, p⁽⁴⁾`（论文正是"轨迹解析参数化"才得以回避这个问题）——**这也解释了为什么作者把在线轨迹优化列为下一步，而不是把微分做在机上**。
