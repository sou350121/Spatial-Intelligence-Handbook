# 以电流为触觉：面向柔顺灵巧操作的 proprioceptive 接触反馈 (Current as Touch: Proprioceptive Contact Feedback for Compliant Dexterous Manipulation)

> **发布时间**：2026-07-03（arXiv:2607.03529v1 [cs.RO]）
> **论文 / 模型名**：Current as Touch / CRP predictor
> **核心定位**：不装触觉/力传感器、不做显式力矩控制，用**电机电流 + 关节状态**作为"本体触觉"，直接学习一个 **Compliance Reference Position (CRP)**——即"让标准 PD 控制器产生合适接触力时关节目标该在哪"，从而在位置控制接口上实现柔顺抓取。

触点在于一个错配：灵巧手需要柔顺力控，但主流遥操作与模仿学习管线只能输出**关节位置**。本文把"柔顺"翻译成"位置参考"，让同一接口同时服务遥操作与策略学习，且不需要任何外置触觉/力传感。

---

**X-Ray（非专家版）**：接触丰富的灵巧操作需要不断调节接触力，但低成本的灵巧手只有位置接口，装触觉/力传感器又贵又脆。本文发现**电机电流随接触力一致变化**（可用简单回归以 RMSE 10.09g/17.75g 预测法向力），于是不把电流解码成力，而是学一个"位置目标"：PD 控制器追踪这个目标时产生的跟踪误差恰好等于合适的抓取力。对 spatial AI 研究者意味着——**触觉信号可以从执行器内部信号里"白嫖"，且能直接塞进既有的 position-based 策略接口**。

## 1 · 核心架构 / 方法总览

### 1.1 系统组件对比表

| 模块 | 输入 | 输出 | 训练 / 推理差异 |
|---|---|---|---|
| 观测编码器 (temporal conv) | 观测窗口 `o_{t-H+1:t}`（H=10） | 特征 `z_t`（dim 64） | 训练/推理一致；3×1D conv + ReLU + temporal pooling + LayerNorm |
| ACT-style action encoder | 未来动作块 `a_{t:t+K-1}` + `z_t` | 高斯隐风格 `(μ_t, logσ_t²)` | **仅训练**；推理时 style latent 置零（保持因果） |
| Action chunk decoder | `z_t` + style latent | 未来 CRP 块 `â_{t:t+K-1}`（K=10） | 训练/推理一致；4 层 Transformer，4 头，dim 128，dropout 0.1 |
| Auxiliary current head | `z_t` | 离线平滑电流 `Ī_t` | **仅训练**；部署时从控制回路移除，不加延迟 |
| 执行聚合 | 最近 M 个预测 | 平滑 CRP `q^exec_t` | 推理时用指数平均（默认 M=3） |
| 底层 PD 控制器 | CRP `q^c_ref,t`、测量 `q_t` | 力矩 `τ_t` | 固定增益 `K_p, K_d`，非学习 |

### 1.2 关键机制

**⚡ Eureka Moment：不把电流解码成力/力矩，而是直接学习"在当前位置下、要让 PD 控制器产生合适接触力时，关节目标应当在哪"——柔顺被重写为一个自适应位置参考（CRP），电流只是塑造该参考的本体接触线索。**

三个支撑性设计：
1. **CRP 监督来自人类在环演示**：`q^{c,*}_{ref,t} = q_cmd,t`——操作员用视觉反馈不断修正命令位置，录下来的命令是"经过闭环修正的、能产生成功柔顺交互的"噪声但有效的参考。
2. **意图速度防泄漏**：观测只喂 `v_intent,t = q_cmd,t − q_cmd,t−1`，不喂 `q_cmd,t` 本身，迫使模型结合当前状态与电流去**推断**合适 CRP，而非抄答案。
3. **原始电流 + 平滑电流辅助监督**：推理喂 **raw, zero-delay current**（避免低通滤波的相位延迟），训练用离线中值+滑动平均的 `Ī` 作辅助回归目标，逼迫 latent 保留缓慢的接触/负载趋势。

### 1.3 信息流 / 架构图

```
遥操作模式:
  [user cmd] ──► v_intent = q_cmd,t − q_cmd,t-1 ─┐
                                                 ├─► 观测窗口 (H=10)
  [hand+arm] ──► q_t (measured) ────────────────┤   o = [v_intent, q_robot, I]
  [motors]   ──► I_t (RAW current) ─────────────┘        │
                                                          ▼
                              ┌───────────────────────────────────────┐
                              │  Observation Encoder (3×1D conv→z_t)   │
                              └──────────────┬────────────────────────┘
                                             │  z_t
             训练时: future action chunk ──► Action Encoder ──► z_style
                                             │                       │
                                             ▼                       ▼
                              ┌────────────────────────────────────────┐

                              └──────────────┬─────────────────────────┘
                                             │

           o_policy = [q_robot, I, g_t]

执行:  最近 M 个 CRP 预测 ──► 指数平均 q^exec_t ──► PD 控制器 τ = Kp(q^c_ref − q) − Kd·q_dot
```

## 2 · 数学核心

📌 **Napkin Formula**

```
柔顺 = 位置目标:  τ = Kp · (q_ref^c − q)     ← 跟踪误差 → 想要的接触力
学这个目标:      q̂_ref^c = f_θ( q_history , I_history , u )
```

**目标**：让机器人不需要力矩接口、不需要力传感，就能产生合适接触力。

**公式组**：

| 环节 | 公式 | 变量说明 | 直觉 |
|---|---|---|---|
| PD 生成力矩 | `τ_t = Kp(q^c_ref,t − q_t) − Kd·q̇_t` | `Kp, Kd` 固定增益；`q_t` 测量位置 | CRP 太深入物体 → 力矩过大压碎；太靠近当前位置 → 法向力不足打滑 |
| CRP 监督 | `q^{c,*}_{ref,t} = q_cmd,t` | 人类演示命令 | 噪声但 task-valid，经视觉闭环修正 |
| 意图速度 | `v_intent,t = q_cmd,t − q_cmd,t−1` | 命令差分 | 不泄漏 target，只保留抓/放/保持意图 |
| 参考损失 | `L_ref = ‖q̂^c_ref,t − q^{c,*}_ref,t‖²` | — | 主任务 |
| 辅助电流损失 | `L_cur = ‖Ī̂_t − Ī_t‖²`，`Ī̂_t = h_φ(z_t)` | `Ī` 为离线平滑电流 | latent 保留缓慢负载趋势 |
| 总损失 | `L = L_ref + λ_KL(e)·L_KL + λ_cur·L_cur` | `λ_cur=0.1`，`λ_KL^max=1e-5` | KL 线性退火，`E_anneal=100` epochs |
| 执行聚合 | `q^exec_t = Σ α^m q̂^{(t−m)}_t / Σ α^m` | 默认 M=3 | 平滑 vs 响应动态负载 |
| 电流平滑标签 | `I^med = MedianFilter_{k_m}(I)` → `Ī = mean_{k_u}(I^med)` | `k_m=5, k_u=5` | 去 PWM/通信尖峰，保留负载趋势 |

**为什么要学 CRP 而不做显式力估计**：实际电流是混合信号
`I_t = Φ_contact(q, q̇, f) + Φ_internal(q, q̇, h) + ε`
——接触项之外还有摩擦、线缆、背隙、重力、温漂（`τ_bias = g(q) + τ_cable + τ_backlash`），而 `τ = J_c(q)^T f` 对灵巧手是病态逆问题（接触点未知、多指同时接触、滑动改变 Jacobian）。学 CRP 可以**吸收可重复的系统项、忽略不可预测的随机项**，且不依赖标定过的 current→force 映射。

## 3 · 带数字走一遍（玩具设定，仅示范）

设单指关节，`Kp = 2.0 Nm/rad`，`Kd = 0.05`，接触力杠杆臂 `r = 0.02 m`。

- **情形 A（刚性 retargeting，CRP 过深）**：物体把关节挡在 `q = 0.30`，但命令目标 `q^c_ref = 0.50`。
  稳态 `q̇≈0`，`τ = 2.0 × (0.50 − 0.30) = 0.40 Nm` → 接触力 `≈ 0.40/0.02 = 20 N` → 压扁纸杯。
- **情形 B（本文 CRP）**：模型从电流反馈判断已接触（`ΔI/Δq` 变大），输出 `q^c_ref = 0.35`。
  `τ = 2.0 × (0.35 − 0.30) = 0.10 Nm` → 接触力 `≈ 5 N` → 稳握不碎。
- **情形 C（CRP 太浅）**：`q^c_ref = 0.305` → `τ = 2.0 × 0.005 = 0.01 Nm` → `0.5 N` → 打滑。

**真实（论文报告的动机测量）**：在 Unitree Dex3 与 LEAP Hand 上，简单的"电流+位置"回归预测法向力的 RMSE 为 **10.09g（Dex3）** 与 **17.75g（LEAP）**，R² 分别为 **0.99** 与 **0.95**——这支撑了"电流含接触信息"的前提。

3. **平滑 vs 负载响应（Table 7，倒水任务，每设置 10 trials）**：

   | 聚合帧数 M | Grasp success | Hold success (0g→250g) |
   |---|---|---|
   | 1 | 40% | 90% |
   | 2 | 70% | 100% |
   | 3 | 90% | 100% |
   | 4 | 100% | 70% |

   M=1 响应快但抓取期抖动（初始抓取仅 40%）；M=4 抓取最稳但动态负载响应变慢（保持率降到 70%）。默认 **M=3**。
4. **KL 权重的隐藏成本（Table 8）**：`λ_KL^max = 0` 时遥操作握拳成功 100%，但默认的 `1e-5` 只有 **60%**（`1e-4` 降到 30%）——默认值是为倒水任务的稳定性选的，代价是牺牲在线跟随响应性。

## 5 · 数据与评测

**数据组成（Table 5）**：

| 任务 | 硬件 | 演示数 | 平均长度 / 频率 |
|---|---|---|---|
| 遥操作抓取 | LEAP Hand + Franka | 550 | 10.2 s @ 30.0 Hz |
| 遥操作擦白板 | Dex3 + Unitree G1 | 100 | 8.8 s @ 28.6 Hz |
| 动态持瓶倒水 | LEAP Hand + Franka | 100 | 14.9 s @ 30.0 Hz |
| 单张取卡 | Dex3 + Unitree G1 | 150 | 8.7 s @ 27.9 Hz |

- 遥操作抓取：对 **10 种不同刚度物体**各采 50 条抓取演示（foam cup, toy football, grape, apple, band-aid, steel case ruler, toy baseball, water sprayer I, water sprayer II, plastic water bottle），另加 50 条**空中自由手部运动**演示（用于分离"接触电流"与"内部执行器电流"）。
- 所有任务按 **80% 训练 / 20% 评估** 划分。
- 倒水演示每条包含抓空瓶 + 倒入 250 g 水（近常速率）。

**评测设置（讲条件）**：
- **演示来自与评测用户不同的操作者**——测的是迁移而非记住某个人的修正风格。
- 遥操作：新手与有 10 分钟练习的用户各做 **15 trials**；倒水每负载 **12 trials**；取卡 **52 trials**。
- **基线**：遥操作用 Retargeting（直接执行重定向命令）/ w-o Current（同一 CRP 预测器但不含电流）/ w- Current（完整原始电流模型）；策略学习基线为 **ACT-style behavior cloning**（机器人状态 + 物体位姿），本文方法加上电机电流。
- **物体位姿来源**：取卡用 **VICON** 动捕卡组相对机器人基座位姿；倒水用固定放置的预计算 `SE(3)`。

**关键结果（逐字）**：
- **叠泡沫杯（Table 1）**：新手 Retargeting 21.9s/43.3% deformed/13.3% grasp failure；w/o Current 31.1s/15.0%/76.7%；w/ Current **16.8s/0.0%/6.7%**。熟练 Retargeting 20.7s/25.0%/15.0%；w/o Current 35.3s/16.7%/71.7%；w/ Current **16.1s/0.0%/3.3%**。
- **擦白板（Table 2）**：新手 Retargeting 40.0%/9.3s；w/o Current 46.7%/9.3s；w/ Current **100.0%/6.9s**。熟练 Retargeting 100.0%/7.1s；w/o Current 60.0%/8.3s；w/ Current **100.0%/6.5s**。
- **动态持瓶（Table 3）**：250g 时 w/o Current 16.7% stable / 58.3% slipped / 25.0% fell，w/ Current **100.0% stable / 0.0 / 0.0**；OOD 350g 时 w/o Current 100% fell，w/ Current **41.7% stable / 58.3% slipped / 0.0 fell**。

## 6 · 能力与失败模式

**能做**：
- 脆物轻触（叠泡沫杯，deformed 0.0%）；持续面接触（擦白板，双双 100% 成功）；薄物精确交互（取卡 strict 55.8%→76.9%，多取卡 7.7%→0.0%）；动态负载适应（250g 100% 稳定，OOD 350g 不掉落）。
- **跨手迁移**：LEAP+Franka 与 Dex3+G1 两套具身；同一 CRP 接口同时服务遥操作与策略学习。
- 纯本体信号：无任何外置触觉/力传感器。

**不能做 / 失效场景**：
- **不解决感知/定位**：策略需要 VICON 或预计算 `SE(3)`；论文明确"does not address perception or localization"。
- **无解析最优力保证**：演示提供"经验性 CRP 监督"，非最优力标签；性能依赖演示质量与任务覆盖。
- **负载感知依赖特定关节**：倒水的动态负载信号依赖 LEAP 每指根部的 **abduction/adduction 电机**（横向抓握时负重增加这些关节阻力/电流）；没有此类关节的手 → 剪切/竖直负载信号更弱。
- **依赖电流可信息性**：取决于手部硬件、传动设计与电流测量。
- **未彻底消融**：辅助电流损失、执行平滑、启发式电流阈值控制器均未系统化对照。
- **KL 权重敏感**：遥操作握拳成功随 `λ_KL^max` 从 0→1e-4 由 100% 掉到 30%（Table 8）。

### 隐含假设 (Hidden Assumptions)

1. **PD 增益固定且部署不变**：CRP 是通过 `Kp` 生成力的，训练标签来自特定 `Kp/Kd` 下的成功命令；换增益/换固件 → 同一 CRP 产生的接触力按比例失真。
2. **电流的系统性偏差对同一台机器人可重复**：`I⁰`、摩擦、传动效率、线缆、背隙在固定硬件上是稳定项（Appendix C.1）；换手、长期磨损、温度漂移会破坏这一假设。
3. **人类演示命令是 task-valid CRP 标签**：默认操作者的视觉闭环修正总能收敛到可用的位置参考。
4. **接触相关电流 Φ_contact 可由历史窗口预测**：随机项（通信尖峰、量化噪声、不可重复撞击）假定只能被统计衰减，而非被建模。
5. **训练与部署的电流采样/预处理一致**：推理用 raw current，因此采样率、总线、量化必须与训练一致，否则 latent 的"系统性项"吸收失效。
6. **物体位姿可外部获得**：取卡依赖 VICON、倒水依赖固定 `SE(3)`。
7. **小运动过滤只施加于策略数据**（非遥操数据），使策略数据避开"几乎静止导致未来动作歧义"的片段。
8. **倒水训练是近常速率**：测试时随机速率、且 350g 超出训练分布，靠外展电机的隐式负载信号做部分泛化。

| 无传感柔顺 | Minimalist Compliance Control [25] | 电机电流/电压 | **显式 wrench 估计 + 任务空间导纳** | 需电机模型 + Jacobian |
| **本文** | Current as Touch | **电机电流 + 关节状态（本体）** | **学习 CRP + 标准 PD 位置接口** | **零外置传感、零 wrench 估计** |

与 [25] 的关键差异：两者都"用执行器信号替代 F/T 传感"，但 [25] 走 **explicit wrench recovery + model-based admittance**，本文**直接学到位置参考**，天然匹配灵巧手遥操作与策略学习的位置命令接口，且能吸收难以辨识的硬件系统项。

**🎤 面试 Tip**：被问"这跟直接用电流估力/阻抗控制有什么本质区别？"——答：**"它不是估计力，而是估计'位置'。"** 因为灵巧手与 BC 策略的动作空间是关节位置，把柔顺编码成 CRP 就能让电流反馈无损穿过既有位置接口；代价是它把 `Kp/Kd` 硬编码进了学习目标，换 PD 增益就需要重标定——这是它相对阻抗控制最大的结构性局限。

## 8 · GitHub-validated pitfalls (atlas 联动, 2026-09-19)

**Repo 信号核查**：全文仅给出项目网页 `https://cat.chenyangma.com/`，**未出现任何 `github.com` 链接**（无 repo URL、无 commit、无 issue 流）。因此按铁律**不写任何 repo/issue/commit 编号**，以下 4 条 pitfall 全部由 §6 失败模式 + 方法约束**推导**（未经 issue 验证）。

| # | Pitfall | 推导链 |
|---|---|---|
| 1 | **换 PD 增益即失效（力按比例失真）** | §6 隐含假设 1（CRP 对固定 `Kp/Kd` 标定） + Eq.1/35 中 `τ = Kp(q^c_ref − q)` 显式依赖 `Kp`。部署到不同手/固件（不同 `Kp`）时，同一 CRP 产生的接触力线性缩放 → 脆物压碎或打滑。**缓解**：冻结 PD 增益，或在新增益下重采少量演示重标定。 |
| 2 | **没有 abduction/adduction 关节的手 → 动态负载失效** | §6 失败模式："动态负载感知依赖 LEAP 的 abduction/adduction 电机…没有此类关节的手提供更弱的剪切/竖直负载信号" + §4.3 对该电机负载信号的解释。倒水这类需竖直负载感应的任务会退化为纯位置策略（Table 3 的 0g 行显示无负载时两者都 100%）。 |
| 3 | **电流可重复性漂移（温漂/磨损/换手）→ latent 吸收的系统项失效** | §6 隐含假设 2 + Appendix C.1 中 `τ_bias = g(q) + τ_cable(q,h) + τ_backlash(h)` 与 `I⁰` 明确"difficult to identify… may drift with temperature, wear, and cable routing"。长时间运行或更换手指后，训练时吸收的系统性电流偏移不再成立。 |
| 4 | **默认 λ_KL 已在遥操作响应性上做了牺牲** | Table 8：默认 `λ_KL^max = 1e-5` 对应遥操作握拳成功仅 **60%**，而 `0` 为 **100%**。若直接复用默认超参到强调"人对人跟随"的遥操作场景，会观察到响应性下降——需按任务重新调 `λ_KL`。 |

> 备注：§5 limitations 已自陈"未彻底消融辅助电流损失、执行平滑、启发式电流阈值控制器"，因此上述 1–4 之外若出现性能退化，**优先排查超参（`λ_KL`、`M`）与硬件电流采样一致性**，而非假定模型结构问题。
