# 弥合现实差距：灵巧力控抓取与操作的全状态零样本 Sim-to-Real 部署 (Closing the Reality Gap: Zero-Shot Sim-to-Real Deployment for Dexterous Force-Based Grasping and Manipulation)

> **发布时间**：2026-07-06（arXiv:2607.04940v1 [cs.RO]）
> **论文 / 模型名**：Closing the Reality Gap（BUPT × UCL，Zhe Zhao / Zhibin Li / Yilin Ou / Mengshi Qi）
> **核心定位**：把"密集触觉 + 关节力矩/电流"这类全状态反馈塞进 RL 观测空间，靠三条 sim-to-real 工程手段（距离场式触觉仿真、current→torque 标定、执行器模型随机化）做到**零样本、无微调**上真机；作者自称这是**首个完全在仿真中训练、零样本迁移到真机实现可控抓取力的多指灵巧手演示**。

灵巧手的接触密集动力学让"仿真训练、真机部署"长期断层：要么触觉仿真太慢导致 RL 探索不足，要么真机根本没有力矩传感器。本文不谈新网络结构，谈的是**一套可复现的 sim-to-real recipe**——而这正是硬件落地的真正瓶颈。

---

## X-Ray 开场

**解决什么问题**：多指灵巧手 12+ 自由度、接触密集，纯仿真训出来的策略一到真机就碎；且廉价灵巧手既没有关节力矩传感器，触觉仿真又慢到无法做大规模 RL 探索。
**提出了什么**：一个全状态（dense tactile + joint torque）非对称 actor-critic PPO 策略，配三件工具——(i) **并行前向运动学 + 距离场**近似密集触觉（每指 120 个虚拟 taxel，全手 600 个），(ii) **准静态 current→torque 标定**替代力矩传感器，(iii) **执行器模型随机化**（PD 增益、齿隙 deadband、力矩-速度饱和、效率因子）。
**对 spatial AI 研究者意味着什么**：这不是感知/重建论文，而是**"仿真器保真度如何影响可控性"的实证**——接触的表示方式（距离场 vs FEM/软体）决定了 RL 能不能跑得动，而观测的压缩方式（120 taxel → 4 维 `(F_i, μ_i)`）决定了策略能不能迁移。

### 1.2 关键机制

⚡ **Eureka Moment：把"接触"从**几何/软体问题**降维成**距离查询**——用并行前向运动学算出每个虚拟 taxel 相对物体表面的最近点，用一次点积的符号判接触、用穿透深度 + Mooney-Rivlin 曲线算力。接触不再需要 FEM 或软体求解器，于是密集触觉能以 RL 需要的速率跑起来，同时保留可迁移的接触特征分布（Fig. 4：真机接触区被仿真接触区**包含**）。**

第二条同等级洞见：**真机没有力矩传感器不是问题，问题是"仿真里力矩和真机里电流不是同一个量"。作者不去装传感器，而是把 `current→force` 与 `torque→force` 两条曲线都归一化到 `[0,1]` 对齐**——让策略在仿真中看到的力矩含义与真机电流含义同构。

## 2 · 数学核心

📌 **Napkin Formula**

```
接触 = 一次点积的符号:     Contact ⇔ v_oij · n_o < 0
触觉观测 = 一个"力加权的重心":  μ_i = Σ_j f_ij · p_ij / Σ_j f_ij
力矩 = 在"齿隙 + 速度饱和"两个夹板之间被裁剪的 PD 输出
```

**目标**：把 120 个/指的触觉读数，压成策略能消化、且真机同构的少数几个量。
**公式链** → **变量** → **直觉**：

1. **接触判据（Eq.11）**
 `v_oij = p_ij − p_o`，`n_o` 为物体表面外法向。点积为负 ⟹ taxel 已嵌入物体内部 ⟹ 视为接触。
 *直觉*：不做碰撞检测、不做软体形变，只问"这个点在表面里侧还是外侧"。代价是它无法区分"穿透 0.1mm 的轻触"与"穿透 1mm 的压紧"——这个差别交给下一步。

2. **合力（Eq.13）**：`F_i = Σ_{j∈S_i*} f_ij`，只对激活 taxel 集合 `S_i*` 求和。
 *直觉*：稀疏性——绝大多数 taxel 根本没接触，求和天然稀疏。

3. **力加权接触中心（Eq.14）**：`μ_i = Σ f_ij p_ij / F_i`，即**压力中心（center of pressure）**。
 *直觉*：这一个 3D 向量同时编码了"接触在哪里"和"接触偏在哪一侧"，是接触力分布的一阶矩。

4. **仿真的简化（§III-E1）**：用力正比于穿透深度的一阶近似 `f_ij ≈ k·d_ij`，代入后 `k` 上下约掉：
 `μ_i,sim = Σ d_ij p_ij / D_i`，`D_i = Σ d_ij`。
 *直觉*：仿真里**连力都不用真算**，用几何穿透深度就得到同一个加权质心——这就是"快"的来源。

5. **执行器模型（Eq.15-18）**：
 `τ_c = k_p(q_ref − q_m) + k_d(q̇_ref − q̇_m)`（PD）
 `τ_b = 0` if `|q_ref − q_m| < ε` else `τ_c`（**齿隙死区**）
 `τ_sat^±(q̇) = ±τ₀(1 − |q̇|/q̇_max)`（**直流电机力矩-速度包络**）
 `τ_applied = η · clip(τ_b, τ_sat⁻, τ_sat⁺)`
 每 episode 重采样 `k_p, k_d, ε, τ₀, q̇_max, η`。
 *直觉*：齿隙解释了"小命令下手指纹丝不动"的真机现象；饱和项解释了"高速甩动时抓不紧"；`η` 覆盖力矩常数与驱动效率的制造公差。

**奖励（Eq.1-10）**：`R_torque` 对四指用目标力矩的高斯核 `exp(−(τ_i−τ_target)²/2σ²)`（σ=0.10），拇指改用二值区间 `I(0.01 ≤ τ_thumb ≤ 1.1)`；`R_force` 同构（力区间 `0.01~200`）；`R_diff` 惩罚四指第一关节位置的方差（类人协同）；`R_outer` 惩罚外指偏离中立位；`R_action = w‖a_t − a_{t−1}‖²`；`R_vel = w‖q̇‖²`。

## 3 · 带数字走一遍（玩具设定）

**场景**：一个指尖上的 4 个 taxel，物体表面近似一个平面，位于 `z = 0.010 m`，外法向 `n_o = (0,0,1)`（物体占据 `z ≤ 0.010`）。为简单起见只考虑 z 分量，令 `p_o = (0,0,0.010)`。

| taxel | `p_ij` (z, m) | `v_oij·n_o = z − 0.010` | 接触? | `d_ij = |v_oij|` |
|---|---|---|
| t1 | 0.0120 | +0.0020 | ✗ | — |
| t2 | 0.0095 | −0.0005 | ✓ | 0.0005 |
| t3 | 0.0088 | −0.0012 | ✓ | 0.0012 |
| t4 | 0.0125 | +0.0025 | ✗ | — |

**合力**（取 `k` 省略）：`D_i = 0.0005 + 0.0012 = 0.0017`。
→ 若按 Eq.13 的线性力模型，`F_i ∝ D_i`；下面是**力加权**质心：

```
μ_z = (0.0005 × 0.0095 + 0.0012 × 0.0088) / 0.0017
    = (4.75e-6 + 1.056e-5) / 0.0017
    = 1.531e-5 / 0.0017
    ≈ 0.00901 m
```

**读出来的东西**：
- 接触中心 `μ_z ≈ 0.00901`，比两个接触点的**算术平均** `(0.0095+0.0088)/2 = 0.00915` 更靠近 t3——因为 t3 压得更深、力更大。**这就是"力加权"的物理意义：压力中心偏向受力重的一侧。**
- 策略拿到的触觉观测是 `(F_i, μ_i)` 共 4 维，而不是 120 个 taxel 的原始读数——**每指压缩 30 倍**。
- 关键工程含义：只要真机的触觉阵列也能给出"合力 + 压力中心"这两个量（论文 §III-E2 定义 `T_i=(F_i, μ_i)`），仿真与真机的**观测语义就一致**，这就是同一策略能零样本迁移的前提。

> ⚠️ 以上为**演示用玩具数值**，不是论文报告的任何实测数据。

| 工程指标 | 论文报告值 |
|---|---|
| 策略推理延迟 | 「论文未报告」 |
| 训练 wall-clock / 迭代步数 / 并行环境数 | 「论文未报告」 |
| VRAM / GPU 型号 | 「论文未报告」 |
| 控制频率 | 「论文未报告」（仅有 "high-rate" 的定性描述） |
| 物理引擎 | IsaacLab |
| 机器人 | 12-DoF 直驱灵巧手 XHand（`N=5` 指） |
| 触觉规模 | 每指 `M_i = 120`，全手 `Σ M_i = 600` |
| 动作维度 | 12D 关节命令 |
| 真机实验量 | in-hand 旋转消融：每配置 **10 trials** |

**可推导的工程 trade-off（非论文数据，属方法结构本身）**：

1. **触觉分辨率 vs 观测维度**：600 个 taxel 若全进观测，是 600+ 维；压缩成 `5D 力 + 15D 接触中心` 后只有 20 维。这是本方法能训得动的**结构性原因**，代价是丢失了接触的空间精细分布（只保留一阶矩）。这也解释了 §IV-2 的消融：去掉接触中心（一阶矩）→ 成功率从 25.1 掉到 12.2。
2. **随机化 vs 收敛速度**：`k_p, k_d, ε, τ₀, q̇_max, η` 每个执行器每 episode 重采样一次，策略须在参数分布上鲁棒。分布设窄 → 迁移失败；设宽 → 策略保守。论文只给了"all model parameters are resampled for each actuator at the beginning of every training episode"，**未给出各参数的分布范围**。
3. **距离场触觉 vs 物理正确性**：用几何穿透近似软体形变，省掉了软体求解；代价是力只能通过 Mooney-Rivlin 曲线间接映射，**材料的应力-应变曲线（Fig. 3b）必须事先测得并假设随时间稳定**。
4. **真机物体位姿的取值方式**：力控抓取任务里，物体 Z 由 `SAM 掩码中心 ↔ 掌心距离` 估计，**X/Y 保持固定**；物体线速度由此位置的差分得到。这是一个典型的"把视觉不确定性砍到只剩 1 个自由度"的工程妥协。
5. **旋转任务的真机变体**：可选"无方向观测"（纯本体感觉）或"物体内嵌低成本 IMU 直读方向"。后者引入了**额外硬件依赖**（IMU 需嵌入被操作物），但论文未报告两种策略在真机上的对比数字。

## 5 · 数据与评测

**数据组成**：本文**不使用任何外部/公开数据集**做训练或评测——策略完全在 **IsaacLab** 仿真中通过 RL 训练，真机评测在 **XHand 12-DoF 灵巧手**上执行。唯一涉及外部模型的是用 **SAM**（Segment Anything）在真机侧做物体掩码以估计 Z 坐标。

**两个任务与评测设置**：

- **§III-C1 力自适应抓取（force-adaptive grasping）**：物体置于桌上、手从随机位姿去抓的传统方案探索代价高且易学出非自然抓取。本文改用**倒置"接物"（catch-the-object）**：手**固定倒置**，物体向掌心抛落，策略学习在随机物体属性/动力学/外部扰动下接住并稳定抓取。力命令为 **0 到 1** 的连续值。

## 6 · 能力与失败模式

### 能做（论文实证）
- **力命令跟踪**：接触力与关节力矩随 force command 近似**线性正相关**；`R_Force` 与 `R_torque` 同时使用时相关性与力度范围最强（表 V）。
- **零样本真机部署**：两个任务均**未做真机微调**；仿真与真机行为一致（Fig. 7、Fig. 8）。
- **单轴连续旋转**：完整配置平均 25.1 次连续 90° 成功、平均耗时 3.36 s。
- **未见形状泛化（力控抓取）**：Fig. 9 展示了训练中未见的不规则物体的稳定抓取。
- **触觉观测压缩有效**：只用"合力 + 压力中心"两个量即可支撑迁移。

### 不能做 / 边界
- **旋转只支持单轴 90° 递增**——作者明确归因于手部自由度受限，不是任意轴/任意角 reorientation。
- **抓取是"倒置接物"设定**，手**固定倒置**；没有做桌面场景下的常规抓取学习（作者明确说这是刻意规避）。
- **力控抓取的物体 xy 位置被写死**，只估计 Z。
- **旋转任务的仿真依赖立方体**，未展示任意几何的 in-hand 旋转。
- **真机评测规模小**：每配置 10 trials。

### 隐含假设 (Hidden Assumptions)

1. **重力方向在任务中被写死**。`§III-C1` 的"倒置接物"里，重力的方向是任务定义的一部分；策略观测中并没有手部基座位姿（表 I 无 base pose 项）。→ 换一个安装姿态，观测分布即失配。
2. **准静态假设**。`§III-E3` 的 current→torque 映射是在**准静态条件**下拟合的（"fit a current→torque map under quasi-static conditions"），假设力与电流/力矩近似成比例并归一化到 `[0,1]`。
3. **真参数落在随机化区间内**。执行器随机化只在"真机参数位于采样分布内部"时才有意义；论文未报告分布范围，也未报告真机参数落入区间的验证。
4. **材料属性稳定**。触觉力依赖 Mooney-Rivlin 应力-应变曲线（Fig. 3b），隐含假设橡胶材料的力学性质不随时间/温度显著漂移。
5. **物体表面能被点云良好采样**。Eq.11 依赖在物体表面找到最近点 `p_o` 及其法向 `n_o`；稀疏网格、薄壁、强凹面几何都会让"最近点/法向"退化。
6. **触觉阵列的标定长期有效**。真机的 `F_i` 由触觉传感器读数求和得到，而仿真→真机的力域对齐依赖 `F_max,real` 与 `F_max,sim` 的归一化——换了传感器或发生漂移，`[0,1]` 尺度就错位。
7. **IMU 变体需要把传感器塞进被操作物**。方向观测的真实性以"物体内嵌 IMU"为前提（Table II 的 object orientation 仅对 critic 开放；真机需外挂 IMU）。
8. **特权 critic 假设仿真特权状态可信**。表 II 中大量 `×→✓` 的特权项（指尖速度 30D、指尖旋转 30D、物体角速度 3D 等）意味着 critic 依赖**仿真真值**——仿真这些量的偏差会直接污染价值估计。

## 8 · GitHub-validated pitfalls (atlas 联动, 2026-09-21)

**官方 repo 未在论文中给出（全文无任何 `github.com` 链接，也没有嵌入可点击的仓库超链接）；因此无 commit / issue 流可供核对。以下 3 条 pitfall 由 §6 失败模式与论文方法约束推导，未经 issue 验证。**

- **P1 — 倒置接物设定的重力方向被写进策略，换安装姿态即失效。**
 *来源*：§III-C1 明确定义"手固定倒置、物体向掌心抛落"，且表 I 的观测项（关节角/力矩、物体位置/线速度、接触力/中心、指尖位置、力命令）**不含手部基座位姿或重力方向**。
 *推导*：策略把"重力在掌坐标系中的方向"隐含在训练分布里。若把这套策略装到机械臂上、以另一种腕部朝向去桌上抓取（即论文明确回避的常规抓取场景），观测虽形式合法但语义失配 → 抓取力与协同模式不成立。
 *验证动作*：修改 §III-C1 的手掌基座旋转（如 ±30°）后重训或直接部署，观察表 I 中各量的分布偏移与抓取失败率。

- **P2 — 准静态 current→torque 标定在高速/大电流工况下线性假设破裂，力命令跟踪退化。**
 *来源*：§III-E3 明确"fit a current→torque map **under quasi-static conditions**"，且用 `I_max / τ_max / F_max,real / F_max,sim` 归一化到 `[0,1]`；同时 §III-E4 的 Eq.17 说明真机存在**力矩-速度饱和**（`τ₀(1−|q̇|/q̇_max)`）。
 *推导*：标定曲线不含速度维度，而真机在快速合拢/快速旋转时必然进入饱和区；此时"电流 ↔ 力矩"的一一映射被速度调制 → 策略读到的 `joint torque (12D)` 观测系统性偏大或偏小 → 表 V 里的力范围（44.50~93.92）在真机高动态段无法复现。
 *验证动作*：用同一力命令，分别在准静态与高 `q̇` 下记录真机电流/触觉合力，对比两条 `command→force` 曲线是否分裂。

- **P3 — 距离场触觉在薄壁 / 稀疏网格 / 强凹面上产生假接触或退化接触中心。**
 *来源*：Eq.11 的判据 `v_oij · n_o < 0` 只依赖**单点最近表面点 `p_o` 及其法向 `n_o`**；Eq.14 的 `μ_i` 再由穿透深度加权求和。全手 600 个 taxel 挤在"five independent dense groups"里。
 *推导*：(a) 薄壁物体（卡片、薄片）会让指尖背面的 taxel 也找到"最近点"并算出负点积，产生整片假接触；(b) 顶点稀疏的网格让"最近点/法向"跳变，`μ_i` 出现阶跃；(c) 强凹面下最近点可能落在另一个凹腔内，法向与真实接触面不符 → 接触中心指向错误区域。这些都会污染表 IV 中权重最高的"force-weighted contact center"。
 *验证动作*：在仿真中用薄片与低多边形网格重复 §III-E2 的 Fig. 4 对比（真机接触区 vs 仿真接触区），检查"真机接触区被仿真接触区包含"这一性质是否消失。
