# 活线重建驱动的自主操控 (Live Thread Reconstruction for Autonomous Manipulation)

> **发布时间**：2026-10-22（arXiv:2610.30694v1 [cs.RO]）
> **论文 / 模型名**：Live Thread Reconstruction（无单独方法代号）
> **核心定位**：把"可变形缝线重建"从**每帧从零解的静态重建**改成**以 B 样条控制多边形为状态的增量 EKF**，从而在夹爪遮挡、自交、出画的情况下持续跟踪，并把重建结果直接接到针拾取 / 解缠 / 打结收紧的动作生成上。

导语：可变形缝线有"无限自由度、无固定 pose"，静态重建（单帧重解全配置）在长程任务中既不可解也不鲁棒。本文的结论是：**只要首帧给一个可靠初始化，后续用 EKF 热启动就能穿过遮挡并支撑序列化操控**——硬配置针拾取从静态的 7/10 提升到 14/15。

---

## X-Ray 开场

一个缝合机器人要完成"拾针—拉线—收紧"这种长程任务，必须先知道**线此刻在哪儿**；但线是软的、会自交、会被夹爪挡住，而单帧静态重建每步都要从零解一个不可解的配置空间问题。本文提出一条 image-to-manipulation 流水线：首帧用图排序 + QP 拟合一条三次 B 样条，之后**把样条控制点当作 EKF 状态**，逐帧用关键点观测 + 形状先验（平滑/曲率/弧长/结数）做信息形式更新，匹配质量 $q_i$ 同时决定观测权重和几何约束的松紧，输出一个时序一致的 live thread state 供抓取点优化与动作生成使用。对 spatial AI 研究者的意义：这是一份**"可变形 1D 拓扑物 + 几何滤波 + 规则化操控"的完整闭环样本**，也是"没有学习、纯几何 + 滤波能否撑起长程任务"的一个明确实验证据点。

## 1 · 核心架构 / 方法总览

### 1.1 系统 / 组件对比表

每帧 $k$ 的输入固定为**一对校正后的双目图像 + 一张二值分割掩膜 $\mathcal{M}$**。全流水线**没有任何学习成分**：没有训练集、没有网络权重，全部是逐帧几何优化 + 滤波。

| 模块 | 输入 | 输出 | 训练 / 推理差异 | 关键超参（全文给出的） |
|---|---|---|---|---|
| ① Keypoint Selection（沿用 [2]） | rectified stereo pair + mask $\mathcal{M}$ | 3D 关键点簇 + 视差置信 $\rho(\bm p)$ | 无训练；逐帧 | 视差取平台中心 $d=\frac12(d_\ell+d_h)$；workspace band 深度门限；缺失深度用 Dijkstra 反距离插值 |
| ② Intersection Detection（本文新增） | 2D 关键点邻域 $\mathcal{N}$ | crossing 候选 + 两臂轴线交点 | 无训练；逐帧 | 结构张量主特征值比 $\lambda_1/\lambda_0>0.2$；RANSAC 提臂；臂须跨骑质心 $\bm\mu$ |
| ③ Keypoint Ordering | cold：邻接图；warm：上一帧 posterior | 弧长参数 $s_i$ + 匹配质量 $q_i\in[0,1]$ | 无训练；**frame 1 用 cold，后续用 warm** | 五重 gate（横向距/深度距/Mahalanobis/歧义/近交叉点）；3-D $\chi^2$ 检验 |
| ④ Spline EKF | 逐帧关键点观测 + 工具运动 | 控制多边形 $\bm x$ 后验 + 协方差 | 无训练；逐帧递推 | $\bm R_i^{-1}\leftarrow\max(c_iq_i,w_{\min})\bm R^{-1}$；支撑度 $\zeta_j$ 冻结阈值 |
| ⑤ Spline Initialization（仅 frame 1） | 3D 关键点 + 先验 $\bm y^{\mathrm{prior}}$ | B 样条控制点 $\bm y$ | 仅首帧解一次 QP | Eq.(1) 的 $\lambda$、 bending 矩阵 $\bm D$、$\bm W$、$\bm E$ |
| ⑥ Manipulation（3 个原语） | 重建后的 thread state | grasp point + 动作序列 | 无训练；谓词/规则驱动 | keep-out sphere（结与交叉点）、arc band、loop-interior 限制 |

**关键结构性事实**：整套系统的"时序性"只存在于 ③④ 之间——③ 把上一帧 posterior 当参考做匹配，④ 把上一帧 posterior 当滤波先验；① ② ⑤ 都是无状态的。

### 1.2 关键机制

**⚡ Eureka Moment：把"可变形线的瞬态几何"换成"样条控制多边形的隐状态"，于是重建 = 一个线性观测的 EKF 递推；而一个统一的匹配质量 $q_i$ 同时被用来调观测精度和放宽几何约束——好匹配收紧、坏匹配放松。**

三个支撑性设计：

1. **冷/热双排序**（II-D）：首帧没有先验，只能图最短路径定弧长序（cold）；之后线是连续运动的，用"上一帧后验"做门控匹配（warm），并把**交叉点附近的关键点先摘掉**、之后沿最近臂轴线插值 + 3-D $\chi^2$ 检验恢复——这是处理"自交歧义"的核心手法。
2. **交叉检测作为独立几何谓词**（II-C）：结构张量比值 $>0.2$ 只做**候选**，真正判定要求 RANSAC 提的两条臂**在质心两侧都跨骑**，以此排除发夹弯和平行线段。
3. **线程-夹爪交互进过程模型**（II-E）：控制点按工具运动做 warp，**按到工具尖端的距离指数衰减**，过程噪声按运动幅值 $m_k$ 缩放——即"夹爪附近我敢动，远端我不敢动"。这把操控动作本身变成了滤波的先验信息。

### 1.3 信息流

```
 stereo pair ──┐
               ├─► ① Keypoint Selection ──► 3D keypoints + ρ(p)
 mask M ───────┘            │
                            ├─► ② Intersection Detection ──► crossing centers
                            │
                            ├─► ③ Ordering ── cold(frame1) / warm(EKF posterior)
                            │        └─► s_i, q_i
                            ▼
              ┌─── frame 1 ──► ⑤ QP over control points y  ──┐
              │                                              ├─► ④ Spline EKF
              └─── frame k>1 ─────────────────────────────►  │   (information form,
                                                             │    + shape priors
                                                             │    as pseudo-measurements)
                                                             ▼
                                                    posterior x_k, Σ_k
                                                             │
                                                             ▼
                                        ⑥ Grasp-point optimization (safety/task 约束)
                                                             │
                                                             ▼
                                        Needle Pick-Up / De-tangling / Knot Tightening
                                                             │
                                                          (tool motion)
                                                             └──► 回到 ④ 的过程模型
```

注意最后一条边：**操控动作会回流到滤波过程模型**，这是"live"这个词的实质含义——重建与操控不是串联而是互喂。

## 2 · 数学核心

📌 **Napkin Formula**

$$\bm R_i^{-1}\leftarrow\max(c_i q_i,\,w_{\min})\cdot\bm R^{-1},\qquad \bm z_i=\bm H_i\bm x+\bm\eta_i,\quad \bm x=\text{B 样条控制多边形}$$

一句话：**线的状态是控制点，观测是 3D 关键点，可信度用"置信 × 匹配质量"直接乘进信息矩阵，坏点最多被压到 $w_{\min}$ 而不会被丢掉。**

### 2.1 首帧初始化：约束 QP

目标：在"线要平滑"和"别偏离先验"之间取平衡，同时让样条穿过关键点给出的三维盒约束。

$$\min_{\bm y}\ \bm y^{\top}\bm D^{\top}\bm W\bm D\bm y+\lambda\left\lVert\bm E(\bm y-\bm y^{\mathrm{prior}})\right\rVert^{2}\quad\text{s.t.}\ \ \bm\ell_i\le \bm B(s_i)\bm y\le \bm u_i \tag{1}$$

| 变量 | 含义 |
|---|---|
| $\bm y$ | B 样条控制点（首帧的待解量） |
| $\bm D,\bm W$ | 弯曲能量算子及其权重（平滑项） |
| $\bm E,\lambda$ | 时间/先验偏离算子与权衡系数（相对 $\bm y^{\mathrm{prior}}$ 的偏离） |
| $\bm B(s_i)$ | 弧长参数 $s_i$ 处的基函数取值 |
| $[\bm\ell_i,\bm u_i]$ | 由关键点导出的逐点上下界盒 |

直觉：**平滑项提供"线是光滑的"这一物理先验，盒约束提供"线必须经过这些观测点"这一数据证据，$\lambda$ 决定你更信谁。**

### 2.2 递推：线性观测的 EKF

状态 $\bm x$ = 三次样条的**控制多边形**，观测模型**线性**：

$$\bm z_i=\bm H_i\bm x+\bm\eta_i$$

因为基函数对控制点是线性的，所以"样条拟合"天然就是一个线性高斯滤波问题——这是选 B 样条做状态的根本理由。

**量测更新（信息形式）**：精度被 match quality 与置信共同膨胀

$$\bm R_i^{-1}\leftarrow\max(c_i q_i,\,w_{\min})\,\bm R^{-1}$$

- $c_i$：视差置信（由 next-best score margin 与平台宽度给出）
- $q_i$：warm ordering 的综合匹配质量 $\in[0,1]$
- $w_{\min}$：精度下限，**保证再差的观测也不会被完全剔除**（避免状态在某些区域彻底无约束）

**过程模型**：控制点按工具运动 warp，指数阻尼于到工具尖端距离

$$\bm x_{k+1}=f(\bm x_k,\ \text{tool motion})+\bm w_k,\qquad \bm w_k\sim\mathcal N(\bm 0,\bm Q(m_k))$$

$\bm Q$ 随运动幅值 $m_k$ 缩放：**动得越多越不确定**。

**形状先验当伪观测**：平滑、曲率、弧长、**结数（knot count）** 都以 pseudo-measurement 形式并入同一个更新。

**支撑度与裁剪**：

$$\zeta_j=\sum_i\left|b_j(s_i)\right|$$

$\zeta_j$ 低的**内部**控制点被**冻结**（没有观测支撑就别让它乱跑），两端无支撑则**裁掉**。

### 2.3 约束松弛

$$\text{边界}\,[\bm\ell_i,\bm u_i]\ \text{按}\ 1-q_i\ \text{比例放宽}$$

直觉：**$q_i=1$ 的观测给紧盒子（几乎硬约束），$q_i=0$ 的观测给松盒子（几乎无约束）**——这样交叉点附近被摘掉再插值的点、以及遮挡期的坏匹配，都无法把整条样条拉歪。

## 3 · 带数字走一遍（玩具设定，非论文数据）

### 3.1 交叉检测的阈值闸门

设某关键点邻域的结构张量给出 $(\lambda_0,\lambda_1)$，判据是 $\lambda_1/\lambda_0>0.2$：

| 情形 | $\lambda_0$ | $\lambda_1$ | 比值 | 判定 |
|---|---|---|---|---|
| 明显十字 | 1.00 | 0.55 | 0.55 | 候选 ✓ |
| 轻微折角 | 1.00 | 0.35 | 0.35 | 候选 ✓ |
| 近直线 | 1.00 | 0.12 | 0.12 | 非交叉 ✗ |

注意 0.2 是**必要不充分**：即便过闸，还要两条 RANSAC 臂**跨骑质心两侧**才算真交叉——这一步专门杀掉"发夹弯"和"两条平行线"。所以上表第二行（0.35）如果两臂都落在质心同侧，仍然会被拒。

### 3.2 匹配质量如何改写观测权重

取 $c_i=1$、$w_{\min}=0.05$、$\bm R^{-1}$ 归一为 1：

| 场景 | $q_i$ | $\max(c_iq_i,w_{\min})$ | 等效权重 | 边界放宽 $1-q_i$ |
|---|---|---|---|---|
| 清晰可见、远离交叉点 | 0.92 | 0.92 | 92% | 8% |
| 靠近交叉点、参与歧义 | 0.40 | 0.40 | 40% | 60% |
| 刚被摘掉后沿臂插值恢复 | 0.04 | **0.05** | 5%（被 $w_{\min}$ 托底） | 96% |

第三行是设计要点：$q_i=0.04$ 本应给 4% 权重，被 $w_{\min}$ 抬到 5%——**下限的作用不是"保留信息"，而是"不允许状态在某段彻底失去约束"**，否则冻结/裁剪逻辑会在那一段产生病态。

### 3.3 支撑度冻结（示意基函数值）

设 6 个控制点、4 个观测落在 $s=0.10,0.35,0.60,0.85$，示意性基函数绝对值（玩具值）：

| $j$ | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| $\zeta_j$ | 0.02 | 0.61 | 1.13 | 0.98 | 0.55 | 0.03 |

内部点 $j=0,5$ 的 $\zeta$ 极低 → 若它们是内部点则冻结；由于这里是**端点**，直接裁掉。物理含义：如果夹爪挡住了线中段，那一带的控制点会被冻结（保持上一帧形状），而线端一旦出画就被裁短——**这就是"遮挡下仍稳定"的机制来源，也是遮挡期形状会漂的机制来源**。

### 3.4 论文真实数字（逐字取自 Table I 与正文）

| Setup | Static Easy+Medium | Static Hard | Live Easy+Medium | Live Hard |
|---|---|---|---|---|
| Needle Pick Up | 18/20 | 7/10 | 13/15 | 14/15 |
| Tightening | - | - | 15/15 | 13/15 |

正文对应百分比：静态易/中 90%、活体易/中 87%、活体难 93%、静态难 70%；打结收紧活体易/中 100%、难 87%。**易/中配置两者可比（90% vs 87%），分歧全在 hard（70% vs 93%）**——作者归因于 live 能在夹爪遮挡中存活并在抓取中途重定位，而单帧静态重建无法恢复。

可推导的工程约束（**基于方法结构，非论文数字**，标 `UNVERIFIED`）：

- **逐帧计算图**：①~④ 每帧都要跑一次双目匹配 + 聚类 + 结构张量 + RANSAC + EKF 更新，其中 RANSAC 与邻接图 Dijkstra 插值是**离散迭代**环节，其迭代次数论文未给，是延迟的主要不确定源（`UNVERIFIED`）。
- **状态维度很低**：状态只是控制多边形，EKF 的协方差规模由控制点数决定，与"线的像素长度"无关——这是该表示法相对稠密点云/网格重建的核心工程优势（结构性结论，非实测）。
- **首帧成本不对称**：frame 1 要解一次带盒约束的 QP（cold ordering + Eq.(1)），之后不再解；因此**任务启动延迟 ≫ 稳态帧延迟**，长程任务摊薄后可接受（结构性推断）。
- **部署硬依赖**：一个可靠的 $\mathcal{M}$ 提供者。掩膜边界误差会直接进入 ① 的关键点簇与 Eq.(1) 的盒约束 $[\bm\ell_i,\bm u_i]$，而流水线里没有任何环节对此做鲁棒化。
- **部署软依赖**：工具尖端位姿（进入过程模型的指数阻尼核）。论文未说明尖端位姿由机器人正运动学还是视觉给出。

## 5 · 数据与评测

**数据组成**：论文**没有使用任何公开数据集**，全部为实机试次。全文未出现 dataset / benchmark 名称（`论文未报告`）。

**评测设置**（条件而非结论）：

- **任务一：needle pick up**。与 **static（single-frame）thread reconstruction [1]** 对比，分 easy/medium 与 hard 两档配置。static 侧 20 + 10 试次，live 侧 15 + 15 试次（**注意两侧试次数不同，非配对设计**）。
- **任务二：knot tightening**。**仅在 live reconstruction 下评测**，理由是 "no previous benchmark exists"（正文原文）。15 + 15 试次。
- **指标**：仅**成功率（成功试次/总试次）**。全文**没有**重建误差指标（无 RMSE / APE / 投影 IoU / 掩膜重合度）。
- **重建精度的定量对比被明确推给未来工作**：作者计划"comparing projected reconstruction to segmentation masks across visibility conditions (fully visible, minimally occluded) and recovery scenarios"。**即本文的核心主张（活体重建更准）在数值上未被验证**。
- **de-tangling 只出现在方法与 Fig. 2 中，无定量结果**（未来工作明确列出）。
- **定性观察（作者陈述，非量化）**：一旦在无歧义帧上完成初始化，重建在"夹爪遮挡大部分线段、线移出画面、视差变噪"三种情况下保持稳定。

**读这篇论文时的正确期待**：它证明的是**成功率层面的下游收益**，不是**重建精度层面的收益**。两者不能互相替代。

## 6 · 能力与失败模式

**能做（有实验或明确方法支撑）**

- 在连续操控中维持一条时序一致的缝线状态，穿过夹爪遮挡与自交歧义（定性 + hard 配置成功率 14/15）。
- 把安全/任务约束（keep-out sphere、arc band、loop-interior 限制）作为**可检查的显式谓词**施加到抓取点选择上——这正是不用模仿学习黑箱的动机。
- 三个操控原语：needle pick-up（沿线上移 grip 直到够到针）、de-tangling（找最高跨线股、抬起→平移→绕轴滚转→沿切线退出）、knot tightening（交替 trade rounds，receiver 先闭合 giver 再松，张力从不完全卸掉）。
- 把工具运动作为过程模型先验注入——操控动作本身改善重建。

**不能做 / 会失败（多数由作者自陈或直接可推）**

1. **epipolar-parallel 线段重建不准**——作者自陈的"main drawback"，直接限制可操作范围。方法侧的缓解手段是"视差取平台中心 $d=\frac12(d_\ell+d_h)$ 以避免 epipolar-parallel 段的偏置"，但**这只是去偏，不是恢复**：沿极线方向的深度本质上不可观。
2. **需要"无歧义帧"来初始化**——cold ordering + QP 首帧若碰到自交密布的配置，第 3 节的歧义会直接进入初值。
3. **交叉点附近靠"摘掉再插值"**：若两条臂的轴线本身估错（发夹弯、三条线交于一点），沿"最近臂轴线插值"会把错误固化进 posterior。
4. **遮挡期形状依赖冻结**：低支撑控制点被冻结 = 该段保持旧形状；长时间遮挡下"稳定"与"漂移"是同一枚硬币。
5. **结数（knot count）作为伪观测**：拓扑先验若不匹配实际（多打了一个结、结被打散），更新会被系统性拉偏。
6. **完全依赖外部二值掩膜**，且掩膜生成方式未报告。
7. **de-tangling 无定量验证**，其成功率未知。

### 隐含假设 (Hidden Assumptions)

| # | 假设 | 若不成立会怎样 |
|---|---|---|
| H1 | 双目已**校正（rectified）**且标定稳定，视差可直接转 3D | 视差→深度的映射偏差会整体进入关键点，EKF 只能平滑不能纠偏 |
| H2 | 线始终在已知的 **workspace band** 内（深度门限滤波的前提） | 线离开该带即被门限剔除，等价于"出画" |
| H3 | 场景里只有**一条**开放曲线，无分叉、无多线缠绕 | 关键点簇的图排序（shortest-path）会给出错误弧长序 |
| H4 | 分割掩膜 $\mathcal{M}$ **准确且每帧可得** | 掩膜边界误差污染关键点与 QP 盒约束，流水线无鲁棒化环节 |
| H5 | **工具尖端位姿已知**（过程模型指数阻尼核的输入） | warp 核错位 → 夹爪附近的控制点被错误驱动 |
| H6 | 帧间运动足够小，使 **warm ordering 的"匹配上一帧 posterior"** 成立 | 快速拉动/甩线时匹配 gate 集体失效，退化为无先验 |
| H7 | 交叉点数量与拓扑变化**缓慢**，摘掉+插值能覆盖 | 拓扑瞬变（结突然散开）会造成一帧的错误后验，并被 EKF 记住 |
| H8 | epipolar-parallel 段**占比不高**或不在关键抓取区 | 见失败模式 1 |
| H9 | 试次在受控台架/体模上，双臂协作、光照与背景可控 | 真实手术场景的血液、反光、烟雾会同时打击 ① 与 ② |
| H10 | "稳定"以**主观观察**判定 | 无定量重建精度支撑，稳定性主张的边界未知 |

## 7 · 与相关工作对比

| 方法 | 时序处理 | 遮挡鲁棒性 | 安全约束可否显式施加 | 是否闭环到操控 | 本文的差异点 |
|---|---|---|---|---|---|
| 静态/单帧重建 [1] | 每帧从零重解全配置 | 差（hard 配置 7/10） | 部分 | 是（作为 baseline） | 本文在 hard 上 14/15；本文直接复用其作为对照 |
| Joglekar et al. [2] | 单帧图排序 + QP 样条拟合 | 中 | 部分 | 否 | 本文**沿用**其关键点选择、cold ordering、QP 初始化，**新增**交叉检测、warm ordering、Spline-EKF、操控层 |
| 模仿学习（拾针/打结）[3][4] | 策略隐式编码 | 取决于数据 | **差**（黑箱，难加手术室安全约束） | 是 | 本文用显式几何谓词 + keep-out sphere 替代黑箱策略 |
| **本文** | 首帧 QP + 增量 EKF，操控动作回流过程模型 | 强（定性 + hard 93%） | **强**（keep-out sphere / arc band / loop-interior 均为可检查约束） | 是（三个原语） | 唯一同时具备"活体重建 + 显式安全约束 + 闭环操控"的组合 |

**面试 Tip**：被问"这篇和 [2] 到底差在哪"时，不要答"加了 EKF"（太浅）。标准答法是三段：**① 状态表示的复用而非替换**——它照搬 [2] 的 B 样条 + QP 框架，把"每帧解一次 QP"换成"首帧解 QP、后续解 EKF"，因此增量成本极低；**② 新增的是歧义处理**——交叉检测（结构张量 + 跨骑臂校验）与 warm ordering（近交叉点摘点后沿臂插值 + 3D $\chi^2$）才是让"活体"在自交下不崩的关键；**③ 真正的贡献在系统闭环**——操控动作通过"指数阻尼 warp + 运动幅值缩放过程噪声"回流进滤波器，这是纯重建论文不会做的事。最后补一句诚实的短板：**重建精度的定量对比是未来工作，本文只有下游成功率**。

## 8 · GitHub-validated pitfalls (atlas 联动, 2026-10-23)

**Repo 状态核查**：全文（含 HTML 版与参考文献区）**未出现任何 `github.com` 链接，也未出现项目页或数据/代码发布声明**；作者单位为 UCSD ECE 与 JHU CS。故本节**无社区 issue 流可引用**，以下 3 条 pitfall 全部由 **§6 失败模式 + 方法硬约束** 机械推导，**未经 issue 验证**。

**Pitfall 1 — epipolar-parallel 段不是"精度略降"，而是"沿极线方向无约束"**
- 来源失败模式：§6 失败模式 1（作者自陈 main drawback）。
- 方法约束链：① 视差取平台中心 $d=\frac12(d_\ell+d_h)$ 是**去偏**操作，平台宽度的存在本身就说明该处匹配是**平坦/不可辨**的 → $\rho(\bm p)$ 低 → $c_i$ 低 → $\bm R_i^{-1}$ 被压到 $\max(c_iq_i,w_{\min})$；同时 §2.3 的边界按 $1-q_i$ 放宽 → 该段盒约束几乎失效。
- 后果：EKF 在该段退化为**只由形状先验（平滑/曲率/弧长）外推**。表现出来不是"线抖"，而是**沿极线方向的深度坍塌**，且因为状态被记住了，坍塌会延续数帧。复现该问题的最小实验：把线摆成与极线平行并让夹爪在中段遮挡——预期看到该段重建贴向先验外推而非观测。

**Pitfall 2 — 掩膜 $\mathcal{M}$ 是硬输入，换一个 mask 提供者就换一套失败模式**
- 来源失败模式：§6 失败模式 6 + H4。
- 方法约束链：流水线的**函数签名**是 `(rectified stereo pair, binary mask M)`；掩膜同时进入 ① 的关键点簇提取与 Eq.(1) 的盒约束 $[\bm\ell_i,\bm u_i]$。论文未报告掩膜来源。
- 后果：若部署时改用学习式分割，"掩膜边界在哪"会直接变成"样条的盒约束在哪"。因为 §2.3 的松弛只依赖 $q_i$（匹配质量）而不依赖**边界置信**，一个自信但错位的掩膜会给出**紧约束 + 错位置**——这是最难通过调参救回来的组合。这条也解释了为什么本文必须做台上演示而非跨场景泛化：掩膜管线的域偏移没有被建模。

**Pitfall 3 — 首帧初始化是一个未被自动化处理的"人为时机选择"**
- 来源失败模式：§6 失败模式 2 + H6。
- 方法约束链：`frame 1` 走 **cold ordering（邻接图最短路径）+ QP**，`frame k>1` 走 **warm ordering（匹配 EKF posterior）**——两套路径的分支条件是"是否存在 posterior"，**不是**"当前帧质量是否足够"。
- 后果：整个长程任务的成败被绑定在一帧上，而论文没有给出任何"该帧是否适合初始化"的判据（例如交叉数、掩膜覆盖率、匹配质量分布）。工程落地时必须自己加一个初始化门控，否则一旦在自交帧启动，错误初值会被 §2.2 的冻结/伪观测机制**系统性地固化为先验**，后续 warm ordering 只会不断自我确认。这也解释了为什么作者的定性描述特意强调"once a reconstruction is initialized on an unambiguous frame"——那句话本身就承认了门控缺失。
