# VTAP 夹爪：指尖传感与视触觉主动手掌协同的灵巧手内操作 (VTAP Gripper: Synergizing Fingertip Sensing and a Visuo-Tactile Active Palm for Dexterous In-Hand Manipulation)

> **发布时间**：2026-07-16（arXiv:2607.15448v1 [cs.RO]）
> **论文 / 模型名**：VTAP Gripper（Visuo-Tactile Active Palm）
> **核心定位**：把"手掌"从被动的结构件升级成**可动 + 可看 + 可摸**的第三类接触面，用 13 DOF 的非拟人三指机构做出接近高 DOF 拟人手的在手操作能力——不靠更多手指，靠**指-掌协同**。
> **本体论坐标（5 轴）**：problem=n/a · representation=n/a · sensor=RGBD · paradigm=hybrid · time=filter-streaming。⚠️ 需注意：论文的掌部实际是**单目 USB 相机（GC0307，FOV 50°）+ 压阻触觉阵列**，全文未出现深度相机/RGBD 传感器；sensor 轴的 RGBD 标注与正文不完全吻合，引用时请以正文为准。

机器人操作正从"受控工位里的 pick-and-place"走向"半结构人类环境里的抓后操作（reorientation / 精确对位）"。平行夹爪机械简单但重构能力差，拟人手灵巧但笨重、贵、难控。VTAP 的结论是：**灵巧度不必来自高 DOF 的拟人结构，可以来自一个会动、会看、会摸的手掌与三根手指之间的结构化协同**。

---

## X-Ray 开场

现有触觉夹爪几乎把感知与驱动全部堆在"手指"上，掌-物接触被系统性忽略；而少数带主动手掌的工作，掌要么只能动不能感知，要么需要用机械式模态切换或双目系统才能同时拿到"远场视觉 + 近场触觉"。VTAP 的做法是：给三指夹爪装一块 **1-DOF 可升降的视触觉手掌**——同一片镀镜面漆的硅胶膜，LED 熄灭时是透明窗口（当长距相机用），LED 点亮时把内部光照反射到形变面（当光学触觉传感器用），**无需机械重配置、无需双目**；配合指尖 32×12 压阻阵列和一套"手势条件子空间"重定向框架，在四项任务（反应式抓取、注射器重定向+推杆、团聚物分选、多模态轴孔装配）上验证了"指-掌协同"的可行性。对 spatial AI 研究者而言，它的价值不在某个新模型，而在于提供了一个**多模态接触数据采集的硬件参考架构**：手掌自带近场视角，恰好补上腰挂相机在受限空间被遮挡的坑。

### 1.2 关键机制

**⚡ Eureka Moment：同一片膜，用"LED 开关"切换光学状态——灭灯时镀镜面漆的硅胶是透明的（长距视觉），亮灯时镜面漆把内部光反射回形变面（光学触觉），于是"视觉/触觉双模手掌"退化成一次照明控制，而不是一套机械切换机构或双目系统。**

配套的第二个洞见：**非拟人三指夹爪的重定向难点不在 IK，而在"没有解剖学对应"**。VTAP 用"手势先验把配置空间切成一维子空间"（cage / power / pinch 三种抓取原语约束 q1，q3 直接锁死），再用一个常量 SE(3) 变换把人类手腕系 𝒲 映射到中间系 ℐ，绕开"三指基座在几何中心而非腕部"的坐标系错配——**先用离散先验降维，再做连续优化**。

## 2 · 数学核心

📌 **Napkin Formula**

```
每一帧遥操作 = 一个带盒约束的非线性最小二乘：

  q*_t = argmin  λ1‖v^g − v^ℐ‖² + λ2‖r^g − r^ℐ‖² + Σ_j w_j‖q_j^t − q_j^{t−1}‖²
         s.t.  q_min ≤ q_t ≤ q_max

每一帧抓取 = 一个标量能量越阈值就停：

  Q = Σ_{i=1}^{3} [ α·ΔC_f + (1−α)·Σ_{m,n} S_f(m,n) ]  >  T_th
```

一句话直觉：**重定向 = "指尖位置 + 指尖朝向"的加权最小二乘 + 速度平滑正则；抓取终止 = "接触面积变化"与"信号强度"的加权和越过一个经验阈值。**

### 2.1 手指前向运动学（式 1–2）

目标：把关节角 q = [q1, q2, q3, q4]ᵀ 映射到指尖位姿，用于重定向中的 ‖v^g − v^ℐ‖² 计算与工作空间分析。

```
ᴱ_T(q) = ᴼ_T¹ · ¹_T² · ²_T³ · ³_T⁴ · ⁴_Tᴱ = [ R(q)  p(q) ]
                                            [ 0₁ₓ₃   1   ]
```

其中各段变换为（D 表示沿固定连杆向量的平移，R_X/Y/Z 为绕轴旋转）：

| 段 | 表达式 | 含义 |
|---|---|---|
| ᴼ_T¹ | D_&#123;p₁&#125; · R_Z(φ) · R_Y(π/2) · R_X(−q1) | 基座偏移 p₁ + 首关节方位角 φ + 桡/尺偏 |
| ¹_T² | D_&#123;l₁&#125; · R_Z(−π/2) · R_X(π/2 + q2) | 连杆 l₁ + MCP 屈伸 |
| ²_T³ | D_&#123;l₂&#125; · R_Z(−π/2) · R_X(−q3) | 连杆 l₂ + 内收/外展 |
| ³_T⁴ | D_&#123;l₃&#125; · R_Z(π/2) · R_X(q4) | 连杆 l₃ + PIP 屈伸 |
| ⁴_Tᴱ | D_&#123;l₄&#125; | 指尖偏移 |

三指绕掌布置，各占 120° 扇区：[−60°, 60°]、[60°, 180°]、[180°, 300°]。用蒙特卡洛在关节限位内采 **5000** 组随机配置估算工作空间，得到约 **469 mm (X) × 477 mm (Y) × 311 mm (Z)** 的包络——说明这个"小"夹爪的空间覆盖并不小。

### 2.2 重定向目标（式 3–6）

| 项 | 公式 | 变量说明 | 直觉 |
|---|---|---|---|
| 位置项 | L_pos = Σ_&#123;i=1&#125;^&#123;3&#125; ‖**v**_i^g − **v**_i^ℐ‖²₂ | **v**_i^g：夹爪基座系 𝒪 到第 i 指尖的向量；**v**_i^ℐ：中间系 ℐ 到人手指尖的向量 | 只对齐"指尖相对基座的方向与距离"，不对齐绝对位置 → 吃掉两种本体在尺度上的差异 |
| 朝向项 | L_rot = Σ_&#123;i=1&#125;^&#123;3&#125; ‖**r**_i^g − **r**_i^ℐ‖²₂ | **r**_i^g：接触面中心 → 机器人指尖；**r**_i^ℐ：人 **PIP → 指尖** 向量 | 因为夹爪**没有 DIP 关节**，用 PIP→tip 而非 tip 朝向，才能在 VR 捕获下保持可观测 |
| 平滑项 | L_vel = Σ_&#123;j=1&#125;^&#123;6&#125; w_j ‖q_j^t − q_j^&#123;t−1&#125;‖²₂ | 只对 **6 个** 被优化关节求和（3 指 × &#123;q2, q4&#125;），w_j 为每关节权重 | 抑制追踪噪声引起的抖动；也解释了为什么"6"这个数字反复出现——不是 12 |
| 总目标 | L = λ1 L_pos + λ2 L_rot + L_vel | λ1, λ2 全局标量权重 | 所有内部子项统一套 **Huber 型鲁棒罚函数**：对噪声稳定，又保留对小误差的敏感性 |
| 求解 | q*_t = argmin L(q_t), s.t. q_min ≤ q_t ≤ q_max | — | 逐帧、无记忆（除 L_vel 中的上一帧）、盒约束投影 |

### 2.3 抓取终止判据（式 7）

```
Q = Σ_{i=1}^{3} [ α·ΔC_f + (1−α)·Σ_{m,n} S_f(m,n) ]  >  T_th
```

- ΔC_f：第 i 指触觉图中**非零接触像素数的变化量**（接触面积扩张速度）
- Σ S_f(m,n)：该指所有 taxel 的**累积信号幅值**（压力强度）
- α ∈ [0,1]：面积项与强度项的平衡；T_th 为**经验选取**的终止阈值
- 直觉：不只问"压到多大力"，而是问"接触正在以多快速度扩张 + 已经压了多重"——ΔC 项是对"刚接触、正在包裹"这一瞬态的响应。

### 2.4 分选（singulation）重定向——非优化的一小段几何映射

在 pinch 模式下只映射人的拇指与食指到两个主动指，监控两个几何线索：
1. 拇指尖-MCP 向量 与 食指指尖-PIP 向量 的**夹角**；
2. 拇指-食指指尖的**欧氏距离**。

两者分别接近平行、且距离低于预设阈值时，控制器切入 singulation 模式：
- 人指尖距离 **线性映射** 为两个 q3 关节**等幅反向**驱动；指尖向量的相对角决定运动**符号**；
- 对应 MCP 的 q2 屈曲由"拇指-中指距离"的线性映射调节 → 每指 2 个主动 DOF 协同。

## 3 · 带数字走一遍（玩具设定，非论文数据）

> 论文未给出连杆长度 l₁~l₄ 与具体 λ/w 取值，因此下面用一个**二维两连杆玩具模型**演示重定向的数值行为与 L_vel 的作用。所有数字均为示范，**不代表论文参数**。

**设定**：单指简化为平面 2R（关节 q2 = MCP，q4 = PIP），l₁ = 40 mm，l₂ = 30 mm，角度自 x 轴起算 θ₁ = q2，θ₂ = q2 + q4。人手指尖目标 **v**^ℐ = (45, 45) mm。

**Step 1 · 上一帧（t−1）的姿态**：q2 = 30°, q4 = 45° → θ₁ = 30°, θ₂ = 75°

```
p = 40·(cos30°, sin30°) + 30·(cos75°, sin75°)
  = 40·(0.8660, 0.5000) + 30·(0.2588, 0.9659)
  = (34.64, 20.00) + (7.76, 28.98) = (42.40, 48.98) mm
L_pos = (42.40−45)² + (48.98−45)² = 6.76 + 15.84 ≈ 22.6 mm²
```

**Step 2 · 只解 L_pos 的闭式解**（2 方程 2 未知，一般有精确解）：

```
|p|² = l₁² + l₂² + 2 l₁ l₂ cos q4
4050 = 1600 + 900 + 2400·cos q4  →  cos q4 = 0.6458  →  q4 ≈ 49.8°
偏移角 = atan2(l₂ sin q4, l₁ + l₂ cos q4) = atan2(22.90, 59.37) ≈ 21.1°
q2 = 45° − 21.1° ≈ 23.9°
校验：40·(0.9141,0.4053) + 30·(0.2807,0.9598) = (36.56,16.21)+(8.42,28.79) = (44.98, 45.00) ✓
```

**Step 3 · 加入 L_vel 会发生什么**：从 (30°, 45°) 跳到 (23.9°, 49.8°)，关节位移 Δq2 = −6.1°, Δq4 = +4.8°。取玩具权重 w = 0.05：

```
L_vel = 0.05·[(−6.1)² + (4.8)²] = 0.05·(37.2 + 23.0) ≈ 3.0
```

再算"偏离 5° 的代价"：把 q2 挪到 28.9°（q4 不变）→ p = (40.91, 48.74)，L_pos ≈ 30.6 mm²。

**结论（可面试复述）**：约 **1.2 mm²/度** 的位置误差梯度，与 L_vel 的 **0.1/度** 量级平滑罚项在同一数量级上博弈——所以 λ1 与 w_j 的标定不是"调参玄学"，而是在"跟手性"与"抗 VR 抖动"之间显式取一个折中点。论文对这一取舍只写了 λ1、λ2 为"global scalar weights"、w_j 为"joint-specific weight"，**具体数值未报告**。

**Step 4 · 抓取阈值玩具算例**：α = 0.5，若当前三指分别为

| 指 | ΔC_f（非零接触像素变化） | Σ S_f（taxel 累积幅值） | 单指贡献 |
|---|---|---|---|
| 1 | 20 | 400 | 210 |
| 2 | 15 | 320 | 167.5 |
| 3 | 10 | 260 | 135 |
| — | — | **Q** | **512.5** |

若经验阈值 T_th = 600，则三指继续屈曲；Q 越过 600 的那一帧停止闭合。**注意 α 决定了这个标量偏向"面积"还是"力"**：α→1 时系统更容易压碎易碎物（因为只等接触铺开、不等力上升），α→0 时更容易在薄壁/轻物上提前停止。论文未在正文中对 α 偏置做敏感性分析，这是它"经验阈值"说法的来源。

| **底层控制** | 夹爪：内置 **current-based PD** 控制器；机械臂：**UR5e**，**RTDE** 位置控制 |
| **单帧重定向求解耗时** | **论文未报告** |
| **端到端延迟 / 抖动** | **论文未报告** |
| **算力 / VRAM / GPU 型号** | **论文未报告**（方法链为阈值判据 + 非线性优化 + 形态学/Canny + 梯度边缘 + 圆拟合，全文未出现学习模型或神经网络推理） |
| **整机质量 / 负载 / 功耗** | **论文未报告** |
| **成本 / BOM** | **论文未报告** |

### 关键工程 trade-off（可从正文机制直接读出，非估算）

1. **电机数减半的机械红利**：用双轴 Dynamixel（2XC430 / 2XL430）让每指只需 2 个电机就实现 4 DOF，6 个电机覆盖 12 个手指 DOF。代价是同一电机两轴共享一个外壳与控制接口，q1/q2 与 q3/q4 各自成对耦合在控制总线上——重定向求解时 q1 由手势事件驱动（离散）、q2 由优化驱动（连续），两种更新节律落在同一块电机上，需要小心处理指令时序。
2. **被动柔顺替代力控**：TPU 3D 打印的 Fin-Ray 结构"无需显式接触建模"即可适配不同几何，因此系统里**没有力/力矩传感器**，抓取力完全由式 (7) 的单标量阈值间接调节。这是省成本的关键，也是 drill 只有 5/10 的根因之一（见 §6）。
3. **1 个掌 DOF 换掉一部分腕部需求**：注射器任务中"按压推杆"由小指动作映射到掌的线性执行器完成——用 50 mm 行程的直线运动替代了额外的腕部/手指 DOF，这是"13 DOF 拼出高灵巧度"的核心账。
4. **单目双模换掉一整套触觉硬件**：LED 灭/亮 + 镜面漆透明度，让同一颗 GC0307 既做长距视觉又做光学触觉，避免了 [19] 的机械切换机构与 [20] 的双目系统。代价是**两种模态不能同时工作**——peg-in-hole 必须先视觉、后触觉两次切换（论文的状态机正是这么写的）。
5. **25 Hz → 100 Hz 插值的隐含代价（推论，非论文陈述）**：人手姿态只有 ~25 Hz（40 ms 一拍），插值到 100 Hz 只是把阶跃抹平，并不增加信息。接触瞬态（如滑移起始）若发生在两帧之间，触觉闭环无法在 40 ms 内做出反应——这与 §V 中"drill 在触觉反应式闭合力建立前就打滑"的现象方向一致，但论文未把它归因为频率问题。
6. **部署形态约束**：整套流程需要 VR 头显 + UR5e + 外部标定，属于**实验室遥操作/数据采集平台**，不是可脱机自主运行的嵌入式方案。

## 5 · 数据与评测

**没有任何数据集、benchmark 或训练流程**。全部为实物实验，平台为 **UR5e + Meta Quest 3**。这一点必须先讲清楚：本文不提供 learning-based 的 baseline 数字，也不在任何公开 benchmark 上评测。

### 5.1 任务与设置

| 任务 | 设置（逐字对应正文） | 指标与结果 |
|---|---|---|
| **反应式抓取** | 5 个 **YCB** 物体 + 4 个日常物体，按 cage / power / pinch 三组；物体随机放置于工作空间、初始朝向任意；**掌相机用形态学处理 + Canny 边缘检测**估物体朝向以对齐抓取位姿；随后启动触觉反应式控制器抓取并抬升；"整个过程稳定夹持不掉落"记为成功 | 每物体 **10** 次试验。Table I 逐项：Soccer **10/10**、Baseball **10/10**、Rope **10/10**、Box **9/10**、Drill **5/10**、Hammer **10/10**、Potato Chip **10/10**、Light Bulb **10/10**、Strawberry **10/10**；总体成功率 **93.3%** |
| **在手多轴重定向** | 直径 **40 mm** 球体，用预定义朝向轨迹独立驱动各轴，协调手指运动 | 绕 x、y 轴约 **±15°**，绕 z 轴约 **±20°** |

| **在手分选（singulation）** | 从容器抓取多颗绿豆，用拇指-食指滚动映射到 q3 内收/外展完成逐颗分离；5 类目标物：绿豆、软糖小熊、不规则巧克力球、**7 mm** 直径钢珠、棉签 | 正文给出成功的定性证据（末态每指尖呈单一接触模式）；**分选成功率论文未报告**。全文另称可操作"直径小至 **3 mm**"的物体 |
| **多模态轴孔装配** | 全自主；六棱柱，侧面 **15 mm** 直径孔，**14 mm** 销；顶面 **30×30 mm ArUco** 标记做粗位姿估计，**销的位姿假定已知**；掌先视觉模式估初位姿→接触后切触觉模式（点亮内部照明）→贴面下移找孔心（灰度化 + 梯度边缘 + 轮廓滤波 + 代数圆拟合 + 离群剔除精修圆心）→ 机械臂修正位姿插入 | **10** 次连续试验，总体成功率 **70%**，插入容差 **1 mm** |

### 5.2 论文中唯一的横向对比数字

- 与 **GelSight Mini** 相比，指尖触觉阵列的**传感面积大约 215%**（原文 "approximately 215% larger sensing area"）。
- 与现有带触觉夹爪的遥操作方案 [33] 相比，本文框架**不需要遥操作机械臂或外部动捕系统**——这是定性表述，无数值。

### 5.3 评测口径的三个必须说明的条件

1. **无 baseline**：所有成功率都是本系统的绝对成功率，没有与平行夹爪、拟人手或纯视觉方案在同任务上的对照。因此不能声称"比 X 强 Y%"。
2. **样本极小**：单任务最多 20 次（注射器），其余 10 次/物体或 10 次总试验。65% 与 70% 的置信区间很宽。
3. **阈值未标定公开**：α、T_th、λ1、λ2、w_j、分选的"预设阈值"全部是经验值，正文未给具体数 → 复现时必须自行标定，成功率不可直接对齐。

## 6 · 能力与失败模式

### 6.1 能做（有实验支撑）

- **三种抓取原语**：cage（大/铰接物，如足球、棒球）、power（宽/重物，如锤子）、pinch（易碎物，如草莓、灯泡、薯片）——**指尖触觉使易碎物无损伤抓取**，power 模式 + 主动掌支撑了锤子这类大、宽、薄圆柱物。
- **多轴在手重定向**：40 mm 球体绕三轴 ±15°/±15°/±20°。
- **掌参与的在手操作**：注射器从支架取出 → pinch 抓取 → 中指触发重定向使出口朝下 → **小指映射到掌执行器按压推杆**完成液体转移。
- **微粒分选**：绿豆、软糖、巧克力球、7 mm 钢珠、棉签，可处理小至 3 mm 直径物体；靠触觉接触模式的"多模式 → 单模式"变化判定分离成功。
- **视觉→触觉的模态切换式装配**：15 mm 孔 / 14 mm 销，1 mm 容差，70% 成功率。
- **数据集采集潜力**：掌部自带近场视角，在受限操作空间里补上腰挂相机易被遮挡的盲区（正文明确把这一点作为对 learning-based 数据采集的价值）。

### 6.2 不能做 / 会失败（逐条来自 §V 与实验数据）

| 失败现象 | 论文给出的原因 | 涉及的具体机制 |
|---|---|---|
| **Drill 抓取仅 5/10** | 重量较大 + 质量分布不对称，**在触觉反应式闭合建立足够稳定接触力之前就打滑** | 式 (7) 的 Q 依赖接触演化，力上升滞后于滑移起始；系统无力传感，无法预判 |
| **注射器 13/20（65%）** | 大部分失败发生在**小指动作驱动推杆**时注射器滑落；根因是 **VR 手部追踪遮挡**——头显靠近以捕获小指动作时，拇指或食指偶发丢失追踪，系统把丢追踪**误判为手指松开**，pinch 抓取被意外打开 | 掌执行器由小指手势触发（离散事件），与 pinch 保持状态共用同一套手势识别；追踪一断，状态机即翻车 |
| **分选无量化成功率** | — | 只给了视觉/触觉定性证据，未统计 |
| **轴孔装配 3/10 失败** | **论文未报告**失败原因（正文只给总体 70%） | — |

论文给出的缓解方向（作者自述）：改用**数据手套**，或用**另一只手**来控制掌的驱动。

### 隐含假设 (Hidden Assumptions)

1. **"销的位姿已知"**——轴孔装配原文明确写 "the peg pose is assumed known"。这条假设一旦去掉（真实产线未知孔位），整套流程需要额外的销定位环节，70% 不能直接外推。
2. **物体能被单目 + Canny 可靠分割**：抓取前的朝向估计依赖形态学处理与边缘检测，隐含物体与背景有足够对比度、轮廓闭合、无强反光/透明（灯泡是特例且成功了，但正文未讨论边界）。
3. **ArUco 标记在视野内且尺寸足够**：30×30 mm 标记 + 50° FOV，隐含工作距离受限；超出范围即丢粗位姿。
4. **触觉信号随接触单调增长**：式 (7) 的 ΔC 与 Σ S 都假设"压得更紧 → 数更大"，对软/薄/易屈服物体（薯片、软糖）不必然成立。
5. **经验阈值跨物体可迁移**：α 与 T_th 是单一组经验值，未做按物体类别分档，隐含"一个阈值能覆盖从草莓到钻机"。
6. **被动柔顺足以吸收几何差异**：Fin-Ray 的被动变形被当作"无需显式接触建模"，隐含物体刚度远高于 TPU 且接触面不会发生大幅滚动。
7. **中间系 ℐ 的常量 SE(3) 变换长期有效**：人手腕系 → 中间系的映射是**常量**，隐含 VR 追踪坐标系与机器人基座之间标定稳定、不漂移。
8. **手势可被左手稳定识别**：cage/power/pinch 切换依赖"左手掌开合"手势；推杆依赖小指动作。两者都假设 VR 在特定头显姿态下仍能持续追踪所有相关手指——**这正是 65% 成功率的破口**。
9. **两种掌模态不同时可用是可接受的**：视觉与触觉互斥（LED 单状态），隐含任务能切成"先看后摸"的两段式，而非需要边看边摸。

**面试 Tip（被问到"这篇和主动手掌/视触觉手掌的工作有什么本质不同"时怎么答）**：
> 不要说"它也有主动手掌"——那是 [15-17] 已经做过的事。要答**两点正交的新意**：第一，**掌的感知是"一膜双模"而不是"两套硬件"**——镀镜面漆的硅胶膜靠 LED 亮灭在"透明窗口"和"光学触觉面"之间切换，把 [19] 的机械切换机构和 [20] 的双目系统一起省掉了，代价是视觉与触觉**不能同时工作**，所以任务必须写成"先看后摸"的状态机。第二，**它把非拟人三指的重定向当成一个"降维"问题而不是"IK 问题"**——先用左手手势把配置空间切成 cage/power/pinch 三个一维子空间（顺手把 q1 定死、q3 锁住），只剩 3 指 × &#123;q2, q4&#125; 共 6 个关节做优化，再用一个常量 SE(3) 把人类手腕系挪到中间系 ℐ 来绕开"基座在几何中心而非腕部"的错配。如果面试官继续追问局限，就诚实说：**这套东西没有学习、没有 baseline、阈值全靠经验，65% 的注射器成功率就是被 VR 追踪遮挡打掉的**。

## 8 · GitHub-validated pitfalls (atlas 联动, 2026-10-25)

> **诚实声明**：论文全文**没有给出任何 github.com 仓库链接**。唯一出现的项目地址是 `https://yuhochau.github.io/vtap/`，且为**纯文本形式的项目主页**（非可点击的 github.com 代码仓库链接）。因此本节**不存在可核验的 issue 流**，以下 3 条 pitfall 全部由 **§6 的具体失败模式 + §III 的具体方法约束**推导而来，**未经社区 issue 验证**，不包含任何 issue 编号、commit 或引文。

### Pitfall 1 · 「小指驱动掌」的手势状态机会被一次追踪丢帧打穿
- **方法约束**：§III-C 的 gesture-conditioned subspace 中，q1 由**离散手势事件**更新（左手掌开合切换 cage/power/pinch），q3 在非分选模式下**直接锁死**；掌的线性执行器则由"小指收缩"这一事件触发。
- **失败模式**：§V 明确记录 —— 头显靠近以捕获小指动作时，拇指/食指偶发丢失追踪，系统**把丢追踪解读为 finger release**，pinch 抓取被意外打开，导致注射器在推杆阶段滑落（13/20）。
- **落地后果 / 复现建议**：任何照搬该状态机的实现，都会在"抓取保持"与"掌驱动"共用同一套手部追踪时出现**状态翻转放大效应**——单帧丢失即可让 q1 跳到另一抓取原语，且因为是离散更新，不会像连续关节那样被下一个优化帧平滑回来。复现时必须加**去抖 / 迟滞（hysteresis）**，或按作者建议改用数据手套 / 另一只手控制掌。

### Pitfall 2 · 单标量阈值 Q > T_th 在"易碎"与"沉重"之间不可调和
- **方法约束**：§IV-A 式 (7) 把"接触面积变化 ΔC_f"与"信号强度 Σ S_f"压成**一个标量**，由 α ∈ [0,1] 平衡，T_th 为**经验选取**的单一阈值。
- **失败模式**：§V 记录 Drill **5/10** —— 因重量大、质心不对称，**在 Q 触发前就已滑落**；同一套阈值下 Strawberry / Light Bulb / Potato Chip 却都是 10/10。
- **落地后果 / 复现建议**：把 T_th 调低会压碎易碎物、调高会让重物滑落，两种失效方向在**同一个标量上直接冲突**，无法靠调一个数同时解决。工程上必须按物体类别/预估质量**分档 α 与 T_th**，或引入能预测滑移的量（力/滑移检测），而不是继续堆叠触觉能量项。

### Pitfall 3 · LED 开关既切模态、也切掉了系统的成像基准，每次上电都要重标定
- **方法约束**：§III-B 的双模机制完全依赖**镜面漆的受控光学透明度** —— LED 灭 → 透明（外部场景成像）；LED 亮 → 内部光反射至形变面（光学触觉）。两模态共用同一颗 GC0307，且**互斥**。
- **失败模式**：§IV-D 的孔心定位靠"灰度化 + 梯度边缘 + 轮廓滤波 + 代数圆拟合 + 离群剔除"，而梯度阈值直接受照明亮度与膜面反射率支配；同时 §V 已暴露 70%（3/10 失败）且**未报告失败原因**，其中一类典型来源就是触觉成像基准漂移。
- **落地后果 / 复现建议**：环境光强变化、LED 老化、镜面漆磨损、硅胶膜更换（传感盒是**可拆卸**的）都会同时改变两个模态的成像基准。部署时需要：(a) 每次更换传感盒后重做触觉图像的增益/偏置标定；(b) 视觉模式下做外部光抑制或固定工位遮光；(c) 圆拟合的梯度阈值做自适应而非硬编码。此外，**视觉与触觉不能同时工作**这一硬约束意味着任何"边看边摸"的闭环策略在这套硬件上无法直接实现，必须改写为两段式状态机。
