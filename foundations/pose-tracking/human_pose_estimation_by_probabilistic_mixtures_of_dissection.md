# 高斯与均匀分布概率混合下的人体姿态估计 (Human Pose Estimation by Probabilistic Mixtures of Gaussian and Uniform Distributions)

> **发布时间**：2026-10-08（arXiv:2610.14093v1 [cs.CV]）
> **论文 / 模型名**：Probabilistic Mixtures of Gaussian and Uniform Distributions（作者未给方法起缩写，全文以 "Ours (GMM) / Ours (Volume) / Ours (Softmax)" 指代各变体）
> **核心定位**：一个 **post-hoc、零重训练、零新增可学习参数** 的解码层——拦截 raw heatmap，把它显式建模成 `GMM + 均匀背景` 的连续密度，从而在**精度与 DARK 持平**的前提下额外拿到多模态假设、几何不确定度与 OoD 报警能力。

现代 HPE 把网络输出的整张概率热图强行压成**一个坐标 + 一个峰值置信度**，遮挡与拥挤场景下这份"多峰犹豫"被永久丢弃。本文不改网络、不重训，只在解码端把热图当密度读：均值给坐标，全方差给不确定度；代价是后处理在 CPU 上要花 1311.7–1391.6 ms/实例。

## X-Ray 开场

姿态网络输出的 heatmap 本质上是一张"关节可能在哪"的概率地形图，但 `argmax` 和 DARK/UDP 这类亚像素解码器只取最高那一点，把"左右腕各有一个峰"这种关键信息直接扔掉。本文的做法是：把热图归一化成概率质量函数，用 Monte Carlo 采样 + EM 拟合一个 **K∈&#123;1,2&#125; 个高斯 + 一个均匀背景**的混合模型，坐标取高斯成分的空间期望，不确定度取标定后的协方差体积行列式。对 spatial AI 研究者的意义在于：**不确定度可以是解码器的副产品，而不是训练目标**——任何产出 heatmap 的 frozen backbone 都能直接挂上这一层，且它的参数化形式天然通向多视图 3D 三角化（绕开 𝒪(N³) 体素内存）。

## 1 · 核心架构 / 方法总览

### 1.1 系统组件对比表

| 模块 | 输入 | 输出 | 训练 / 推理差异 |
|---|---|---|---|
| Backbone（HRNet-W32 / ResNet50 / ViTPose-Small） | 256×192 top-down crop | raw heatmap `H_k`（17 关节） | **完全冻结**，零重训、零架构改动 |
| Stage 1 · 随机 TTA | bbox + 5 尺度 × 水平翻转 | 多视角 heatmap 集合 | 推理 only |
| Stage 2a · 连续聚合 | 反变换对齐后的 heatmap | 加权融合密度 `P_k(x)` | 推理 only；抑制 heatmap poisoning |
| Stage 2b · Monte Carlo 采样 | 温度锐化密度 `P_T` | N=1000 个连续样本 `x̃_m` | 推理 only；含 1/12·I 均匀去量化 |
| Stage 3 · GMM+Uniform（EM + BIC） | 样本集 | `{π_k, μ_k, Σ_k}`、`π_u` | 推理 only；k-means++ 初始化 |
| Stage 4 · MRF MAP-BP | K=2 节点的 μ 候选 | 修正后坐标 | 推理 only；K=1 节点完全旁路 |
| 不确定性层 | `Σ_final`、`π_u` | `U_gmm`、`U_adapt` | 推理 only |

**关键点**：整张表里没有一行是"训练"。论文明确声明 "requiring no architectural modifications or retraining" 与 "zero additional learnable parameters"。

### 1.2 关键机制

**⚡ Eureka Moment：被 argmax 丢掉的那团概率质量本身就是信息——只要把它参数化成 `GMM + 均匀汇`，亚像素精度、多模态假设、可标定几何不确定度这三件事就是同一个参数化的三个免费副产品。**

三个机制串起来才有这个效果：
1. **均匀成分是"概率汇"**（论文 Figure 2）：极端退化下 EM 把弥散背景噪声倒进 `π_u`（0.062× 退化时 `π_u = 14.51%`），而不是让高斯方差爆炸去覆盖它——所以高斯的椭圆仍保持真实物理朝向和亚像素定位。
2. **全方差公式让"左右肢混淆"自动变成大不确定度**：`Σ_total` 里含 `(μ_k − μ_global)(μ_k − μ_global)^T` 项，双峰间距沿混淆轴**二次**撑大协方差体积。这是"limb swap 检测"不需要额外分类器的原因。
3. **BIC 当结构闸门**：只在 K=1 与 K=2 间选，且惩罚极重（见 §3 的 41.45 nats 门票），保证 MRF 只在证据压倒性时才被触发。

## 2 · 数学核心

📌 **Napkin Formula**

```
p(x̃|Θ) = Σ_{k=1..K} π_k 𝒩(x̃|μ_k, Σ_k) + π_u 𝒰(x̃|A),   K ∈ {1,2}
x̂ = Σ_k π̃_k μ_k                       ← 坐标 = 高斯成分的空间期望
U_spatial = det(Σ_final)              ← 不确定度 = 标定后协方差体积
```

一句话直觉：**把 heatmap 当密度读，均值给坐标，全方差给不确定度，均匀项吸收"看不懂的部分"。**

### 目标 → 公式 → 变量 → 直觉

**(a) 热图 → 概率质量函数**（论文 Eq.1）
```
Ĥ_k(x,y) = max(0, H_k(x,y)) / Σ_{i,j} max(0, H_k(i,j))
```
`H_k` 是第 k 个关节的 raw heatmap。截断负值 + 全局归一，使其满足 Kolmogorov 公理。**为什么必须拦截原始热图**：DARK 的 Taylor/Hessian 展开在解析上就把多峰地形抹平了，事后再想恢复已经来不及。

**(b) 仿射映射的 codec 分歧**（论文 §3.2，易被忽略的工程陷阱）
```
A_MSRA = diag(s_input / s_hm)                  ← 整数比例
A_UDP  = diag((s_input−1)/(s_hm−1))            ← 分数比例
```
`x_img = A·x_hm + b`。把协方差反投影到图像坐标系时，用错这一项会引入**非对称空间漂移**。直觉：`s=256→64` 时 MSRA 给 4.0，UDP 给 `255/63 ≈ 4.0476`，1.2% 的尺度差在椭圆长轴上会被放大成可见的方向偏斜。

**(c) TTA 的连续置信加权**（论文 Eq.2–4）
```
𝒞_k^(n) = (ρ_k^(n))^α · (1 − 1/(1 + (ρ_k^(n)/(μ_k^(n)+ε))/τ))^β
w_k^(n) = 𝒞_k^(n) / Σ_m 𝒞_k^(m)
P_k(x) = Σ_n w_k^(n) · H̃_k^(n)(x)
```
`ρ = max(Ĥ)`（峰高），`μ = 𝔼[Ĥ]`（均值）。**直觉**：中毒热图满足 `ρ ≈ μ`（平坦），峰均比趋零 → 权重自然归零，不需要不可导的硬阈值。`τ=10.0, α=β=1.5` 为论文配置。

**(d) 采样与去量化**（论文 Eq.5 + §3.4）
```
P_T(x) = exp((1/T)·log(P_k(x)+ε)) / Σ exp((1/T)·log(P_k(x)+ε))     T=0.3
x̃_m = x_m + ε,  ε ~ 𝒰([−0.5,0.5]²),  Cov(ε) = (1/12)·I ≈ 0.0833·I
```
**关键设计决策**：这 1/12 的方差偏置**故意不扣回**，论文把它当作"1×1 像素格子的量化下界正则"，与 Tikhonov 互补，保证 `Σ_k` 严格正定。直觉：整数采样点会让多个样本落到同一像素，经验协方差矩阵降秩、不可逆，后续 Mahalanobis 距离计算会崩。

**(e) 混合模型**（论文 Eq.6）
```
p(x̃|Θ) = Σ_k π_k 𝒩(x̃|μ_k, Σ_k) + π_u 𝒰(x̃|A),   Σ_k π_k + π_u = 1
```
`A` = 输入 bbox 面积 → 均匀项是**常密度背景汇**。`Θ = {π_k, μ_k, Σ_k} ∪ {π_u}`，EM 求解。

**(f) 数值稳定**（论文 Eq.7–8）
```
Σ̃_k = Σ_k + (λ_reg − min(0, λ_min))·I            λ_reg = 1e-4
BIC = p·ln(M) − 2ℒ                                 M = 1000
```
Tikhonov 项按谱分解动态注入（只在最小特征值过低时）。BIC 是保守闸门：只有结构模糊的证据压倒性时才允许 K=2。

**(g) MRF 的成对势**（论文 Eq.9–10）
```
argmax_Y [ Σ_i log φ_i(y_i) + Σ_(i,j) log ψ_ij(y_i, y_j) ]
log φ_i(y_i) = log π_k^(i) − ½ log det(Σ_k^(i)) − log(2π)
ψ_ij = exp( −(‖y_i−y_j‖₂ − μ_ij^bone·√A_box)² / (2(σ_ij^bone·σ_mult·√A_box)²) )    σ_mult = 2.0
```
`μ_ij^bone`、`σ_ij^bone` 从 **COCO train2017 可见实例**经验统计。一元势对高弥散假设施加惩罚（`−½ log det Σ`）；二元势把 2D 欧氏骨长拉向先验均值，`σ_mult=2.0` 是给投影缩短留的松弛。

**(h) 不确定度：全方差 + 运动学标定**（论文 Eq.11–13）
```
μ_global = Σ_k π̃_k μ_k,   π̃_k = π_k / Σ_j π_j
Σ_total  = Σ_k π̃_k [ Σ_k + (μ_k − μ_global)(μ_k − μ_global)^T ]
Σ_final  = Σ_total / (s·κ_j)² + εI                    ε = 1e-6
U_gmm    = 1 − exp(−β · det(Σ_final))                 β = 0.1
```
`κ_j` 是 COCO 的关节级容差常数，`s²` 来自 bbox 面积。**注意均匀项被刻意排除在 `Σ_total` 之外**：均匀分布跨整个 bbox 的方差比局部关节激活大几个数量级，混进去会直接饱和椭圆，把真正的几何歧义淹没。

**(i) 自适应 Softmax 融合**（论文 Eq.15）
```
U_adapt = (e^{U_base}·U_base + e^{U_gmm}·U_gmm) / (e^{U_base} + e^{U_gmm}),   U_base = 1 − P_DARK
```
避开 max-pool 的非可导脊线；论文报告 `β=0.1` 是数据集无关的统一工作点。

## 3 · 带数字走一遍（玩具设定，用于演示，非论文实验结果）

**设定**：一个关节的 2D 热图呈双峰，`μ₁=(10,10)`（`π₁=0.55`）、`μ₂=(14,10)`（`π₂=0.45`），每峰各向同性 `Σ_k = 0.25·I`。采样 `M=1000` 点。

**Step 1 · 全方差计算**

`μ_global = 0.55·(10,10) + 0.45·(14,10) = (11.8, 10)`

```
Σ_total = 0.55·[0.25I + (−1.8,0)(−1.8,0)^T] + 0.45·[0.25I + (2.2,0)(2.2,0)^T]
        = 0.25I + [0.55·3.24 + 0.45·4.84]·diag(1,0)
        = diag(0.25 + 1.782 + 2.178, 0.25)
        = diag(4.21, 0.25)
```

`det(Σ_total) = 4.21 × 0.25 = 1.0525`

对比单峰情形（若网络只给一个峰）：`det = 0.25 × 0.25 = 0.0625`。**体积放大 16.8×**。

这里有个必须点破的细节：**一维情形下全方差恒等于总方差，无论怎么分组都是 4.21**——也就是说 trace 类的标量指标根本区分不了"一个宽峰"和"两个窄峰"。论文选 **determinant** 而非 trace，正因为 det 对沿混淆轴的**各向异性**敏感（数学上即 `det(σ²I + π₁π₂ d dᵀ) = σ²(σ² + π₁π₂‖d‖²) > σ⁴`）。这是"limb swap 自动变成大不确定度"的真正机制。

**Step 2 · 加入去量化偏置（论文刻意保留）**

`Σ → Σ + (1/12)I ≈ Σ + 0.0833I`：

`diag(4.2933, 0.3333)`，`det ≈ 1.4311`。体积涨了 36%，但换来了 `Σ` 严格正定、EM 可逆——论文明确说这是 "principled lower-bound regularization penalty"。

**Step 3 · BIC 的结构闸门有多严**

按 2D 全协方差计数（`p = 6K`：K 个自由混合权重 + 2K 个均值 + 3K 个协方差参数）：

```
BIC(K=1) = 6·ln(1000) − 2ℒ₁ = 41.45 − 2ℒ₁
BIC(K=2) = 12·ln(1000) − 2ℒ₂ = 83.09 − 2ℒ₂
ΔBIC = 41.45 − 2(ℒ₂ − ℒ₁)
```

**要在 K=1 和 K=2 之间翻盘，对数似然必须多赚 20.7 nats（即 2Δℒ > 41.45）。** 这就是论文所谓 "heavily penalizes unnecessary complexity" 的量化含义，也解释了为什么 `K=2` 的频率能当场景复杂度指标用：COCO clean 只有 4.9%，Extreme 退化下涨到 59.4%，OCHuman baseline 就有 27.3%（遮挡自带双峰）。

**Step 4 · 结果解读**

- 坐标用 `μ_global = (11.8, 10)`，落在两峰之间但偏向权重大的峰——这正是"保留犹豫"的代价：如果真值是 (10,10)，MRF 该把它拉回去。
- `U_gmm` 走 Eq.13 会饱和到接近 1，触发 OoD 报警；论文真实场景给的参照值是 `det(Σ_final) = 34.58`（Figure 9 的左眼缺失案例）。
- 若 K=2 且 MRF 被触发，二元势会比对 `‖y_i−y_j‖` 与 `μ_ij^bone·√A_box`；论文 Figure 10 的实测是 `d=8px` 对 `μ=24px` 的先验，结果被推开 **19 px** 造成灾难性 swap——这是玩具例子推不出的、只能靠真实数据暴露的失败。

## 4 · 工程视角

| 项目 | 论文报告值（逐字） | 备注 |
|---|---|---|
| 连续 TTA 聚合（Stage 2a） | 3.2–3.6 ms | 论文称 "negligible overhead" |
| MRF Belief Propagation（Stage 4） | 1.58–1.62 ms | 同上 |
| 采样 + EM + BIC（17 关节，单线程 CPU） | **1311.7–1391.6 ms / 实例** | 延迟主导项 |
| 全 pipeline 吞吐 | **0.5–0.7 FPS** | 论文称 "unsuitable for real-time edge deployment" |
| 峰值 VRAM（三种 backbone） | 118–265 MB | 输入 256×192 |
| 输入分辨率 | 256×192 | 固定，保证跨 backbone 公平 |
| Backbone 前向延迟 | **论文未报告** | 只报告了后处理分阶段耗时 |
| TTA 侧前向次数开销 | **论文未报告**（配置为 5 尺度 × 水平翻转的笛卡尔积） | 论文未把 backbone 侧开销计入 profiling |
| GPU 化后的后处理延迟 | **论文未报告**（仅提出"可作为 batch-tensor GPU 算子实现"的路径） | |
| 硬件 | CPU 后处理（host RAM）+ NVIDIA RTX A6000（致谢中注明由 NVIDIA 捐赠） | 热图被搬到 host RAM 上执行后处理以保持框架无关 |

**核心 trade-off 三句话**：

1. **零参数 vs 零加速**。整层没有任何可学习参数，但也完全没有为速度做过优化——瓶颈精确地落在"迭代式混合拟合"上（采样 → EM → BIC），而 MRF 图推理与内存搬运几乎免费（1.58–1.62 ms / 118–265 MB）。
2. **延迟是可并行化的延迟**。17 个解剖关节的 MC 采样与 GMM 聚类**条件独立**，因此这一层对关键点维度完全可解耦。论文把这条当作"通向交互帧率的直接路径"，但没有给出实测——任何声称"GPU 化后能到 X FPS"的说法在本文里都是 `UNVERIFIED`。
3. **内存不是约束，延迟才是**。118–265 MB 的峰值 VRAM 意味着这一层不会在边缘设备的显存上碰壁；0.5–0.7 FPS 才是它进不了实时环路的唯一原因。

## 5 · 数据与评测

### 数据组成

| 数据集 | 论文选它的理由 | 评测规模 |
|---|---|---|
| COCO val2017 | "well-framed and isolated individuals"，常规基线 | 每条件 500 张 |
| CrowdPose | "high density of overlapping individuals"，拥挤鲁棒性 | 每条件 500 张 |
| OCHuman | "severe, heavy occlusions"，结构性完整性与不可见关节 | 每条件 500 张 |

**退化策略**：不是注入高斯噪声或均匀模糊，而是**确定性下采样**（resolution loss），从 `Clean 1.00×` 到 `Extreme 0.062×`，逼网络在受限像素证据下推断几何。每个数据集 × 每个退化level 都跑恰好 500 次独立推理，保证指标轨迹反映架构韧性而非样本量波动。

### 评测设置

- **Backbone**：HRNet-W32（DARK 解码，MMPose 内建）为主；ResNet50（DARK）与 ViTPose-Small（UDP）作跨架构验证（结果在主文之外）。
- **配置**：N=1000 样本/关节，T=0.3，seed=42，EM ≤100 iter 或 1e-3 对数似然收敛，λ_reg=1e-4，BIC 在 K∈&#123;1,2&#125; 间选；TTA 用 0.85/0.925/1.0/1.075/1.15 五尺度 + 水平翻转，α=1.5 / β=1.5 / τ=10.0；MRF 的 σ_mult=2.0；融合 β=0.1。
- **指标**：OKS；Loose Swaps（对侧 OKS 高于同侧，且对侧匹配 OKS>0.3）；Catastrophic/Strict Swaps（对侧超越同侧 >0.7）；AUSE（越低越好）；ECE；AUROC（visible vs. `vis=0` 二分类）。

## 6 · 能力与失败模式

### 能做（有具体数字支撑）

- **精度无损地拿到概率表示**：干净图像上三个数据集与 DARK 差 ≤ 0.0008 OKS，退化轨迹也完全镜像。
- **显式多模态假设**：K=2 时同时保留 `Mode 1: w₁=0.56 / Mode 2: w₂=0.43` 两个候选及其 2σ 椭圆，而 DARK 只能二选一硬commit。
- **抗 heatmap poisoning**：把中毒尺度从"污染源"降级为"低权重参与者"（`w_k = 29.3%`），单例 OKS 从 0.69 拉回 0.82。
- **拥挤场景的 OoD 报警**：CrowdPose 单峰预测上 AUROC 0.9435 vs 基线 0.3838，这是本文最硬的一块结果。
- **保留"看不见"这个信息**：`π_u` 作为与几何正交的缺失指标，随退化单调上升。

### 不能做 / 会崩

1. **常规场景的精度提升**：没有。Table 2 全是负 Δ；TTA 下 DARK 仍领先 0.0002–0.0020 OKS。
2. **2D MRF 在透视缩短下会主动帮倒忙**：这是全文最诚实的负面结论。Figure 10 里 GMM 本来把缩短的下肢定位正确（`d=8px`），2D 欧氏骨长先验（`μ=24px`）把它判为"解剖违规"，硬推开 **19 px** 造成 strict swap。量化后果：CrowdPose Extreme 175（vs GMM 171、DARK 169）、OCHuman Extreme 254（vs GMM 249）。
3. **K>2 的歧义无法表达**：BIC 只在 1 与 2 间选，三峰或连续弥散的多假设场景只能退化成 K=2 或 K=1。
4. **峰值置信度在遮挡下反向**：DARK `1−P_DARK` 在 CrowdPose 的 AUROC 0.3838 是"自信地锁在背景杂物上"（`P_DARK=0.70` 而关节根本不存在）。
5. **实时**：0.5–0.7 FPS，论文自己写明不适合实时边缘部署。

### 隐含假设 (Hidden Assumptions)

| # | 假设 | 一旦不成立会怎样 |
|---|---|---|
| A1 | 归一化后的单通道 heatmap 可当作该关节的空间 PMF，且 17 个关节互相独立 | 关节间相关性（如腕-肘耦合）无法进入密度；MRF 是唯一的事后补偿，且它是硬约束 |
| A2 | bbox 内的背景噪声可用**常密度** `𝒰(x|A)` 近似 | 若误检集中在 bbox 某一角落（真实多人场景常见），均匀汇吸收不掉，`π_u` 低估缺失、`Σ` 被拉偏 |
| A3 | 混合成分数 `K ≤ 2` 足够覆盖真实歧义 | 三人重叠或半身出框时真实峰数 >2，BIC 被迫选 K=2，把第三峰并入某个高斯 → 方差虚高 |
| A4 | 骨长先验 `μ_ij^bone, σ_ij^bone` 从 **COCO train2017 可见实例**统计，可用 `√A_box` 去归一化 | 跨数据集/跨人群（儿童、极端体型）时先验失配；`√A_box` 是各向同性缩放假设，对非等比 bbox 不成立 |
| A5 | 2D 欧氏骨长 ≈ 3D 骨长的投影 | 透视缩短下直接失效，见失败模式 2 —— 论文自己把这个假设列为 3D 扩展的首要动机 |
| A6 | `Cov(ε) = (1/12)I` 的去量化偏置应**保留**而非扣除 | 若下游需要绝对方差（而非排序），这会引入 0.0833 的系统性体积膨胀；论文的立场是"这是量化下界的正则"，属于主观取舍 |
| A7 | 峰均比 `ρ/μ` 能区分"锐利真峰"与"扩散中毒" | 若真实关节本就宽弥散（远距离小目标），会被误判为中毒而遭衰减 |
| A8 | 均匀项与高斯项正交可分（`π_u` 独立指示缺失） | `π_u` 上升也可能只是模型对背景敏感，而非关节不可见；论文未给出两者的判别实验 |

## 7 · 与相关工作对比

| 维度 | DARK / UDP | RLE | 标准离散 TTA | 本文（GMM+Uniform） |
|---|---|---|---|---|
| 输出范式 | 亚像素坐标 | 亚像素坐标 | 亚像素坐标（平均后解码） | **连续概率分布** |
| 量化误差对策 | Hessian / Taylor 展开 | Normalizing Flows | 无（像素级平均） | MC 采样 + 均匀抖动 |
| 不确定性输出 | 峰值 `P_max` / `P_DARK` | 单峰方差 | 峰值 | **多模态协方差体积 + `π_u`** |
| 多模态感知 | 无 | 无（单峰假设） | 无 | **显式（K=1/2，BIC 选）** |
| OoD 拒识 | 弱（启发式） | 中 | 弱 | 论文自评 **High** |
| 是否需重训 | 否 | **是**（架构改动 + 端到端） | 否 | **否**（零参数、零架构改动） |
| 额外推理开销 | ≈0 | ≈0（test-time） | N 次前向 | 1311.7–1391.6 ms CPU 后处理 |

论文自己的定位（Table 1）是：DARK/UDP 与 RLE 分别占住"精度"和"概率化"两个角，但都**假设单峰**；本文用后验混合模型同时拿到亚像素精度、多模态、OoD 三件事。

**🎤 面试 Tip**：如果被问"这个方法比 DARK 强在哪"，**绝对不要答"精度更高"**——Table 2 全是负的 Δ（−0.0002 到 −0.0008 OKS），TTA 下还落后 0.0002–0.0020。正确答法是三段式："① 精度上它是**持平**，不是提升，这是论文的明确设计目标（证明概率化不牺牲精度）；② 真正的增量是**在零重训前提下多拿到两样东西**——多模态假设（K=2 保留 0.56/0.43 两个候选不被压成一个点）和可标定的几何不确定度（CrowdPose 单峰 OoD AUROC 0.9435 vs 基线 0.3838）；③ 代价也很明确：CPU 后处理 1311.7–1391.6 ms/实例，0.5–0.7 FPS，且 2D MRF 在透视缩短下会**反向伤害**（CrowdPose Extreme 175 vs 169）。"

## 8 · GitHub-validated pitfalls (atlas 联动, 2026-10-18)

**Repo 状态说明**：论文 "Data and Code Availability" 一节以**纯文本**给出 `https://github.com/santiago-git19/probabilistic-pose-gmm.git`，但未以可点击超链接形式嵌入正文；且论文 2026-10-08 发布、距今仅 10 天，**暂无可验证的社区 issue 流**。因此以下 4 条 pitfall **全部由 §6 失败模式 + §3 方法约束推导，未经 issue 验证**，不含任何 issue 编号或 commit hash。

**P1 · 用错 codec 的 scale convention → 协方差椭圆方向/尺度漂移**
- 来源失败模式：§6 A5 / §3.2 的仿射映射。
- 方法约束：论文 Eq. 明确区分 `A_MSRA = diag(s_input/s_hm)`（整数比例）与 `A_UDP = diag((s_input−1)/(s_hm−1))`（分数比例）。
- 触发条件：把 HRNet（MSRA 系）的映射矩阵套到 ViTPose（UDP 系）上，或反之。后果是连续椭球反投影时出现非对称漂移，坐标本身可能只差亚像素，但 `det(Σ_final)` 会系统性偏斜，直接污染 AUSE 与 AUROC 的排序。**MMPose 的 `codec` 字段必须与后处理矩阵成对切换。**

**P2 · 跳过均匀去量化 → EM 在 M-step 崩溃**
- 来源失败模式：§3.4 的 "covariance collapse"。
- 方法约束：采样点是**整数像素坐标**，多个样本落在同一 `(x,y)` 会让经验协方差矩阵降秩、不可逆，Mahalanobis 距离失效。
- 触发条件：为了"干净"而删掉 `ε ~ 𝒰([−0.5,0.5]²)` 这一步。**必须保留 1/12·I**，且按论文立场**不得事后扣回**——扣回虽然"数学上更无偏"，但会重新引入近奇异矩阵。

**P3 · 无 k-means++ / 无 Tikhonov → 死成分与非法椭圆**
- 来源失败模式：§6 A3 的 K=2 强制拟合。
- 方法约束：论文 Eq.7 的 Tikhonov 按谱分解动态注入（`λ_reg=1e-4`），且对 `π_k < 10⁻³` 的成分主动监控。
- 触发条件：BIC 选了 K=2 但第二个峰实际只是几个共线离群点 → EM 收敛到退化簇 → `Σ₂` 最小特征值 ≤ 0 → `det(Σ_final)` 为负或复数 → `U_gmm` 的 `1−exp(−β·det)` 直接失效。**初始化必须用 k-means++，正则必须按特征值条件触发而非固定加。**

**P4 · 忘记关闭 MMPose 内建 `flip_test` → 双重翻转，自定义聚合被绕过**
- 来源失败模式：§4.1.3 的配置说明。
- 方法约束：论文明确设置 `test_cfg={}` 关闭内建 flip TTA，因为外部 pipeline 已显式生成翻转 + 尺度视图。
- 触发条件：直接复用 MMPose 默认 `test_cfg` 时，框架内部会再翻一次并自行平均，导致 ① 翻转视图被重复计数（同一视角权重翻倍）、② 论文 Eq.2–4 的置信加权完全没被执行——而这两点恰恰是消除 heatmap poisoning 的唯一机制。实测表现就是 §6 失败模式 4 的 `OKS_GMM = 0.69`。
