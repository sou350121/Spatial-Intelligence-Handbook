# 从单条未完成示教中同时学习前向与反向技能用于受约束操作 (Learning Forward & Reverse Skills from a Single Unfinished Demonstration for Constrained Manipulation Tasks)

> **发布时间**：2026-07-15（arXiv:2607.13882v1, cs.RO）
> **论文 / 模型名**：LfD-Screw（论文未给模型缩写；项目主页名 `LfD-Screw`）
> **核心定位**：把接触段示教拆成"常螺旋运动原语序列"，从而用**一条可能被截断的示教**同时得到前向"超出示教长度"的执行和**无需额外数据**的反向技能——比 DMP / DMP+admittance / DMP+twist+admittance 三种 one-shot 基线在 4 个受约束任务上成功率高。

导语：接触丰富（contact-rich）操作的传统 LfD 需要多条**完整**示教，而且只学"正向"；一条被安全约束或重复子动作截断的示教通常直接作废。本文的观察是——这类任务本质上是**分段常螺旋（constant screw）运动**，而螺旋结构对"走多远"不变，因此可以从半条示教里既外推出完整行程，又把 twist 取负得到反向技能。

---

## 🩻 X-Ray 开场

它解决的问题：接触丰富任务里示教贵、常常只有一条、而且因为安全/腕部限位/重复子动作而**没做完**；同时现有 LfD 方法学不出"反向技能"（会锁不会开锁）。
它提出的东西：一条 demo → 自由段用 DMP、接触段用**twist 方向分割**切成若干段 → 每段拟合一个 `π_n = {ŝ_n, q_n, h_n, θ_n^end}` 螺旋原语 → 执行时用 **6D admittance 位姿纠偏 + 1D admittance 进度调速**，进度 `θ` 不被示教长度限制；反向只需 `(ω,v) ↦ (−ω,−v)` 并把原语序列倒过来。
对 spatial AI 研究者的意义：这是一个"**用几何不变量替代数据量**"的干净样本——不训练网络、不做视觉闭环，只靠 SE(3) 结构与力反馈把 one-shot 泛化的自由度从"轨迹长度"换成"螺旋参数"，值得作为"结构化表示 vs 规模化数据"的对照锚点。

### 1.2 关键机制

**⚡ Eureka Moment：接触丰富操作的运动段本质是"常螺旋"——而常螺旋结构对执行长度不变，所以"没做完的示教"不是缺陷，它已经足够定义整段任务；把 twist 取负、原语序列倒序，就免费得到反向技能。**

这个洞见一句话把三个痛点连起来解决：
1. **外推**：`T_des(θ) = T_0 exp(ξ̂θ)` 里 `θ` 是自由标量，"示教停在哪" 只是 `θ_n^end` 的一个**参考值**（论文明确：`θ_n^end` 只用于初始化执行速度，**不作终止条件**）。终止由 `θ̇` 持续低于阈值决定。
2. **反向**：螺旋参数 `(ŝ, q, h)` 描述的是一条几何约束轴，正向/反向共用同一条轴 → 反向不需要重新示教、不需要重新拟合。
3. **抗噪**：分割只看**方向**（6D 单位方向特征 + PCA 主方向 + 余弦相似度），不看速度/时间/dwell，因此对短而抖的接触段稳健——这是它与 KTS/AWE 类方法的正面差异。

## 2 · 数学核心

📌 **Napkin Formula**

```
一条示教  =  自由段(DMP)  +  Σ_n  常螺旋原语 π_n = {ŝ_n, q_n, h_n, θ_n^end}
执行:  T_des(θ) = T_0 · exp(ξ̂_n θ)        ← θ 无上界，示教长度只是参考
调速:  θ̇ = θ̇_0 + v_θ,  M_θ v̇_θ + B_θ v_θ = −L   ← 阻力 L 大 ⇒ 自动减速
反向:  (ω, v) ↦ (−ω, −v),  顺序 {π̃_N … π̃_1}      ← 免费，不重学
```

**① 目标：把段内位姿解释成"一个 twist + 一个进度标量"**

```
T_i^rel = T_0^{-1} T_i ≈ exp(ξ̂ θ_i)                                   (6)
```

- `T_0`：该段第一个位姿（**局部系**，所有原语参数都在这个系里）
- `ξ = (ω, v) ∈ R^6`：常 twist；screw 坐标形式 `ξ = [θ̇ŝ; −θ̇ ŝ×q + h θ̇ ŝ]`（Eq.2）
- `θ_i`：进度标量（旋转段≈累计转角；纯平移段≈沿轴位移）

**② 拟合：在 se(3) 里做加权 Huber 最小二乘**

```
r_i = log( exp(ξ̂θ_i)^{-1} · T_i^rel ) ∈ R^6                            (7)
min_{ŝ,q,h,{θ_i}}  Σ_i ρ( ‖ [ w_R r_i^ω ; w_T r_i^v ] ‖₂ )             (8)
```

- `ρ(·)`：Huber（抑制人示教的离群点）
- `w_R / w_T`：平衡旋转与平移误差
- **降维技巧**：不对每个样本优化独立 `θ_i`，而是 `θ_i = s · θ_i*`（`θ_i*` 是单调初始化序列，`s` 是全局尺度）→ 只优化 4 个量 `(ŝ, q, h, s)`。这是 one-shot 场景下"能算完"的关键。
- **纯平移特例**：段内累计旋转可忽略时 → `ω = 0, v = d̂`（`d̂` 由 PCA 给出），`θ_i` 变成沿轴位移。插入/推压类几何正好落在这里。

**③ 执行：名义螺旋 + 双通道 admittance**

```
T_des(θ) = T_0 exp(ξ̂_n θ)                                              (9)
M Δẍ_ee + B Δẋ_ee + K Δx_ee = w_ee                                     (10)   ← 6D 位姿纠偏
F∥ = F_ee^T ŝ_ee,  τ∥ = (τ_ee − q_ee × F_ee)^T ŝ_ee                    (11)   ← 沿轴分量
L  = k_F∥ F∥ + k_T∥ τ∥ + k_F⊥ F⊥ + k_T⊥ τ⊥                              (12)   ← 标量负载
M_θ v̇_θ + B_θ v_θ = −L,   θ̇ = θ̇_0 + v_θ                               (13)   ← 1D 进度调速
```

- 关键权重关系：`k_F⊥, k_T⊥ ≪ k_F∥, k_T∥`——**沿轴阻力调速度，侧向力交给 6D 纠偏**。这是"分工"，避免两个 admittance 互相打架。
- 终止条件：`θ̇` 持续低于阈值（而不是 `θ = θ_n^end`）。

**④ 反向**

```
π_n = {ŝ_n, q_n, h_n, θ_n^end}  →  π̃_n : (ω, v) ↦ (−ω, −v)              (IV-E)
序列 {π̃_N, …, π̃_1}，同一 admittance 控制器；接触释放用正交 dither 探测
```

直觉：`exp(ξ̂θ)^{-1} = exp(−ξ̂θ)`——同一条轴、反方向的进度。所以"锁紧"和"拧松"共享同一个几何约束，不需要第二次示教。

## 3 · 带数字走一遍（玩具设定，非论文数据）

**场景**：peg-in-hole，孔深 `2.5 cm`，示教被截断在 `θ^end = 2.0 cm`（对应论文 Fig.5 的"黑色点线截断"设定）。段内旋转可忽略 → 走**纯平移特例**：`ω = 0, v = d̂`，`d̂` 指向孔轴。

**离线**：分割后该段只有一个原语 `π_1 = {ŝ=任意, q=任意, h→∞ 等价, θ^end = 2.0 cm}`；`T_0` = 接触开始时的末端位姿。

**在线执行**（以下数值为玩具设定）：

| 时刻 | θ (cm) | 实测轴向负载 L | `v_θ = −L/B_θ`（取 B_θ=2.0） | `θ̇ = θ̇_0 + v_θ`（取 θ̇_0 = 3.0 cm/s） | 行为 |
|---|---|---|---|---|---|
| t₀ | 0.0 | 0.5 | −0.25 | 2.75 | 顺畅进入 |
| t₁ | 1.5 | 1.0 | −0.50 | 2.50 | 正常 |
| t₂ | **2.0** | 1.2 | −0.60 | 2.40 | 已越过示教终点，**继续走**（DMP 基线在这里会停） |
| t₃ | 2.4 | 12.0 | −6.0 | **−3.0** | 触底/卡住 → `θ̇` 变负 |
| t₄ | 2.4 | 12.5 | −6.25 | −3.25 | `θ̇ < 阈值`（如 0.2 cm/s）持续 0.3 s → **原语完成** |

结果：插入深度 ≈ 2.4 cm ⇒ 满足论文的成功判据 `> 2.3 cm`。同一示教下 DMP-only 会停在 `2.0 cm` ⇒ 不满足判据 —— 这与 Table II 中 DMP 前向 peg `0/5` 的失败模式一致（**方向一致，不是数字一致**）。

**反向**（同一 `π_1`）：`(0, d̂) ↦ (0, −d̂)` ⇒ `θ` 增大即沿 `−d̂` 退出。执行开始即在接触中，每短周期做一次正交小圆 dither，比较 `median(|L|)` 与阈值；当 peg 完全脱出，`median(|L|)` 掉到阈值以下 ⇒ 接触释放 ⇒ 交给"时间反演 DMP"跑完剩余自由空间。

**分割侧玩具**：设 `B = 10` 样本，`τ_ω = 0.9`、`τ_v = 0.95`（论文正文未给这些数值，此处纯示范）。若块 `j` 的 `⟨μ_j^v, g^v⟩ = 0.62 < τ_v`，且 `j+1` 也不全大于阈值 ⇒ 判 `j` 为过渡区；块内用 Eq.4 扫 `k` 取方向一致性代价最小者作样本级边界。人手的微抖（`⟨·⟩ = 0.93`）不会越过阈值 ⇒ 不会被切碎，这正是它相对速度/dwell 方法抗噪的原因。

**Trade-off 读法**：
1. **用几何换数据**：换来的是"一条示教 + 无训练"，付出的是"必须存在一个常螺旋段"这个结构性前提 + 一个 F/T 传感器。
2. **用 admittance 换精度**：6D admittance 让执行能在接触中"漂"，但也正是它（sustained Cartesian admittance offsets）被作者列为拧螺丝轴/pitch 偏移的来源之一。**纠偏机制本身是误差源**——这是本文最诚实的工程取舍。
3. **不用视觉换确定性**：没有视觉 servoing ⇒ 没有检测抖动 ⇒ 但物体一旦被移动/初始 AprilTag 位姿有偏，只能靠 admittance 吸收，1 mm 级间隙下余量极小。

| Screw driving | 螺钉预拧入，间隙 **approximately 1 mm**，剩两扣；评测随机初始化为**剩 1–3 扣** | forward: 到达拧紧点并由方法自身机制停止；reverse: 退到最后一扣（螺钉失去自支撑）为止 |

## 6 · 能力与失败模式

### 能做（有证据）

| 能力 | 证据 |
|---|---|
| 单条**截断**示教完成全行程 | Table II forward：peg/battery/lock 各 5/5（DMP 系 0/5） |
| **免数据**反向技能 | Table I/II reverse 均为同类最高；反向只用 `(ω,v) ↦ (−ω,−v)` + 倒序 |
| 多接触阶段串联 | battery insertion 明确 3 个连续接触阶段 |
| 亚毫米间隙 | lock opening &lt; 0.5 mm；peg ≈ 1 mm |
| 短/抖接触段的稳健分割 | Table III：`F1@.5 = 0.92 ± 0.24`、VI `0.29 ± 0.32` 全 baseline 最优 |
| 拧紧的**自终止** | 判据即"由方法自身机制停止"（`θ̇` 低于阈值），不靠外部传感器确认 |
| 换物体尺寸/目标位置迁移 | Fig.6，四个任务全成（无量化计数） |

### 不能做 / 会失败（论文自述 + 可推导）

| 失败模式 | 机制 | 论文证据 |
|---|---|---|
| **拧螺丝误差累积** | 轨迹 stitching（Eq.14）+ 周期性 regrasp，初始位姿误差与 pitch 偏差随多圈旋转累积 → 轴失配 | 未完成示教下 screw 只有 `3/5`（前向与反向均是），"mainly caused by initial pose errors and pitch deviations from trajectory stitching" |
| **缺失的接触阶段不会被推断** | "each task-critical contact phase must be at least partially observed; the method extrapolates observed primitives but does not infer absent phases" | 明确写在 IV-A |
| **只泛化到相似接触拓扑的物体** | "generalization mainly to objects with similar contact topology" | 结论 |
| **admittance 自身引入轴偏移** | "possible axis/pitch misalignment from sustained Cartesian admittance offsets during screw-driving motions with regrasping" | 结论 |
| **常螺旋假设被破坏时（jamming/柔性/曲面滑动）** | 段内被迫用**单** twist 拟合；若真实运动轴在段内漂移，`r_i` 无法被 Huber 吸收 | 推导自 Eq.6–8（论文未做该消融） |
| **细粒度边界定位** | 见 `F1@.2 = 0.67 ± 0.44` | Table III |

### 隐含假设 (Hidden Assumptions)

1. **每个接触段是"常螺旋"**：单一 `ŝ, q, h` 在段内不变。⇒ 卡滞（jamming）导致的有效轴漂移、柔性件、曲面滑动都会让拟合残差系统性偏大。论文没有报告 `r_i` 的残差分布，无法据此判定"何时不该用螺旋原语"。
2. **准静态、低速**：admittance（Eq.10/13）没有惯性/摩擦/振动建模。⇒ 高速或高刚度接触下 `M, B, K` 的稳定性未被论证（论文亦自述执行速度未优化）。
3. **wrist wrench ≈ 任务负载**：`L` 是 `F∥, τ∥, F⊥, τ⊥` 的加权标量（Eq.12），隐含"工具重力/偏置已妥善补偿、且这四个分量足以刻画阻塞"。⇒ 换末端工具需重调 `k`（作者承认 load 权重 task-dependent）。
4. **"停下"= "到位"**：完成判据是 `θ̇` 持续低于阈值。⇒ 卡死与到位在信号上不可区分 → **静默假成功**风险（见 §8 P2）。
5. **原语起始位姿可复现**：`T_des(θ) = T_0 exp(ξ̂_n θ)` 中 `T_0` 是**本原语开始时**的实际末端位姿。⇒ 若上一原语在 admittance 偏移下结束，`T_0` 已不是示教时的 `T_0`，整条螺旋轴随之整体平移——这正是"累积误差"的结构性来源。
6. **物体在执行中不动**：只有起始 AprilTag 位姿，无视觉 servoing。⇒ 接触力把物体推开、或人碰到物体，只剩 admittance 的毫米级吸收能力。
7. **示教在 SE(3) 平滑后是几何可信的**：分割只用方向、并做 dwell 清理，隐含"手的微抖被滤掉后不携带任务信息"。⇒ 若某任务的关键转换本身就是"极短微动"（低于 dwell 幅度阈值），会被清理掉。

## 8 · GitHub-validated pitfalls (atlas 联动, 2026-10-25)

**repo 状态核实**：全文只出现项目主页 `https://tuwien-asl.github.io/LfD-Screw/`（`github.io` 为 GitHub Pages 主页，**不是代码仓库**），**正文未出现任何 `github.com/<org>/<repo>` 形式的代码仓库链接**。因此：**无官方代码 repo 信号，无 issue/commit 可核对**。以下 3+ 条 pitfall **由 §6 失败模式 + 方法约束推导，未经 issue 验证**。

### P1 · 缺腕部 F/T 传感器 ⇒ 整条 pipeline 不可用（非降级，是失效）
- **推导链**：§6 隐含假设 3（wrist wrench ≈ 任务负载）+ 方法约束"接触检测 / Eq.10 6D admittance / Eq.12 标量负载 `L` / Eq.13 1D 进度 / 反向 `median(|load|)` 释放探测全部以 `w_ee` 为唯一输入" ⇒ 若平台只有关节电流估计力矩（多数低成本协作臂），`F⊥, τ⊥` 噪声会把 `L` 淹没，`θ̇` 在"该减速"时不减速。
- **工程后果**：不是精度下降，而是**接触检测与终止判据同时失效**（`θ̇` 永不越过阈值 → 原语永不完成）。移植前先确认：是否有 6 轴 F/T，且采样率足以支撑 admittance 阻尼项 `B Δẋ`。

### P2 · 终止判据 = "速度持续低于阈值" ⇒ 卡死与到位不可区分（静默假成功）
- **推导链**：§6 失败模式"`θ̇` 持续低于阈值即视为完成"（IV-D 原文："considered complete when the effective progress velocity remains below a threshold for a sustained duration"）⇒ 任何**非任务完成的阻塞**（孔内有毛刺、螺纹错扣、物体被夹偏）都会产生同样的 `θ̇ → 0`。
- **工程后果**：系统会报告"原语 N 完成"并切到 N+1，最终结果是**错误位姿上的"成功"**，且日志里没有任何异常。若要上产线，必须在 `θ̇` 判据之外加一个独立完成校验（视觉/外部到位开关/扭矩签名比对）——论文本身没有提供。

### P3 · 拧螺丝的周期性 regrasp 让误差随圈数线性累积，不 scale
- **推导链**：§6 失败模式 1（表 II screw `3/5`，归因"initial pose errors and pitch deviations from trajectory stitching, which accumulate over multiple rotations and lead to axis misalignment"）+ 方法约束 Eq.14 的 stitching（`T'_k = T'_{last} ΔT_k`）与"累计旋转 >≈90° 就松手→回退 90°→重抓"⇒ 每圈至少 4 次重抓，每次重抓都在链上再叠一次 pose 误差，而 `ŝ, q, h` 是**离线固定、不再更新**的。
- **工程后果**：1–3 扣（论文评测范围）尚可，扣数越多越差；且误差是**单调累积**而非随机，重复执行不会自愈。作者的缓解方向写在结论里（screw-aware admittance / online primitive adaptation），即当前版本没有。

### P4 · "示教必须覆盖每个关键接触阶段" ⇒ 截断位置决定可用性
- **推导链**：§6 失败模式 2（IV-A 原文："each task-critical contact phase must be at least partially observed; the method extrapolates observed primitives but does not infer absent phases"）+ 方法约束：分割与拟合都是在**已观测到的段**上做的，`π_n` 的 `ŝ, q, h` 没有任何外推来源。
- **工程后果**：截断在 battery 的"阶段 1 之后、阶段 2 之前"⇒ 只学到一个原语，执行到阶段 1 结束就停（且因为 P2 的判据，可能还报"完成"）。部署时必须做一次**离线可观测性检查**：把示教的接触段切出来的原语数量和人工标注的阶段数对比，不等就拒绝上线。

### P5 · 分割/负载的阈值与权重绝大多数是超参，正文未给值
- **推导链**：方法约束——分割需要 `B, τ_ω, τ_v, w_ω, w_v`（IV-B），拟合需要 `w_R, w_T`（Eq.8），执行需要 `k_F∥, k_T∥, k_F⊥, k_T⊥`（Eq.12）与 `M_θ, B_θ, θ̇_0` 及完成阈值；正文只声明"Segmentation parameters are fixed across all tasks; only safety threshold and scalar load weight in Eq. 12 are task-dependent"，并写"Full values are listed on the website"。⇒ **复现所需数值不在论文内**。
- **工程后果**：换 F/T 传感器量程或换末端工具后，`k` 的量纲平衡必然要重调；`τ_ω/τ_v` 与 `τ ∈ {0.2,0.5,0.8s}` 的边界定义耦合（`F1@.2 = 0.67 ± 0.44` 说明敏感）。任何"照论文默认值跑"的复现尝试都会先卡在这一步。

### P6 · 无视觉闭环 + 1 mm 级间隙 ⇒ 初始 AprilTag 位姿误差直接吃掉间隙预算
- **推导链**：§6 隐含假设 6（只做起始物体位姿估计、执行中无视觉）+ 任务约束（peg ≈ 1 mm、lock &lt; 0.5 mm）+ 系统约束（接触 onset 若"方向一致 + 力显著"就触发 spiral search）⇒ 位姿偏差并不被在线估计，只由 spiral search 与 admittance 兜底。
- **工程后果**：定位精度不足时表现为 **spiral search 反复触发**（时间开销，且作者自述执行速度未优化），间隙最紧的 lock（&lt; 0.5 mm）最先退化；若物体在执行中被推动，系统没有任何恢复路径。
