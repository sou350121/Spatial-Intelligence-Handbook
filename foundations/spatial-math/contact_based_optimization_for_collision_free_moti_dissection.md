# 基于接触的百万机器人无碰撞运动规划 (Contact-based optimization for collision-free motion planning for a million robots)

> **发布时间**：2026-10-30（arXiv:2610.41548v1 [cs.RO]）
> **论文 / 模型名**：SCI — **S**equential **C**ontact **I**nsertion（sequential contact insertion）
> **核心定位**：把"每个时刻每对机器人都不许靠近"的稠密非凸约束，换成一张**稀疏的接触事件清单**；轨迹在接触之间解析重建，于是百万机器人的联合优化变成一个只有几百个未知量、块三对角的代数系统——比 SCP 直接转录快 3–4 个数量级，且**连续时间**上真的不撞。

群体轨迹规划的老大难在于两两分离约束把整条轨迹耦合成一个巨大的非凸问题；主流做法（SCP / 直接转录）把 `[0,T]` 打成网格、把 `N` 条轨迹的全部采样点当决策变量一起优化，规模一大就爆。本文的结论是：最优解里真正"起作用"的约束极少——只在**接触**（机器人之间恰好等于最小间距 `R` 的时刻）——所以只需优化接触，其余靠三次 Hermite 解析补出来。

## X-Ray 开场

它解决的问题是：`N` 个双积分器机器人在固定时域内从给定初态换到给定终态，最小化总平方加速度，同时满足两两最小间距 `R` 与位置/速度/加速度盒约束。它提出的做法是：用状态约束最优控制的**必要条件**证明最优轨迹在接触之间是四次导数为零的三次多项式，接触处只允许**加速度连续、jerk 沿连线等大反向跳变**；于是把所有未知量压缩成一串接触变量 `c_ℓ`，解一个方阵系统 `F(c)=0`，再用"发现违规→插入接触→联合调时调状态→删掉负权重接触"的贪心循环（SCI）推进。对 spatial AI 研究者的意义：这是一次**活跃集（active set）优先**的建模示范——当约束数量随 `N²` 爆炸而真正激活的只有 `O(N)` 个时，把表示从"稠密轨迹"换成"稀疏事件"能带来指数级外的规模收益；同时它给出了"连续时间可行性"这一常被网格法偷偷放弃的保证的严格处理方式。

## 1 · 核心架构 / 方法总览

### 1.1 系统/组件对比

| 模块 | 输入 | 输出 | 关键设定 / 训练-推理差异 |
|---|---|---|---|
| **问题 (1)** | 端点状态 `(x_i0,ẋ_i0),(x_iT,ẋ_iT)`、时域 `T`、间距 `R`、盒约束 | 目标 `J[x]=Σ∫‖ẍ_i‖²dt` | 双积分器；`x_i` 绝对连续、`ẍ_i` 平方可积；**无学习参数** |
| **重心分解 (II-B)** | `x_i` | 重心 `x̄`、中心化 `x̃_i` | `J = N‖ẍ̄‖² + Σ‖x̃̈_i‖²`；盒约束会耦合两者 |
| **必要条件 (II-C)** | 活跃集 `𝒜_ij` | 乘子测度 `μ_ij ≥ 0`、`ν_i^(k)` | 连续约束→Radon 测度；`supp(μ_ij) ⊆ 𝒜_ij` |
| **接触重建 (III-A)** | 接触列表 `c=(c_1..c_m)` | 分段三次轨迹 | 每个 `c_ℓ` 有 `2d(N-1)+2` 项、`2d(N-1)` 自由度；段间 Hermite 插值 |
| **匹配方程 (III-B)** | `c` | 残差 `F(c)`、块三对角 Jacobian | `m[2d(N-1)+2]` 个方程 = 同数未知量；块大小 `2d(N-1)+2` |
| **Groups** | 接触列表 | 接触连通分量 𝒢 | 只重建/求解受影响的连通分量；孤立机器人保留无约束三次曲线 |
| **Match** | `c, 𝒢` | 根 / `unresolved` | 阻尼牛顿 + 带状线性解；回溯保证接触时序；恢复用三次 Green 函数 + Powell 混合法 + 半径延拓 + 能量初始化；负乘子反复出现→shifted deflation |
| **Closest** | 轨迹 | 最近对 `(p,q,t*,ϱ)` | Bernstein 系数凸包界 + BVH 双树剪枝；逐段平方距离极小化 |
| **Insert** | 违规 | 新接触（`m_ℓ=0`） | 最深违规优先；同一连通分量每批最多插一次；重合插入时刻在邻域间隙内错开 |

| **Contact removal** | 负乘子接触 | 缩短的 `c` | 贪心插入的纠错机制；删除后局部检查连通分量是否分裂 |
| **训练阶段** | — | — | **不存在**：全文 0 个可学习参数，全部为确定性数值求解；"在线"执行由底层控制器跟踪，论文不涉及 |

### 1.2 关键机制

**⚡ Eureka Moment**：碰撞约束只在**孤立的接触时刻**真正激活——把乘子测度近似成有限个带非负权重的 Dirac 原子后，最优轨迹在接触之间必然是三次多项式，于是"百万条轨迹 × 上千个时间格点"的决策变量，塌缩成"几百个接触 × 每个接触几项状态"的**方阵代数系统**，剩下的轨迹是免费解析重建出来的。

配套的三个结构性事实（缺一不可）：
1. **加速度连续、只有 jerk 跳变**：代价是平方加速度 ⇒ 加速度扮演"状态"角色，接触只传递 jerk 冲量 `m_ℓ ε_i r_pq(t_ℓ)`，等大反向 ⇒ 重心 `x̄` 保持为固定的三次 Hermite 曲线。
2. **块三对角 Jacobian**：`t_ℓ` 处的方程只涉及相邻两段三次曲线 ⇒ 只依赖 `c_ℓ`、邻居接触和固定端点，带状求解 `O(m)`。
3. **接触图分解**：盒约束作用于单机、不破坏分解 ⇒ 只有通过接触相连的机器人才需要联合求解，其余是解析曲线。

## 2 · 数学核心

📌 **Napkin Formula**

```
D_t⁴ x_i(t) = Σ_{j≠i} r_ij(t) μ_ij        μ_ij ≥ 0，且只在接触时刻非零
```

一句话直觉：**每个接触在法向上给两个机器人一对等大反向的 jerk 冲量；没有接触的地方轨迹就是三次多项式。**

**目标（问题 (1)）**

```
min_x  J[x] = Σ_i ∫_0^T ‖ẍ_i(t)‖² dt
s.t.   (x_i(0),ẋ_i(0)) = (x_i0,ẋ_i0),  (x_i(T),ẋ_i(T)) = (x_iT,ẋ_iT)
       ‖x_i(t) - x_j(t)‖ ≥ R
       x_i ∈ ℬ_i^(0),  ẋ_i ∈ ℬ_i^(1),  ẍ_i ∈ ℬ_i^(2)
```
分离/位置/速度约束对全 `t∈[0,T]` 成立；加速度盒约束只要求 almost everywhere。

**重心分解**

```
x̄ = N⁻¹Σ_i x_i,  x̃_i = x_i - x̄,  r_ij = x_i - x_j = x̃_i - x̃_j
Σ_i ‖ẍ_i‖² = N‖ẍ̄‖² + Σ_i ‖x̃̈_i‖²
```
盒约束全为 `ℝ^d` 时，重心独立地最小化自己的代价，且在每个局部极小处就是端点均值的**三次 Hermite 插值** `x̄^H`——这意味着所有"相互作用"的优化都发生在相对坐标 `r_1j` 里。

**平稳性（含盒约束，式 (2)）**

```
ẍ_i = proj_{ℬ_i^(2)} w_i
D_t² w_i = Σ_{j≠i} r_ij μ_ij + ½ (ν_i^(0) - D_t¹ ν_i^(1))
```
`w_i` 是辅助动量；`ν_i^(k) = ν_i^(k),- - ν_i^(k),+`，非负分量支撑在对应的活跃上下界上（互补松弛）。盒全为 `ℝ^d` 时 `w_i = ẍ_i`，退化为 `D_t⁴ x_i = Σ_j r_ij μ_ij`（式 (3)）——这正是 Kamm et al. [16] 两体接触条件向群体的推广。

**匹配条件（单点接触 `t_ℓ` 只涉及 `p<q`）**

```
⟦ẍ_i⟧_{t_ℓ} = 0
⟦x_i^(3)⟧_{t_ℓ} = m_ℓ ε_i r_pq(t_ℓ),   ε_p = +1, ε_q = -1, 其余 ε_i = 0
⟨r_pq(t), ṙ_pq(t)⟩ = 0    （每个内点接触时刻的相切条件）
```

**有限乘子表示与方阵系统**

```
μ_pq = Σ_{ℓ:(p_ℓ,q_ℓ)=(p,q)} m_ℓ δ_{t_ℓ},   m_ℓ ≥ 0
c_ℓ = ( t_ℓ, n_ℓ, ṙ_ℓ, m_ℓ, (r_1j(t_ℓ), ṙ_1j(t_ℓ))_{j∈{2..N}\{q}} ),   r_ℓ = R n_ℓ, ‖n_ℓ‖=1
F(c) = 0 :  m[2d(N-1)+2] 个方程 / 同数未知量
            （匹配 2d(N-1) + 归一化 1 + 相切 1，逐接触）
```

**Proposition 1**：`F(c)=0` 且 `m_ℓ ≥ 0` 的连续可行重建，**恰好**是该类中带有限支撑乘子的平稳群体轨迹（正反向都成立）。这条命题是方法的合法性基石：贪心插入找到的根不是"某个可行解"，而是**原非凸问题的驻点**。

| 变量 | 含义 |
|---|---|
| `N, d, T, R` | 机器人数、空间维数（`d≥2`）、时域、最小间距 |
| `r_ij, 𝒜_ij` | 相对位置、活跃集（`‖r_ij‖=R` 的时刻集） |
| `μ_ij, m_ℓ` | 碰撞乘子测度、单个点接触的权重（≥0） |
| `n_ℓ, ṙ_ℓ` | 接触法向（`‖n_ℓ‖=1`）、接触点相对速度（与 `n_ℓ` 正交） |
| `ε_F, ε_m, ε_R` | 匹配/端点容差、乘子非负容差、分离容差 |

## 3 · 带数字走一遍

以下为**玩具设定**（自造数字，用于演示机制，非论文实验数据）。

**(a) 未知量计数。** 取 `N=2, d=2`，一个接触 `m=1`。接触向量
`c_1 = (t_1, n_1∈ℝ², ṙ_1∈ℝ², m_1)` 共 `1+2+2+1 = 6` 项；自由度 `2d(N-1) = 4`（归一化 + 相切各去掉 1）。方程数 `m[2d(N-1)+2] = 1×[4+2] = 6`，正好方阵。注意 `{2,…,N}\{q} = ∅`，所以没有额外的相对坐标项。

**(b) 一次接触的 jerk 记账。** 设 `R=1`、`n_1=(0,1)`、`ṙ_1=(1.5,0)`（相切：`⟨n,ṙ⟩=0` ✓）、`m_1=0.4`。则

```
r_pq(t_1) = (0,1)
⟦x_p^(3)⟧ = +0.4 · (0,1) = (0, 0.4)
⟦x_q^(3)⟧ = -0.4 · (0,1) = (0,-0.4)
⟦x_p^(3)⟧ + ⟦x_q^(3)⟧ = 0            ← 动量守恒
⟦ẍ_p⟧ = ⟦ẍ_q⟧ = 0                    ← 加速度不跳
```
重心：`⟦x̄^(3)⟧ = ½(0,0.4) + ½(0,-0.4) = 0` ✓，与"重心是固定三次 Hermite、不受接触影响"一致。物理读法：接触沿法向给了一记 jerk 冲量，把两条轨迹"顶开"，方向和大小由 `m_ℓ n_ℓ` 唯一决定。

**(c) 代价怎么分。** `N=2` 时 `x̃_1 = r/2`、`x̃_2 = -r/2`，所以 `Σ_i‖x̃̈_i‖² = ‖r̈‖²/2`，于是

```
J = ∫_0^T ( 2‖ẍ̄‖² + ½‖r̈‖² ) dt
```
即：重心部分有闭式（Hermite 三次，`J_x̄` 固定），真正要优化的是相对坐标 `r` 的分段三次曲线——这正是 `F(c)=0` 在解的东西。

**(d) 规模账（由论文的 `K=200`、`d=2` 做的量级估算，非论文报告数字）。** 固定网格直接转录至少要 `N × K × d` 个加速度决策变量：`N=1000` 时为 `1000×200×2 = 4×10⁵`。SCI 在 `N=1000` 的网格→双螺旋算例上只有 **118 个接触**；且未知量按**接触连通分量**分摊，孤立机器人直接是解析三次曲线、零未知量。论文在 `N=20` 上报告的中位数是 **6 个最终接触、65 个 matching unknowns**——注意我不对 65 反推分量结构，只按原文引用。

**Trade-off 读法**：
- 论文确实没有报告以下数据：内存峰值、是否多线程、单次 Newton 迭代成本、Jacobian 组装耗时占比；因此无法判断 525.4 s 里 151,071 个接触的瓶颈在 Match 还是 Closest。
- **规模收益来自稀疏性而非并行**：加速比随 `N` 和 `d` 增大而暴涨（`d=10` 时 SCP 50 个实例中超时 37 个），说明它赢的地方是"决策变量数不再随 `N×K` 增长"。
- **容差几乎不影响耗时**（`ε_R` 收紧 100 倍，中位时间 0.006 s 基本不变）——因为孤立接触满足同一组匹配方程；只有持续接触需要加密接触簇。这是本文相对网格法最"工程友好"的一条性质：**精度不是一个旋钮，而只是集群密度**。
- **失败是显式返回而非崩溃**：`Match`/`Insert` 失败或超预算时返回 `unresolved`，流水线必须显式处理这个返回值（300 s 是实验设定，不是内置上限）。

| Baseline | Kamm et al. [17, Sec. III-C] 的稀疏直接转录；`K=200` 等间隔**分段常值加速度**；OSQP 解 QP；≤20 次外迭代、position-change 容差 `10⁻²`；OSQP abs tol `10⁻⁴`、rel tol 0、≤`10⁴` 迭代；比较研究统一 **300 s** 时限 |
| Exp 3 baseline 变体 | `K ∈ {100,200,400,800,1600}`，OSQP abs tol `= ε_R/10` |
| 竞速起点 | 两种方法都从无约束解出发 |
| 成功率定义 | 求解器收敛 + 盒约束满足 + 全程分离 `≥ R - ε_R`（SCI 在 `[0,T]` 全程；SCP 只在被强制的网格点上） |
| 连续时间分离成功率 | 分段多项式轨迹**全程** `[0,T]` 满足 `≥ R-ε_R` 的运行占比；分母含失败与超时 |
| Seeds | `N∈{2,4,…,20}` 每个 50；`N=16` 50 实例；拥堵 6 尺度 × 50 = 300；消融 3 尺度 × 50 = 150；盒约束 102；维数实验 256 校准 + 每 `(d,N)` 50 |
| 统计呈现 | 线=中位数；深/浅带=IQR 与中心 95% 区间 |

## 6 · 能力与失败模式

**能做（有实验支撑）**
- `10⁶` 机器人级别的**开环**群体轨迹规划（`525.4 s`），千级规模进入亚秒级（`0.124 s`）。
- **连续时间**分离保证（容差内），而固定网格 SCP 在 `N=20` 时连续分离成功率是 `0%`、中位赤字 `2.8%` of `R`——即"网格上不撞、网格间照撞"。
- 分离容差收紧 100 倍时成功率与耗时都不塌（100% / `0.006 s`）。
- 有限位置/速度/加速度盒约束（靠凸修正支路），代价几乎为零（`0.20 s` vs 无盒同值）。
- `d` 到 `10` 仍可解，且相对 SCP 的优势随维数扩大。

**不能做 / 明显薄弱**
- **持续接触**（相对位置在接触区间内变化的滑移）**无法**用有限段三次曲线表示；只能靠"点接触簇"逼近，容差越小簇越密，接触数随之增长——这是方法的原理性上限，不是实现问题。
- **不解最优时域**：`T` 是输入。`T` 太短则无解，算法只会一路插接触然后 `unresolved`。
- **点机器人模型**：不建模朝向/几何外形/异构半径（`R` 对所有对统一），也不建模环境障碍、下洗气流、通信与定位误差。
- **只有驻点，没有全局最优证书**；greedy 插入顺序会影响结果（消融显示"最早插入"会让 4/50 个密集实例 matching 停滞）。
- **贪心可能走进负乘子根**：需要删除接触 + `shifted deflation` 重新找根，迭代次数无上界保证，只能靠时间预算兜底。
- **端点必须严格分离**（§II-A 明确假设 `‖x_i - x_j‖ > R` for `t ∈ {0,T}`）；初始/终端构型本身重叠的实例不在适用域内。
- 加速度盒约束只在 almost everywhere 成立（零测集上的越界被允许）。

### 隐含假设 (Hidden Assumptions)
1. **双积分器 + 底层控制器兜底**：所有可行性结论都是"规划的可行性"，跟踪误差、执行器饱和、气动阻尼全部外包给未建模的低层闭环——论文没有闭环实验。
2. **接触图连通分量足够小**：可扩展性完全依赖"最终接触数很小"这一经验事实（`N=20` 中位 6 个接触、`N=1000` 为 118 个）。若真实场景让大量机器人通过接触连成一个大分量，块三对角系统的块尺寸变成 `2d(N-1)+2`，求解代价会退化——论文只论证了分解的**正确性**，没有给出分量尺寸的**最坏界**。
3. **绝对容差是可用的**：`ε_F=10⁻⁷`、`ε_m=10⁻⁹` 是在 `R=0.5`、`T=10√(N/2)` 这套尺度下取的；换单位制（毫米/千米）会直接改变 Newton 的数值行为，隐含假设是"输入已无量纲化到 O(1)"。
4. **采样分布即工作负载**：圆盘均匀采样、零端点速度、统一的 `T∝√N`。真实舰队任务（编队变换、持续巡检、动态目标）的接触结构与随机实例不同，尤其"端点速度为零"大幅降低了匹配方程的难度。
5. **`R` 是纯几何约束**：不区分"必须保持间距"和"碰撞边界带安全余量"，实践中 `ε_R` 会吃掉一部分安全裕度。
6. **单批插入 + 每分量每批最多一次**：这是为控制规模做的启发式约束，隐含假设"一次插入不会同时引爆同分量内的另一处更严重违规"。

**面试 Tip**（被问"它凭什么处理一百万机器人？"）：
不要答"因为它有个更快的求解器"。要答：**它换了表示**。碰撞约束的数量是 `O(N²T)`，但在最优解里真正取等号的只有 `O(N)` 个孤立时刻；所以它把决策变量从"`N` 条轨迹 × `K` 个格点"换成"一张接触清单"，轨迹在接触之间由必要条件**解析确定**（三次多项式），未知量数只跟接触数×接触连通分量尺寸有关。再补一句诚实的边界：**这依赖接触稀疏这一经验事实，且持续接触只能靠接触簇逼近，所以它不是"任意密集群体"的通用解法**。

## 8 · GitHub-validated pitfalls (atlas 联动, 2026-11-02)

论文正文给出了代码与包地址：`https://github.com/jankammeth/sci` 与 `https://pypi.org/project/sci-solver/`。但论文 2026-10-30 提交、今日 2026-11-02，**仅 3 天**，我**没有可核验的社区 issue 流**（不编造 issue 编号/标题/日期/引文）。因此以下 pitfall 全部由 §6 失败模式 + 方法约束**推导**，**未经 issue 验证**：

1. **端点重叠会静默退化，而不是报参数错误**
   *失败模式*：§6「端点必须严格分离」+ §II-A 的 `‖x_i(t)-x_j(t)‖ > R, t∈{0,T}` 是**前置假设**。
   *方法约束*：`Insert` 对"重合插入时刻"的处理是「在相邻时间间隙内错开」，`Groups` 会因插入而 merge 分量。
   *工程后果*：若初/终构型本身有对距 `≤ R`，接触会在 `t=0`/`T` 边界堆积、分量被迫合并、`F(c)=0` 失去端点支撑 → 表现为 `unresolved` 或长时间不收敛。**必须在调库前自己做端点分离预检**（`‖x_i0-x_j0‖>R`、`‖x_iT-x_jT‖>R`），不要指望求解器替你诊断。

2. **`ε_R` 是几何容差，不是数值容差；调松它等于调松安全裕度**
   *失败模式*：§6「`R` 是纯几何约束」+ §V 的成功判据是 `≥ R - ε_R`。
   *方法约束*：默认 `ε_R = 10⁻³`，而 `R=0.5` ⇒ 允许 `0.2%` 的侵入；Exp 3 甚至跑到 `2%`。
   *工程后果*：把 `ε_R` 当"收敛旋钮"随意放大，会让 `Closest` 的连续校验通过、但物理上已经侵入安全壳；同时持续接触的接触簇密度由 `ε_R` 决定，改它会改变接触数与内存轮廓。**应把 `ε_R` 从 `R` 里预先扣除**（用 `R_eff = R_physical - ε_R` 求解）。

3. **绝对容差 `ε_F=10⁻⁷ / ε_m=10⁻⁹` 隐含"输入已无量纲化"，换单位制会翻车**
   *失败模式*：§6 隐含假设 3。
   *方法约束*：`Match` 的收敛判据是 `‖F(c)‖∞ ≤ ε_F` **绝对值** + 阻尼牛顿 + 带状直接解（双精度）。
   *工程后果*：直接把坐标单位从米换成毫米（数值 ×10³），`F` 的残差量级与 Jacobian 条件数同步恶化，Newton 迭代上限 `100` 很可能不够 → 表现为匹配失败/`unresolved`。**务必先把 `R`、`T`、端点归一化到 O(1) 再求解**，与论文的实验尺度（`R=0.5`、`T=10√(N/2)`）对齐。

4. **带盒约束是另一条代码路径，且只在小规模被验证过**
   *失败模式*：§6「不能做」中盒约束依赖 `Bounded correction` 凸子问题 + 对偶解；§V Exp 7 的验证范围是 `N=3–12`、102 个实例。
   *方法约束*：动量 `w_i` 只有在有盒约束时才与 `ẍ_i` 分离（`ẍ_i = proj w_i`），于是轨迹变成**分段多项式**、`ν` 测度引入额外的活跃边界。
   *工程后果*：`10⁶` 规模的算例（Exp 1）用的是 **unrestricted boxes**；若你在百万级实例上打开位置/速度/加速度盒，`0.20 s` 那条数据点**不适用**——它的样本量级差了 5 个数量级。**先把盒约束下的行为在千级规模单独标定**，不要外推。
