# 多手操作策略的多臂落地：搜索指派空间与零空间 (Embodying Multi-Hand Manipulation Policies by Searching the Assignment and Null Spaces)

> **发布时间**：2026-07-24（arXiv:2607.22020v1 [cs.RO]）
> **论文 / 模型名**：Ω-CBSA（On-Manifold Conflict-Based Search with Assignments，读作 "Om CBSA"）
> **核心定位**：把"策略吐出的 N 条末端轨迹 + N 条臂"落成可行的关节轨迹——同时搜索**离散的轨迹↔臂指派**和**连续的多余度零空间**，并对该问题给出 resolution-complete 保证；现有 IK 管线只能 ad hoc 扩展、无可行性/安全性保证。
> **Ontology 5-axis**：problem n/a · representation n/a · sensor n/a · paradigm hybrid · time per-scene

多手策略（Black et al. 2024 / Chi et al. 2024）只输出末端轨迹，在单臂上差分 IK 就能跟，在多臂上却塌了：**没人告诉你哪条轨迹归哪条臂，也没人保证 N 条臂互撞**。这篇论文的结论是：把"指派"和"零空间"塞进同一棵 CBS 约束树里一起搜，就能在保留 IK 级速度的同时拿到完备性。

---

## X-Ray 开场

问题：给定 N 条末端轨迹（`SE(3)` 序列）和 N 条冗余机械臂，求一个**双射指派 σ** 及每条臂的关节轨迹 τ，使得 `FK^i(τ_t^i) = x_t^{σ(i)}` 精确成立、且臂-臂、臂-障碍物均不碰（论文命名为 OM-AMRAMP）。做法：低层用一个**直接跑在姿态约束流形 `ℳ_t` 上**的 A\*（后继 = 名义 IK 投影 + 零空间方向 `±εn` 微移 + IK 回投），并把它升级成"状态里带轨迹编号 j"的多目标版，从而让**指派在搜索中隐式求解**；高层用 CBS 消解两类冲突——「两条臂抢同一条轨迹」（指派冲突）与「两条臂在 t 时刻互撞」（几何冲突，见证点约束）。对 Spatial AI 研究者意味着：**策略输出的抽象层（末端轨迹）与执行层（关节）之间的 gap，可以用搜索而不是学习来补，而且补得有理论保证**——这是"policy 只管语义、planner 管可行"的分工范式。

## 1 · 核心架构 / 方法总览

### 1.1 组件对比表

| 模块 | 输入 | 输出 | 训练 / 推理差异 |
|---|---|---|---|
| `IK(x, q_seed)` | 目标位姿 x、种子构型 | 满足 `FK(q)=x` 的 q（局部、依赖种子） | 无训练；数值迭代 `Δq = J⁺Δx`，本身**只给一个解**，故在 `ℳ_t` 上"早锁定" |
| `Ω-A*_single` | 单条轨迹 `X = {x_1..x_H}`、其他臂已规划路径（可选） | 一条 on-manifold 关节轨迹 τ | 无训练；A\* on `ℳ_t`，状态 `s=(q,t)`，`f = g + w_h·h + w_c·c` |
| `Ω-A*`（多目标） | M 条候选轨迹 `{X^1..X^M}` | `(q,t,j)` 路径，**j 由搜索选定** | 同上；Open 用**每条轨迹首帧**的 IK 解初始化 ⇒ 指派隐式 |
| `OM-PP-A*_single` / `OM-PP-A*` | 优先级序 + 已规划臂轨迹（当作移动障碍，硬约束） | 顺序求解的关节轨迹 | 无训练；快但**不完备**（优先级既定） |
| `Ω-CBSA`（高层） | 全部机器人与轨迹 | 最优性不追求、但完备的联合解 | 无训练；CT 节点 = &#123;约束集, 各臂轨迹, 冲突集&#125;，每次只 replan 受新约束的**一条**臂 |
| 冲突消解 | 指派冲突 / 几何冲突 | 两个互斥子节点 | 指派冲突：子节点分别禁止 R¹ / R² 选 X^j（实现=多目标 Open 初始化时**跳过该轨迹的 IK 种子**）；几何冲突：取见证点 p，禁止某臂在 t 时刻占据 p |

关键点：**本文没有任何学习组件**，"训练-推理差异"这一栏整篇为空——它纯粹是策略下游的执行层算法。

### 1.2 关键机制

**⚡ Eureka Moment：把"哪只手做哪条轨迹"这个离散指派，做成低层 A\* 状态里的第三个坐标 `j`——于是指派不再是外层枚举，而是和冗余零空间一起被同一个 f 值排序、被同一棵 CBS 树剪枝。**

三个支撑细节，缺一不可：

1. **状态含 j ⇒ 指派进入低层**：`Ω-A*` 的状态是 `(q,t,j)`，后继沿 `X^j` 前进、j 不变；初始 Open 里放**所有**候选轨迹首帧的 IK 解。于是"选轨迹"变成"选哪一支初始化没被剪掉"。
2. **零空间 ⇒ 在流形上有了"近邻"**：`FK(q)=x_t` 对 7-DOF 是 1 维流形、对更多余度维数更高；`Null(J(q'))` 给出**位姿不变的合法扰动方向**，`q'' = q' + εn` 再 `IK(x_{t+1}, q'')` 回投，就得到同一位姿下的不同实现——这是"用冗余躲碰撞"的具体机制。
3. **碰撞计为软代价、由 CBS 兜底**：低层只把**障碍物 / 关节限位**当硬约束，臂间碰撞进入 `c(s)` 计入 `f`（`w_c=0.1`）。低层可以坦然地返回一条带臂间碰撞的路径，高层再用见证点把它切开重规划。这正是 `w_h` 与 `w_c` 差 100 倍的道理：**低层负责"算得动"，高层负责"算得对"**。

### 1.3 信息流

```
策略输出 {X^1..X^N}（SE(3) 序列，H 步）
        │
        ▼
┌───────────────────────── Ω-CBSA 高层（约束树 CT）─────────────────────────┐
│  根节点：各臂用 Ω-A* 求 (q,t,j) 路径  ←（可选 warm start：重复 IK-tracking，封顶 500ms）│
│      ↓ 检测冲突                                                        │
│  ┌─ 指派冲突：R¹,R² 都选 X^j ─→ 子节点①禁止 R¹ 选 X^j                   │
│  │                            子节点②禁止 R² 选 X^j（互斥 ⇒ 完备性要点） │
│  └─ 几何冲突：t 时刻体积相交 ─→ 取见证点 p，子节点①禁 R¹ 在 t 占 p      │
│                                子节点②禁 R² 在 t 占 p                  │
│      ↓ 每个子节点只 replan "受约束的那一条臂"                            │
└───────────────────────────────┬────────────────────────────────────────┘
                                │ 低层调用（Ω-A*，多目标）
                                ▼
   Open = ∪_j IK(x_1^j, q_rand)          ← 多目标：j 是搜索自由度
        │
        ├─ pop 最小 f(s) = g + w_h(H−t) + w_c·c
        │
        └─ 后继生成（从 (q,t) 到 t+1，沿 X^j）：
             q'  = IK(x_{t+1}, q)                     ← 名义投影（上流形）
             for n in basis(Null(J(q')))， ± 号：
                 q'' = q' + ε n                       ← 零空间微移（ε=0.2）
                 q'' ← IK(x_{t+1}, q'')                ← 回投到 ℳ_{t+1}
                 若 q'' 无碰障碍 & 在关节限位内 ⇒ 后继 (q'', t+1, j)
                 且（CBS 子节点里）若 q''(t+1) 含见证点 p ⇒ 丢弃（硬约束）
        ▼
   到达 t=H ⇒ 返回 on-manifold 路径（可能仍含臂间碰撞 ⇒ 回高层）
```

## 2 · 数学核心

📌 **Napkin Formula**

```
在 ℳ_t = {q : FK(q) = x_t} 上做 A*：
   f(s) = g(s) + w_h·(H − t) + w_c·c(s)
   后继 = IK 回投( q + ε·n ),  n ∈ basis( Null(J(q)) )
配对问题（谁做哪条）不另解，交给状态坐标 j 与 CBS 的互斥约束。
```

**目标（OM-AMRAMP）**：求双射 `σ: {1..N} → {1..N}` 与 `τ^i = {τ_1^i..τ_H^i}`，使对所有 `i, t, k≠i`：

```
FK^i(τ_t^i) = x_t^{σ(i)}          （精确跟踪）
R^i(τ_t^i) ∩ R^k(τ_t^k) = ∅        （臂间无碰）
R^i(τ_t^i) ∩ 𝒪 = ∅                 （环境无碰）
```

**流形与零空间**：`ℳ_t = { q ∈ 𝒬_R | FK(q) = x_t }`；在 q 处 `Null(J(q))` 是所有"末端位姿不变"的关节方向，取基矩阵 `N(q)`，则 `Δq = N(q)α` 局部保持在流形上。

**代价与启发**：

| 符号 | 含义 | 论文取值 / 形式 |
|---|---|---|
| `g(s)` | 路径代价（关节空间累计位移） | `g(s') = g(s) + ‖q'' − q‖`；初始状态 `g(s) = ‖FK(q) − x_1‖` |
| `h(s)` | 剩余步数启发（"还差几步到 H"） | `h(s) = H − t` |
| `c(s)` | 相对已给其他臂路径的碰撞计数（软） | `c(s') = c(s) + CountCollisions(q')`（按论文印刷式，对**名义投影 q′** 计数，见 §8） |
| `w_h, w_c` | 权重 | `w_h = 10, w_c = 0.1` |
| `ε` | 零空间步长 | `0.2` |

**直觉**：`w_h = 10` 意味着"沿时间前进一步"价值 10，而一次臂间碰撞只扣 0.1 ⇒ **100 次臂间碰撞才等价于浪费一步时间**。低层因此极度"赶时间"、几乎不为其他臂绕路；绕路这件事被显式下放给 CBS 的硬约束（见证点）。这是全篇最重要的工程口味选择：**把软的留在低层（保速度），把硬的留给高层（保完备）**。

**为什么完备**：Lemma 1（`Ω-A*` 在给定离散化下 resolution-complete：有限图、系统展开，可行解必被展开到）+ Lemma 2（指派约束与几何见证点约束均**互斥**：违反 `c¹={R¹不得选 X^j}` 与 `c²={R²不得选 X^j}` 的联合解会让 X^j 同时属于 R¹、R²，与 σ 是双射矛盾）⇒ Theorem 1（CBS 用完备低层 + 互斥约束 ⇒ 完备）。

## 3 · 带数字走一遍（玩具设定，数字为示意非论文结果）

设定：2 条 7-DOF 臂（Kinova Gen3 类）、2 条轨迹 `X¹, X²`、`H = 3`。7-DOF 且任务为 6 维 `SE(3)` ⇒ **零空间维数 1**，每状态至多 `2(d−6) = 2` 个零空间后继（`+εn`, `−εn`）。取 `ε = 0.2, w_h = 10, w_c = 0.1`。

第一轮低层（R¹ 规划，尚不知 R² 的路径）：

| 弹出顺序 | 状态 | `g` | `h = H−t` | `w_h·h` | `c` | `w_c·c` | `f` |
|---|---|---|---|---|---|---|---|
| ① | `(q, t=1)` | 0.30 | 2 | 20 | 0 | 0.0 | **20.30** |
| ② | `(q'_2, t=2)` 名义投影，与 R² 相撞 | 0.55 | 1 | 10 | 1 | 0.1 | **10.65** |
| ③ | `(q''_2, t=2)` 走 `+0.2n` 后回投，无碰 | 0.75 | 1 | 10 | 0 | 0.0 | **10.75** |
| ④ | `(q'''_3, t=3) = 目标` 但 c 继承为 2 | 0.80 | 0 | 0 | 2 | 0.2 | **1.00** ← 到 t=H，**返回路径** |

读法：
- ② 比 ③ 早弹出，因为 `10.65 < 10.75`——**0.1 的碰撞惩罚完全抵不过 0.2 的关节位移**。低层就此返回了一条"在 t=2 撞了 R² 一次"的可行路径。这不是 bug，是设计：`w_c` 本来就是软信号。
- 高层检测到 t=2 处体积相交，取见证点 `p`，生成两个子节点：「R¹ 在 t=2 不得占 p」「R² 在 t=2 不得占 p」。对 R¹ 的重新规划中，② 因为占据 p 被**硬性**丢弃，③ 成为唯一通路 ⇒ 解出。这演示了"零空间不是可选装饰，而是消解几何冲突的唯一手段"（当名义 IK 解恰好落在碰撞里时）。
- 指派冲突的数值形态：若 ② 的路径其实是沿 X² 走的（状态 j=2），而 R² 也选了 j=2，则高层产生指派冲突，两个子节点分别**在多目标 Open 初始化时跳过 X² 的 IK 种子**——即"禁选某轨迹"是通过删初始化实现的，而不是在搜索中打标记。

## 4 · 工程视角

| 项目 | 论文报告值 |
|---|---|
| 计算硬件 | Intel Core i9-12900H CPU（5.2 GHz）；**无 GPU 参与** |
| 运动学库 | Pinocchio（Carpentier et al. 2019） |
| 机械臂 | Kinova Gen3 |
| 求解时限（评测口径） | 5 s（success = 5 秒内解出） |
| Ω-CBSA 全 benchmark 平均耗时 | 约 640（σ = 990 ms，min 16 ms，max 4.9 s） |
| Ω-CBSA 双臂问题平均耗时 | 150 ms |
| 优先级变体（OM-PP-A\* / OM-PP-A\*_single） | 多数问题 1 秒内 |
| IK-Tracking（成功时） | 约 160 ms 平均 |
| 根节点 warm start | 重复 IK-tracking，封顶 500 ms |
| 内存 / VRAM / 吞吐 / 真机控制频率 | **论文未报告** |

Trade-off 读法（可面试复述）：

1. **成功率 vs 时间**：Ω-CBSA 最高但均值被长尾拉高（σ=990 ms > 均值 640 ms，max 4.9 s 逼近 5 s 时限）；优先级变体是"少一点成功率、多数 &lt;1 s"的甜点位。工程上应**先跑 OM-PP-A\*，超时再退 Ω-CBSA**——这正是论文两个变体的存在理由。
2. **搜索规模由谁决定**：`Ω-CBSA` 的瓶颈是 CT 节点数（冲突数）与每次 replan 的单臂搜索；而 Composite A\* 的状态是 `(q^1..q^N, t)` 的**笛卡尔积**，分支因子随 N 指数爆炸 ⇒ 6 臂场景直接不可用（论文明确观察到 "rapid growth in branching factor"）。这是"完备性不能靠联合状态空间硬搜"的标准教训。
3. **单状态开销**：每个后继要做 `1 + 2(d−6)` 次 IK（1 次名义投影 + 每个零空间方向一次回投）。7-DOF ⇒ 3 次 IK/后继；12-DOF 冗余臂 ⇒ 13 次。**IK 次数随手冗余度线性增长**，而 H 又线性拉长搜索深度 ⇒ 长轨迹（高频策略输出）是主要成本源。
4. **无 GPU、无学习**：整个管线可在纯 CPU 上部署到机载算力，这对"策略在 GPU 上、执行在 CPU 上"的机器人栈很友好；但也意味着**没有可并行化的张量级加速**（CBS 天然可并行多 CT 节点，论文未报告是否实现）。
5. **部署约束（论文未报告，属显式缺口）**：真机闭环频率、τ_1 起点如何由外部多臂规划器接管、失效时如何回退——这三项是把它塞进真实机器人栈前必须自己补的。

## 5 · 数据与评测

**无训练数据、无数据集**（本文不含学习组件）。评测由两部分构成：

**（a）仿真 benchmark**
- 规模：**450** 个 benchmark 问题。
- 构成：每个问题含**至多 6** 条末端轨迹与机器人，布置在含障碍物的多样布局中；包含"形似学习策略输出"的运动，以及"人形启发、要求紧协调"的设定（引 Black et al. 2024；Shaoul et al. 2025）。
- 指标：**success rate（5 秒内解出的比例）** + 规划时间。
- 分档：整体成功率、**按机器人数量分档**的成功率、平均总运行时间（Fig. 2 的后三张图）。

**（b）真机验证**
- 物理 **3 臂**平台，三项任务：**cloth rotation、box flip、planar pushing**。
- 真机成功率数字：**论文未报告**（正文仅称 "demonstrated"）。

**Baselines（三族，均为适配而来，因为作者称无算法直接处理 OM-AMRAMP）**
1. **IK-Tracking**：给定 σ，每条臂对首帧采一个 IK 解，其余用 IK 跟踪；**枚举所有 σ**，失败换下一个。快而 myopic。
2. **PP-Descartes**：把 Descartes（De Maeyer et al. 2017）多臂化；枚举所有 σ 与**所有优先级排序**；每条臂建姿态约束 roadmap（采样多 IK 解 + 无碰边），且样本/边须避开已规划的高优先级臂。
3. **Composite A\***：状态 `(q^1..q^N, t)`，单臂后继集与 `Ω-A*` 完全相同（IK + 零空间），联合后继取笛卡尔积并过滤碰撞；Open 用**所有**轨迹首帧的 IK 种子初始化（隐式覆盖所有指派）。

**条件说明（避免误读结论）**：所有对比都在"5 秒时限 + 最多 6 臂 + 静态障碍"的条件下成立；论文报告的定性结论是"提出的规划器在成功率上一致优于全部 baseline，且随臂数增加优势扩大"，并给出两条 baseline 的具体退化原因（Descartes 输在 roadmap 构建开销；Composite A\* 输在分支因子随指派引入而爆炸；IK-Tracking 成功时最快但极 myopic、很少解出）。**逐条成功率百分数与各分档数值在本正文中未给出（只在 Fig. 2 的图中）**，故此处不做数字引用。

## 6 · 能力与失败模式

**能做（具体）**
- N 条臂 × N 条轨迹的**双射指派 + 跟踪 + 互避**联合求解；N 最多验到 6。
- 用**冗余零空间**在"位姿必须精确等于 x_t"的硬约束下腾挪躲碰——这正是 IK-tracking 结构上做不到的（它一个种子定终身）。
- 对固定离散化给出**resolution-complete** 保证：若在给定运动基元分辨率下存在可行 embodiment，`Ω-CBSA` 必找到。
- 单臂低层是**通用**的：`Ω-A*_single` 可独立用于单臂姿态约束规划。
- 纯 CPU、无学习、无 GPU，秒级以内完成多数实例。

**不能做 / 会失效（每条都指向具体机制）**
- **不可达或超出工作空间的策略输出**：目标函数要求 `FK(τ_t)=x_t` **精确**成立；若某帧 x_t 在臂的可达集之外（或受关节限位阻挡），IK 回投永不收敛，该分支的所有后继被静默丢弃 ⇒ 搜索返回"无解"，而不会退化成"最接近的 embodiment"。
- **动态障碍 / 移动的人**：`𝒪` 被定义为**静态**障碍区域，且碰撞检查按 `t` 索引离散化 ⇒ 无动态物建模。
- **关节数多于轨迹数的场景**（M ≠ N）：σ 被定义为 `{1..N} → {1..N}` 的**双射**，空闲臂既不在指派里、也不作为被规划对象 ⇒ 结构性不支持。
- **起点不可达**：`τ_1` 的到达被**显式留给**外部多臂运动规划器（Mishani 2025 / Shaoul 2024a / Shome 2020 / Huang 2025 / Kuffner & LaValle 2000）⇒ 本方法只解"给定起点之后的跟踪"。
- **薄障碍 / 高频时间步**：碰撞在离散时间步上以体积相交判定，且高层只取**一个**见证点 ⇒ 时间步过粗会隧穿，过细则 H 增大、深度成本线性上升。
- **动力学不可行**：无速度/加速度/力矩模型，输出的 τ 只在运动学意义上可行。

### 隐含假设 (Hidden Assumptions)

1. **精确跟踪是可行的**：假设每条策略轨迹的每一帧都落在对应臂的 reachable 集合内，且不与关节限位冲突（否则 `IK(x_t, ·)` 无法回投）。
2. **轨迹是"可执行的运动"，不是"意图"**：假设策略输出已经是稠密、时间对齐、逐帧有意义的 `SE(3)` 序列（H 步、同步），而非稀疏 waypoint 或带时间伸缩的意图。
3. **臂数 = 轨迹数是题设**，且每条轨迹必须被某条臂执行（不能有"跳过这条轨迹"的选项）。
4. **环境静态且已知**：`𝒪` 一次性给定；无感知在环、无未知障碍。
5. **运动学模型精确**：`FK`、`J`、`Null(J)` 均视为准确（无标定误差、无柔性）。
6. **碰撞几何用体积相交判定**，且 3 臂真机实验中的 cloth / box 属于"被操作物"，其自身形变与碰撞代价未在正文建模。
7. **低层"赶时间"偏好是安全的**：假设 `w_c = 0.1` 的软碰撞代价 + CBS 硬见证点足以收敛；即假设 CBS 的节点数不会因频繁几何冲突而爆炸（论文以 max 4.9 s 的经验支持，但无上界）。
8. **分辨率即真值**：resolution-completeness 只对"给定基元离散化"成立；`ε = 0.2` 与零空间基的方向集若不覆盖真正需要的流形通路，则"无解"是离散化的产物，而非问题真的无解。

## 7 · 与相关工作对比

| 维度 | IK-Tracking | PP-Descartes (2017→) | Composite A\* (2014→) | OM-PP-A\* / OM-PP-A\*_single（本文） | **Ω-CBSA（本文）** |
|---|---|---|---|---|---|
| 处理指派 | 外层枚举全部 σ | 外层枚举 σ + 全部优先级序 | 隐式（全轨迹首帧 IK 种子） | 隐式（多目标版） | 隐式（多目标版） |

| 臂间协调方式 | 无（靠运气） | 优先级 + roadmap 内避让 | 联合状态内过滤 | 优先级（已规划臂 = 移动障碍，硬约束） | **CBS 约束树 + 见证点** |

**面试 Tip（被问到"它和 CBS / 和 IK 有什么本质区别"时怎么答）**：
> "它不是又一个多机器人 CBS。标准 CBS 的低层是普通运动规划，本文的低层是**直接长在姿态约束流形上的 A\***——状态 `(q,t,j)`，后继是'IK 回投 + 零空间 `±ε` 微移 + 再回投'，所以它能在'末端必须精确走到 x_t'的硬约束下，用冗余度腾挪避碰；而 j 这一维把**轨迹↔臂的指派**从外层 `N!` 枚举搬进了低层搜索。高层 CBS 只需要多处理一类新冲突——两条臂抢同一条轨迹——办法是把'禁选 X^j'实现为多目标 Open 初始化时跳过该轨迹的 IK 种子。这两条约束（指派 + 几何见证点）都互斥，于是 CBS 的完备性照搬，得到 resolution-complete。代价是它只做运动学、只对静态障碍、且要求轨迹每帧可达。"

## 8 · GitHub-validated pitfalls (atlas 联动, 2026-11-09)

**repo 状态核查**：论文全文出现的唯一 URL 是项目页 `omcbsa.github.io`（正文 "See omcbsa.github.io for more."），**未出现任何 `github.com` 链接**，也无 commit / issue 引用。因此本节**不含任何 issue 编号或引文**；以下 3 条 pitfall 由 §6 失败模式 × 方法约束推导，**未经社区 issue 验证**（标注：`推导，非 issue-verified`）。

1. **"每帧必须可达"⇒ 策略输出外扩即整段判无解**
   - 机制链条：§6「目标函数要求 `FK(τ_t)=x_t` 精确成立」 × §2 后继 `q'' ← IK(x_{t+1}, q'')` 是**局部**迭代（`Δq = J⁺Δx`，种子敏感）。
   - 表现：某帧 `x_t` 略超工作空间（学习策略常见的输出漂移）或在关节限位死角，则该帧所有候选 `q''` 都不满足"无碰 + 限位"，后继集为空 ⇒ 整条分支死掉 ⇒ 上层看到的是"no solution"，而真实需求是"最接近的可执行 version"。工程上必须自己在外面加一层 `x_t` 可达性过滤 / 投影，否则会误判为"算法失败"。
2. **`c(s)` 按名义投影 `q′` 计数，但实际执行的是 `q''` ⇒ 代价与真实碰撞不一致**
   - 机制链条：§2 印刷式 `c(s') = c(s) + CountCollisions(q')`（q′ = 名义 IK 投影） × §6「低层只把障碍/限位当硬约束，臂间碰撞只进软代价」。
   - 表现：`q''` 是零空间微移 + 回投后的**实际**状态，碰撞却记在 `q′` 上。若 `q''` 与 `q′` 的碰撞状态不同（恰恰是零空间探索想利用的情形），`f` 排序会给出与实际路径不一致的偏好。复现时若你按 `q''` 记账，得到的时间/成功率就不会和论文一致——**这是"抄公式还是抄语义"必须自己拍板的一处**。
3. **根节点 warm start 绕过了低层搜索 ⇒ 完备性证明不覆盖它**
   - 机制链条：§4 实现细节「根 CT 节点用重复 IK-tracking 初始化（封顶 500 ms）」 × 定理 1 依赖 Lemma 1（`Ω-A*` 的 resolution-completeness）。
   - 表现：根节点的初始轨迹是由 **IK-tracking** 产生的，而非 `Ω-A*`；论文自己注明这不影响理论保证（"without affecting theoretical guarantees"，因为后续所有 replan 都用 `Ω-A*`）。但实践含义是：**若 warm start 阶段就把某个可行指纹抹掉（例如某条臂被 IK 锁进一条后续无法脱身的走廊），你观测到的失败率会高于纯 `Ω-A*` 根节点**。调参时把 500 ms 设成 0 做对照，是最快定位"是搜索不行还是 warm start 不行"的实验。

**附：可复现性风险（同样为推导）**
- 零空间基 `N(q')` 由 `Null(J(q'))` 的**基选取**决定，不同 Pinocchio 版本 / 不同 SVD 符号约定会给出方向翻转或不同的基 ⇒ 后继集合不同 ⇒ 搜索顺序与最终路径不同。若要做确定性回归测试，必须固定库版本并在对比实验里固定随机种子（论文的 `q_rand` 初始化尤其依赖种子）。
