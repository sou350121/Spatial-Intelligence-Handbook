# 多面体网格上的机器人学习：离散曲面的理论与应用 (Robot Learning on Discrete Surfaces: Theory and Applications)

> **发布时间**：2026-10-01（arXiv:2610.01910v1 [cs.RO]）
> **论文 / 模型名**：Robot Learning on Discrete Surfaces（离散黎曼算子框架 + Mesh DMP / Geodesic GP / Mesh Flow Matching）
> **核心定位**：把机器人接触式技能（打磨 / 绘制 / 擦拭）的学习域从"光滑流形 + 事后投影"直接搬到 CAD / 3D 重建的**标准输出——多面体网格**上，用一套在面 / 边 / 顶点都良定义的离散黎曼算子（切锥、最直测地线 Exp / Log、平行移动、环境空间投影）替代 MeshDMP 的局部近似与 Laplace–Beltrami 的谱近似。

导语：现有 LfD / motion generation 要么假设技能活在平坦欧氏空间（曲线曲面靠事后投影回约束），要么只在旋转 / SPD 这类有闭式算子的光滑流形上做几何感知学习；现实中曲面几乎都是带边 / 顶点奇点的多面体网格。本文的结论是：直接在本征几何上定义算子，DMP 跨曲面泛化更稳、GP 摆脱顶点限制、RFM 生成质量更好且训练时间近乎减半——并在 Franka Research 3 真机上跑通两条端到端流水线。

---

## X-Ray 开场

**解决什么问题**：机器人与物体表面的持续接触操作（打磨、绘制、擦拭、抛光）本质发生在曲面上，但主流学习框架把曲面当成"外部约束"，用投影 / 阻抗 / 局部参数化事后补回来，一旦底层结构变化就崩。而真实曲面是 CAD / 深度重建产出的多面体网格，在边和顶点上不可微、法向不唯一，光滑黎曼学习的整套算子（Log / Exp / 平行移动）在此**没有定义**。

**提出了什么**：一套**离散黎曼算子框架**——切锥（tangent cone）推广切空间到边 / 顶点、基于"最直测地线"原则的 Exp 映射（Algorithm 1）、作为旋转的平行移动、以及环境空间双向投影（Algorithm 2）；并把 DMP、Gaussian Process、Riemannian Flow Matching 三个学习范式全部重建在这套算子上。

**对 spatial AI 研究者意味着什么**：网格从"渲染 / 规划的输入格式"升级为"可直接做几何感知学习的表示"。曲面自己就是学习域，而非约束——这对接触式操作、手绘轨迹迁移、未知物体表面抛光都是可直接复用的算子底座。

### 1.1 系统 / 组件对比表

### 1.2 关键机制

**⚡ Eureka Moment**：**把"曲面几何"从被约束的对象变成算子本身——用切锥（tangent cone）统一处理面 / 边 / 顶点的非光滑性，并用"最直测地线"（straightest geodesic，左右曲线角各等于总角的一半）而非"最短测地线"来定义 Exp 映射，因为在顶点处最短路径不唯一、而最直路径唯一。**

三个落地要点：
1. **DMP 漂移的根因**：MeshDMP 把 forcing term 编码在**随位置移动的局部坐标系**里，曲面曲率让这个坐标系沿轨迹旋转，于是 8 字形演示漂移成"绕中心旋转"。本文把 f 固定在目标切锥 T_gℳ 里、执行时平行移动到 T_pℳ，曲率被算子吸收，漂移消失。
2. **GP 摆脱顶点**：Laplace–Beltrami 核只能在网格顶点评估，面内点要么插值（引入误差）要么上采样（增复杂度）。测地核 k_d=σ²exp(−d_g²/2κ²) 直接在任意点算测地距离。
3. **RFM 的 premetric 选择**：不用 LBO 谱距离，直接用最短路径测地距离作 D，且训练监督来自"两点间最短路径 γ"本身，天然落在网格上，无需每步最近点投影。

## 2 · 数学核心

📌 **Napkin Formula**：
$$v = \mathrm{Log}_p(q) \triangleq \ell\,\dot\gamma(0),\qquad w = P_{p\to q}(v) = R(\ell)R^\top(0)\,v,\qquad k_d(x,x')=\sigma^2 e^{-d_g^2(x,x')/2\kappa^2}$$
**一句话本质**：把曲面上两点间的最短路径 γ 的初速度当作该点的切向量（Log），把沿 γ 的长度保持变换当作运输（平行移动＝旋转），把欧氏核里的直线距离换成测地距离（测地核）。全部算子都归约到"求最短路径 + 沿路径的等距旋转"。

---

**(a) 切锥与总角** 目标：给非光滑点定义"切空间"。
$$\theta(\nu_i) \triangleq \sum_{\mathcal{T}_j\in\mathcal{I}(\nu_i)} \theta_{\mathcal{T}_j}(\nu_i) \tag{2}$$
- θ(p)：面内 / 边上取 2π（局部等距于欧氏）；顶点取所有相邻面在该点张角之和。
- 分类：θ<2π 球面顶点（正曲率）、θ=2π 欧氏、θ>2π 双曲。
- 直觉：把顶点"摊平"到平面上看，缺了多少角度就是曲率的来源。

**(b) 对数映射（Log）** 目标：点 q → 切锥向量 v。
$$v = \mathrm{Log}_p(q) \triangleq \ell\,\dot\gamma(0) \tag{13}$$
- γ：p→q 的最短测地线（折线），ℓ 为弧长，γ̇(0) 为初始单位方向。
- 直觉：v 的方向＝最短路径出发方向，模长＝测地距离。

**(c) 指数映射（Exp）** 目标：切锥向量 v → 点 q。用**最直测地线**逐面推进（Algorithm 1）：若位移落回当前面 → 结束；否则落到面边界 p_{k+1}，取剩余向量 w，绕 p_{k+1} **在网格上本征地旋转 θ/2** 得到新的 v_{k+1}。
- 关键：θ 为 p_{k+1} 处的总角 (2)。顶点处 θ_l=θ_r=θ/2 恰好给出唯一最直路径。

**(d) 平行移动（Parallel Transport）** 目标：把矢量从 T_pℳ 搬到 T_qℳ，长度 / 夹角不变。
$$R(\ell)\triangleq\begin{bmatrix}\dot\gamma(\ell) & n(\ell)\times\dot\gamma(\ell) & n(\ell)\end{bmatrix},\qquad w\triangleq R(\ell)R^\top(0)\,v \tag{16,17}$$
- n(·)：γ 上各点的曲面法向。
- 直觉：因为网格嵌在 ℝ³，运输就是一个旋转矩阵；测地线速度方向被固定（角度 0），垂直分量被二面角旋转。

**(e) 投影** Π_ℳ(p°)=argmin‖p−p°‖（最近点，可用 AABB 加速），Proj_p(v°)=argmin‖v−v°‖ 落回切锥（Algorithm 2：投影到各面 + 各方向边，剔除越界候选，取与 v° 点积最大者）。

**(f) DMP forcing term 迁移**
$$f_{p,k}=\tau^2\ddot p_k-\alpha\big(\beta\,\mathrm{Log}_{p_k}(g)-\tau\dot p_k\big),\qquad f_{g,k}=P_{p_k\to g}\big(f_{p,k}\big) \tag{20,21}$$
执行时（离散）：
$$\tau\nabla_z z=\alpha(\beta\,\mathrm{Log}_p(g)-z)+P_{g\to p}\big(f(x)\big) \tag{22}$$
节奏版：
$$\nabla_z z=\Omega\Big(\alpha(\beta\,\mathrm{Log}_p(g)-z)+P_{g\to p}\big(f(\phi)\big)\Big),\ \dot p=\Omega z,\ \dot\phi=2\pi\Omega \tag{23}$$
- 直觉：演示里每点的 forcing term 先反解，再全部搬到**目标切锥** T_gℳ，形成一套"固定坐标系里的 2D 最小表示"；执行时再搬回当前位置。跨曲面只需换 g′ 和参数化。

**(g) RFM 训练目标**（几何一致的范数）
$$\mathcal{L}_{\mathrm{RFM}}(\Theta)=\mathbb{E}_{t\sim\mathcal{U}(0,1),p\sim\pi_t}\big\|v_t(p,\Theta)-u_t(p)\big\|^2_{\mathfrak g},\qquad u_t(p|p_1)=\frac{\mathrm{d}\log\eta(t)}{\mathrm{d}t}D(p,p_1)\frac{\nabla D(p,p_1)}{\|\nabla D(p,p_1)\|^2_{\mathfrak g}}$$
本文取 **D = 测地距离 d_g**、调度器 η(t)=1−t、流 ψ_t 就取 p_0→p_1 的最短路径 γ。

## 3 · 带数字走一遍（玩具设定）

**玩具 1：立方体顶点上的最直测地线。**
立方体一个顶点处有 3 个面相交，每个面在该顶点张角 90°，故总角 θ(ν)=3×90°=**270°=3π/2** < 2π → 球面顶点（高斯曲率 2π−3π/2=π/2）。
- 最直测地线要求左右曲线角 θ_l=θ_r=θ/2=**135°**。
- 若一条路径撞到该顶点，Algorithm 1 取剩余向量 w，绕顶点旋转 θ/2=135° 后继续——这保证了路径**唯一**。作为对比，"最短路径"原则在这里会因为绕顶点的无穷多条等长路径而**不唯一**，无法定初值问题。这就是为什么要选最直而非最短。

**玩具 2：测地核为何在 κ 太大时失效。**
设训练点最近邻测地距离 d=0.05。核矩阵元素 K_ij=exp(−d_ij²/2κ²)。
- κ=0.1：K=exp(−0.0025/0.02)=exp(−0.125)≈**0.88** → 有区分度。
- κ=0.5：K=exp(−0.0025/0.5)=exp(−0.005)≈**0.995** → 所有元素趋近 1，矩阵近乎秩 1，出现负特征值 → 协方差矩阵非正定 → Cholesky 分解崩。
这解释了论文为何要 Algorithm 3 二分搜索 κ_th：对 Stanford Dragon，κ_th=**0.023**（论文实测量，见 §5）；超过它 GPR 就会给出不一致结果。

**玩具 3：DMP 漂移方向。**
在曲率非零的曲面上，若 forcing term 编码在"随点移动的局部坐标系"，坐标系沿 8 字轨迹转一圈后积累了一个误差旋转（正比于轨迹所围曲率通量）。演示次数越多、执行越长，误差线性累积 → 表现为整条轨迹"绕固定中心旋转"。本文在 T_gℳ 固定编码 + P_{g→p} 运输，误差旋转被算子精确抵消，长时积分仍锁定极限环（论文 Fig. 8 的定性对比）。

| 测地核 setup（Spot the Cow, m=20） | 472 ms |
| 特征函数计算（LBO 核，一次性） | Spot the Cow **27 s**；Stanford Dragon **49 s**；Cube 4×/6× 上采样 **240 ms 与 87 s** |
| RFM 训练时间 | baseline **1 day 6 hours**；本文 **20 hours**（100 000 步、batch 128、每 2000 步验证） |
| 测地预计算复杂度 | **O(N² log N)**，N 为面数；超过 **10 000 面**成为显著瓶颈 |
| 绘制流水线 | 生成 40 000 条轨迹样本通常**不到 5 s** |
| 抛光流水线 | 点云→网格→轨迹整体 **1–10 s**（取决于点云质量），离线生成 100 Hz 轨迹通常**不到 5 s**，执行上采样到 **1 kHz** |

**核心 trade-off（据论文文字归纳）**：
- **测地核**：对每个输入点集都要重建加速数据结构（setup 472 ms @ m=20，随点数上升），但**协方差评估时间对测试点数近似线性**；优势场景是"中小网格（≤5 000 面）+ 网格不预先已知（时变曲面）"。
- **LBO 核**：一次性特征分解很贵，但之后**推理整体更快**；在非光滑面上增大网格密度反而**放大离散误差**（论文观察到性能退化）。
- **RFM**：baseline 每一步都要最近点投影（谱路径不保证落在网格上）→ 慢；本文用 Exp 映射保证路径天然贴面，且训练时的测地线计算被"沿时间廉价上采样"摊薄 → 训练时间从 30 h 降到 20 h。
- **部署约束**：>10 000 面时测地学预计算成为硬瓶颈；LBO 类方法只能在顶点评估，本文可在面内任意点评估（省去插值 / 上采样开销）。

## 5 · 数据与评测

**仿真对比（Sec. V）——三组，逐字：**

**(a) DMP vs MeshDMP [9]**
- 任务：在**平坦面**上学习一个 **8 字形**演示，泛化到 **Stanford Bunny** 网格。
- 两法使用**相同 DMP 参数**：α=48，β=α/4，γ=5，**20 个基函数**，相同初始状态与中心。
- 指标：定性对比（Fig. 8）——两者初期都收敛到极限环；长时积分下本文 (23) 保持极限环，MeshDMP 出现绕中心的**不期望旋转**。
- Exp 映射对比（Fig. 9）：本文 Algorithm 1 重连的路径与参考测地线"数值精度内重合"，MeshDMP 的局部法向投影近似偏离。

**(b) Geodesic GP vs Laplace–Beltrami 核 [10]**
- 数据：3 个顶点相邻立方体面（三角化后 6 面）；ground truth = 从固定点的测地距离的正弦。
- 上采样：817 顶点 / 1 536 面，及进一步 12 481 顶点 / 24 576 面；kappa=0.18，sigma=1；**70** 个 ground-truth 采样点作训练；**100** 次实验（每次随机选 70 个测试顶点）；LBO 核用 GeometricKernels 包 [54]，取前 **1 000** 个特征函数。
- 指标：**MAE**（median + 10th–90th percentile）。结论方向：小 κ 下两法性能相当；大 κ 下 LBO 核不稳定、MAE 恶化到"不可接受水平"；测地核在 κ_th 内保持良好；增大网格密度反而讓 LBO 退化。
- Stanford Dragon 实验：9 983 面 / 4 898 顶点；κ=0.018 评估、κ=0.02 做无噪 GPR；48 个点 / 次、100 次实验；κ_th=**0.023**（Algorithm 3 评估）。本文核在 κ_th 以下"整体略优于" LBO 核。

**(c) Mesh Flow Matching vs RFM [4]**
- 网格：Stanford Bunny（decimated 到 **5 000** 面）、Spot the Cow。
- 目标分布：由 LBO 第 i 个特征函数（26）构造，按阈化后的特征函数值比例在网格上采样 **500 000** 个样本；按 **80–10–10** 划分 train/val/test。
- 设置：Dense NN，**6 层 × 512 神经元**，Swish 激活，ADAM，lr **10⁻⁴**；baseline premetric 用前 **200** 个特征函数的 diffusion 与 biharmonic；相同参数与随机种子。
- 指标：**test NLL**（越低越好，取最低验证 NLL 的 checkpoint）。逐字数值（Table IV）：

| 网格 | i | Geodesic (ours) | Diffusion | Biharmonic |
|---|---|---|---|---|
| Stanford Bunny | 10 | 0.81 ± 0.1 | 1.16 ± 0.02 | 1.06 ± 0.05 |

## 6 · 能力与失败模式

**能做（论文直接声称或演示）：**
- 在**非光滑、非流形光滑**的网格上做几何一致的 Log / Exp / 平行移动 / 投影——包括穿过边和顶点的传播。
- DMP 跨**不同曲率、拓扑、离散分辨率的曲面**泛化，且长时执行不漂移（Fig. 8）。
- GP 在**任意网格位置（含面内部）**做核回归，粗网格上尤其有效，无需光滑 / 密度假设。
- RFM 在网格上生成分布采样，6 组实验中 NLL 全面低于 diffusion / biharmonic 谱基线，训练时间从 30 h 降到 20 h。
- 真机：手绘轨迹迁移到多种曲面 + RGB-D 重建曲面上的抛光。

**不能做 / 明确失败模式：**
1. **大网格**：测地预计算 O(N² log N)，**>10 000 面**时成为显著瓶颈（论文将 Stanford Dragon 9 983 面接近此界）。
2. **大 lengthscale 的 GP**：测地核在 κ>κ_th 时**不保证正定**，会产生不一致的 GP；论文用 Algorithm 3/蒙特卡洛做实际保护，但**κ_th 与曲率、拓扑、采样点数的关系尚无理论刻画**。
3. **LBO 类基线在非光滑面上密度越高越差**——这是被比较方的失败，而非本文的。
4. **方向轨迹在面间过渡处不可微**：论文用"预计算整条轨迹 + 对称滑窗平滑"绕过，说明**在线逐帧生成 normal 方向会有跳变**。

### 隐含假设 (Hidden Assumptions)

- **网格是流形曲面**（manifold surface mesh，piecewise-linear 2D 嵌入 ℝ³）：非流形网格、自交网格、开放 / 有孔洞的非水密网格不在框架内。
- **面为三角形**（"without loss of generality, we consider faces to be triangles"）：一般多边形面需先三角化。
- **度量为环境空间诱导的欧氏度量** 𝔤:⟨v,w⟩≜vᵀw：不适用于无法等距嵌入 ℝ³ 的理想曲面，也不支持各向异性 / 学习得到的度量。
- **任务曲面为静态、单场景**（ontology: per-scene）：时变曲面只作为未来工作提出；每个曲面实例都要重建查询结构 / 特征分解。
- **"最直测地线"在顶点唯一**：这是 Polthier–Schmies 的定义，依赖总角 θ 的数值计算精度；退化网格（极扁三角形）下顶点定位可能不稳。
- **GP 训练前已知或可采样出测试点集**（用于 Algorithm 3 定 κ_th）：否则要走蒙特卡洛，得 min κ_th，会牺牲表达能力。
- **控制器已吸收定位 / 形变误差**：真机靠混合力-阻抗控制器补偿（5 N 恒力），说明开环几何规划本身不保证接触稳定。

**面试 Tip（被问到"这跟 MeshDMP 到底差在哪"怎么答）**：
"MeshDMP 做对了两件事——承认要在网格上学、承认 forcing term 需要可迁移；但它有两个具体缺陷：一是它的 Exp 用局部法向投影近似，只在位移小、相邻面二面角小于 90° 时有效，顶点奇点根本没定义；二是它的 forcing term 编码在随点移动的局部坐标系里，曲面曲率让这个标架沿轨迹转动，长时执行就累积成绕中心的漂移。本文把 Exp 换成基于'最直测地线'的迭代推进——关键洞见是最短路径在顶点不唯一，而最直路径唯一——再把 forcing term 固定在目标切锥里、执行时平行移动回来，曲率被算子吃掉，漂移就没了。"

## 8 · GitHub-validated pitfalls (atlas 联动, 2026-10-08)

**Repo 信号核查**：arXiv 全文**未出现任何 github.com 链接**（开头的 "Report GitHub Issue" 是 arXiv HTML 界面的 UI 文本，非论文的代码仓库）。因此按铁律：**官方 repo 未在论文中给出**，以下 pitfall 由 §6 失败模式 + 方法约束推导，**未经 issue 验证**。

**Pitfall 1 — 测地核用了大 lengthscale → Cholesky 非正定崩溃（推导自 §6 失败模式 2 + 公式 (25)）**
- §6 明确：测地核"不能保证正定当 lengthscale 超过临界值 κ_th"，且 κ_th 与曲率 / 拓扑 / 采样点数的关系尚无理论刻画。
- 方法约束：核 (25) 的核矩阵由 d_g² 决定；论文自己的解法是跑 Algorithm 3（二分搜索）或蒙特卡洛取 min κ_th。**若不先跑这个 safeguard**，在粗网格 + 大 κ 下核矩阵出现负特征值，直接导致 (5)(6) 的 (K_PP+σ²I)⁻¹ 数值失败。
- 复现条件：任意网格，选 κ > κ_th（如 Dragon 上 κ>0.023）。**这不是"可能慢"，而是数学上会产生不一致后验。**

**Pitfall 2 — 面数超 10 000 后测地预计算时间 / 内存失控（推导自 §6 失败模式 1 + O(N² log N)）**
- §6 逐字："geodesic pre-computation … 复杂度 O(N² log N) … 当曲面超过 10 000 面时成为显著瓶颈"。
- 方法约束：Algorithm 3 要先算 m×m 距离矩阵 D；Table III 显示 setup 时间随点集与网格增长（Spot the Cow m=20 setup 472 ms → 随网格规模上升）。
- 复现条件：直接对 >10 000 面的扫描网格（如高分辨率重建）调用距离查询，会先卡在预计算；论文只做到 9 983 面（Dragon）就将其列为局限。

**Pitfall 3 — 逐帧在线生成 normal 方向 → 面间过渡跳变（推导自 §6 失败模式 4 + §VI 实现描述）**
- §6 / §VI-A 逐字机制："assign the orientation … normal to the surface … This choice leads to non-differentiable orientation trajectories when transitioning between faces"。
- 方法约束：法向 n 只在面内常量、跨边即跳变；论文的绕法**不是在线求解，而是预计算整条轨迹 + 对称滑窗滤波**。
- 复现条件：把 DMP (22)(23) 的输出方向实时喂给机械臂（不预计算 / 不滤波），在面间过渡处会得到不连续的方向指令；论文为此专门加了 1 s 滑窗（抛光）/ 预计算平滑（绘制）。

**Pitfall 4 — RFM 训练若不做时间上采样摊销 → 慢到不可用（推导自 §V-C 训练时间描述 + Algorithm 4）**
- §V-C 逐字：训练时"sample 每个 batch 都要构造 p_0→p_1 的测地线"；论文靠"cheap upsampling over time of the vector field u_t"摊销。
- 方法约束：Algorithm 4 每步都调用测地线构造（第 8 行），若不摊销，单步代价正比于测地查询成本。
- 复现条件：高 batch 或大网格下每步都重新算测地线，训练时间从论文的 20 h 膨胀回去——baseline 慢正是因为它每步做最近点投影。
