# 舰载机械臂基于优化任务空间逆动力学的阻抗控制 (Impedance Control of Ship-Borne Manipulators via Optimization-based Task-Space Inverse Dynamics)

> **发布时间**：2026-07-24（arXiv:2607.22030v1 [cs.RO]）
> **论文 / 模型名**：TSID-based Impedance Control for Ship-Borne Manipulators（无独立模型缩写；核心组件 = QP-TSID 控制器 + 30 维 ESKF）
> **核心定位**：把"基座在晃"从**外部扰动**改写成**动力学模型的一部分**——在任务空间加速度约束与前馈力矩里各补一次 `base` 项，剩下的残差才交给任务空间阻抗去吸收；顺带用一个把 IMU 当"量测"而非"预测输入"的 ESKF 实时吐出控制器需要的 `a_B / α_B`。
> **Ontology 5-axis**：sensor = `IMU`(+动捕位姿) / paradigm = `geometric` / time = `filter-streaming`

船载机械臂做接触任务（插接、抓取、给 USV 加油）时，浪涌让基座持续 6-DOF 摇摆，运动学补偿只能修几何、修不了惯性耦合，而纯力位混合/导纳又受制于内环速度伺服。本文的结论是：**在力矩级把 `τ_base` 显式前馈掉、并在 QP 里用硬约束保证可行，末端就能同时拿到 mm 级跟踪和"弹簧一样"的柔顺**——真机固定点平均位置误差 4.73 mm，动态插孔 15/15 全成、接触力比导纳控制器低 45.1%。

## X-Ray 开场

船在晃 → 机械臂末端跟着晃 → 想既"跟得准"又"碰得软"，可经典做法（IK / MPC 预测 / 视觉伺服 / 速度级扰动观测）都停在运动学或速度环，基座加速度带来的关节惯性力矩只能靠反馈硬扛。本文的做法很直接：把浮动基座动力学写成 `M q̈ + C q̇ + g + τ_base = τ + τ_ext + τ_d`，用**二次规划（QP）解任务空间逆动力学（TSID）**，在等式约束里塞进 `J q̈ = ẍ_c − η`（`η` 含基座速度/加速度项）、在代价里塞进阻抗型 PD、在不等式约束里塞进关节/力矩/加速度硬限，最后 `τ* = M q̈* + H` 直接输出力矩。

对 spatial AI 研究者意味着：**"估计 → 模型 → 约束优化 → 力矩"这条闭环链是可以被形式化证明的**（附录 A 给出 uniform ultimate boundedness），而且它把"感知不确定性"和"控制失配"放进同一个误差方程 `Λë + ΛK_d ė + ΛK_p e = −F_ext − δ_d − δ_c` 里做账——这是一个很好用的分析模板，哪怕你做的不是机械臂。

> 全篇没有神经网络、没有训练集；"数据"只出现在辨识与轨迹设计中。

### 1.2 关键机制

**⚡ Eureka Moment：把 `τ_base` 放进 `H` 里一起算，等于把"船在晃"从扰动变成了模型——补偿不再是"抑制"，而是"预知"。**

具体落地成两个耦合的位置：

1. **任务空间**（式 4、7）：`η = J̇q̇ + J_B V̇_B^B + J̇_B V_B^B`，基座的速度与加速度直接进等式约束，`J q̈ = ẍ_c − η` 里已经扣掉了"基座帮你/害你动了多少"。
2. **关节空间**（式 2、10、12）：`τ_base = M_B(q) V̇_B^B + C_B(q, q̇, V_B^B) V_B^B` 经 RNEA 算出后并入 `H = C q̇ + g + τ_base`，随 `τ* = M q̈* + H` 一次性前馈出去。

第二个关键设计（方法学上同样重要）：**ESKF 把 IMU 当量测而不是当预测输入**（式 43–44 的 `H_imu` 里 `∂a_meas/∂a_B = I`）。常规做法里加速度只能"积分出来"，这里因为 `a_B, α_B` 是显式状态且服从局部常加速度模型（`ȧ_B = 0, α̇_B = 0`），滤波器可以直接输出控制器需要的 `a_B / α_B`，无需二次微分。

第三个：任务空间阻抗不是"额外加一个阻抗环"，而是**QP 无约束解 + PD 律的副产品**。式 27 证明：只要不等式约束不激活、`δ_d` 小，末端就严格服从 `Λë + ΛK_d ė + ΛK_p e = −F_ext`——**跟踪精度与柔顺性在同一个目标函数里，不需要切换模式**。

## 2 · 数学核心

📌 **Napkin Formula**

$$\Lambda(\boldsymbol q)\big(\ddot{\boldsymbol x}-\ddot{\boldsymbol x}_c\big)=\boldsymbol F_{\text{ext}}+\boldsymbol\delta_d+\boldsymbol\delta_c \;\;\Longrightarrow\;\; \Lambda\ddot{\boldsymbol e}+\Lambda\boldsymbol K_d\dot{\boldsymbol e}+\Lambda\boldsymbol K_p\boldsymbol e=-\boldsymbol F_{\text{ext}}-\boldsymbol\delta_d-\boldsymbol\delta_c$$

**一句话直觉**：末端对外永远是一个质量-弹簧-阻尼，弹簧那头挂着三种力——你想握的手（`F_ext`）、你没算准的模型（`δ_d`）、你被限幅逼出来的修正（`δ_c`）。前两个小、第三个为零时，柔顺性就是"设计值"。

**目标 → 公式 → 变量 → 直觉**

1. **目标**：在基座 6-DOF 摇摆下，让 `x → x_d`（高精度）同时让末端对外呈现指定的 `Λ, K_p, K_d`（可接触）。
2. **浮动基座动力学**（式 1–2）
 `M(q)q̈ + C(q,q̇)q̇ + g(q, R_B^W) + τ_base = τ + τ_ext + τ_d`，
 `τ_base = M_B(q)V̇_B^B + C_B(q,q̇,V_B^B)V_B^B`。
 - `V_B^B, V̇_B^B ∈ R^6`：基座在 `{B}` 下的空间速度/加速度；`M_B ∈ R^{n×6}, C_B ∈ R^{n×6}` 是基座-关节动力耦合；`τ_base` 用 RNEA 高效算。
 - 直觉：固定基座时 `V_B^B = V̇_B^B = 0` → `τ_base` 消失，退回教科书模型。
3. **微分运动学**（式 3–4）
 `ẋ = J q̇ + J_B V_B^B` → `ẍ = J q̈ + η`，`η = J̇q̇ + J_B V̇_B^B + J̇_B V_B^B`。
 - `η` 就是"基座替你产生的任务空间漂移加速度"，必须在约束里扣掉。
4. **参考加速度**（式 5–6）
 `e = log(x⁻¹ x_d) ∈ se(3)`，`ẍ_c = ẍ_d + K_p e + K_d ė`。用 SE(3) 上的对数映射而不是欧氏差，保证大角度旋转时误差不退化。
5. **QP**（式 10）
 `min_{q̈} ½‖J q̈ − ẍ_c + η‖² + (λ/2)‖N(q̈ − q̈_ns)‖²`
 `s.t. τ_min ≤ M q̈ + H ≤ τ_max`，`q̈_min(q,q̇) ≤ q̈ ≤ q̈_max(q,q̇)`，
 其中 `H = Cq̇ + g + τ_base`，`N = I − J†J`（式 11），`λ = 0.001`。
 加速度边界由状态预测给出（式 9）：`q̈_max = min((q̇_max − q̇)/Δt, 2(q_max − q − q̇Δt)/Δt²)`。
6. **无约束解与约束修正**（式 17、19）
 `q̈₀ = J†(ẍ_c − η) + N q̈_ns`；约束激活时 `q̈* = q̈₀ + Δq̈_c`，`Δq̈_c = −Q⁻¹A_Iᵀ μ_I`（`Q = JᵀJ + λNᵀN`）。
 注意：**`λ` 不影响无约束解**，只通过 `Q` 影响约束激活时的修正方向——这就是 §5.6 里"`λ` 只在约束激活时才有影响"的数学根源。
7. **闭式误差动力学**（式 21→27）
 `M(q̈ − q̈*) = JᵀF_ext + τ_d` → 乘 `J`、用 `JN = 0`、`JJ† = I`（**远离奇异**）→
 `Λ(ẍ − ẍ_c) = F_ext + δ_d + δ_c`，
 `δ_d = Λ J M⁻¹ τ_d`（模型误差等效任务空间力），`δ_c = Λ J Δq̈_c`（约束激活等效任务空间力），`Λ = (J M⁻¹ Jᵀ)⁻¹`。
8. **稳定性**（附录 A）：`w = −Λ⁻¹F_ext − J M⁻¹τ_d − J Δq̈_c`，若 `‖w‖ ≤ w̄` 且 QP 可行、远离奇异，则 `e, ė` uniformly ultimately bounded。
 **关键限定（作者自己强调）**：这保证的是"有界"，不是"小"；`δ_c` 大时上界可能大到没有工程意义。

## 3 · 带数字走一遍（玩具设定，数字为演示自造）

**设定**：单自由度移动关节（`n = 1`），`J = 1`，连杆+末端等效质量 `M = 2 kg`，于是 `Λ = (JM⁻¹Jᵀ)⁻¹ = 2 kg`。基座沿该轴加速度 `a_B = 0.3 m/s²`，故 `τ_base = M_B a_B = 2 × 0.3 = 0.6 N`（取 `M_B = M`）。增益取论文真值 `K_p = 500`、`K_d = 40`。

**第 1 步：算指令加速度。** 目标静止（`ẍ_d = 0`），当前落后 `e = 5 mm`，`ė = 0`，`η = 0.3 m/s²`：
`ẍ_c = 0 + 500 × 0.005 + 0 = 2.5 m/s²`

**第 2 步：扣掉基座贡献。** 式 7：`q̈ = ẍ_c − η = 2.5 − 0.3 = 2.2 m/s²`。
（如果不扣 `η`，就会多命令 `0.3 m/s²`，基座一加速末端就过冲。）

**第 3 步：输出力矩。** `τ* = M q̈ + H = 2 × 2.2 + 0.6 = 5.0 N`。
其中 `0.6 N` 是纯前馈——**它不需要任何反馈就能被"预知"**。

**第 4 步：假设漏掉 `τ_base`。** 那就输出 `τ = 4.4 N`，实际系统里 `0.6 N` 变成未补偿扰动 `τ_d`：
`δ_d = Λ J M⁻¹ τ_d = 2 × 1 × (1/2) × 0.6 = 0.6 N`
稳态：`Λ K_p e_ss = −δ_d` → `e_ss = 0.6 / (2 × 500) = 0.6 mm`。
→ **一个 1 行代码的漏项，换来 mm 级稳态误差**；这与论文 §IV-B2 里"未建模载荷主要造成稳态误差而非振荡"的结论同构（论文真值：固定基座、无补偿时末端质量 0.73 kg，载荷加到 2.5 kg 误差单调上升）。

**第 5 步：看柔顺性的代价。** 阻抗刚度 `Λ K_p = 2 × 500 = 1000 N/m`，即 **1 N 让末端退 1 mm**。接触力 10 N → 静态偏移 10 mm。
→ 这解释了论文为什么插孔时 `F_xy` 只能压在几牛量级（scale 1.0 下均值 3.619 N）——**柔顺是靠"允许退让"买来的**，不是靠"更硬的力控"。

**第 6 步：看动态品质。** `ω_n = √500 ≈ 22.4 rad/s ≈ 3.6 Hz`，`ζ = K_d/(2√K_p) = 40/(2 × 22.36) ≈ 0.894`。
→ 接近临界阻尼、带宽 3.6 Hz。而基座运动主频若接近这个量级，`δ_d` 就会被放大——这正是论文在真机上"小幅基座运动时相对优势变小、且旋转误差不占优"的动力学解释方向（论文自身归因于摩擦/参数不确定/振幅缩小）。

| 软件栈 | Pinocchio（动力学）+ TSID 库（QP） | 无学习框架 |

**Trade-off 读法**

1. **算力不是瓶颈，约束才是。** 单周期 0.0212 ms（i7-13620H 均值）对比 1 ms 预算，余量约 47×；真正的风险是 0.89%（8901/10⁶，换算值）的不可行样本——一旦 QP 不可行，控制律就无解，必须靠外部兜底（论文未描述兜底策略，属部署空白）。
2. **感知频率远低于控制频率。** 1 kHz 控制 vs 100 Hz IMU vs 120 Hz 位姿 → 每个控制周期里 `a_B, α_B` 有约 10 个周期是"外推"的，靠 `ȧ_B = 0, α̇_B = 0` 的局部常加速度假设 + 过程噪声兜着。**这是精度上限的一个直接来源**（论文未量化该外推误差）。
3. **QP 维度极低（`n = 7`，约束 4n 行）。** 换成 `n = 20+` 的冗余臂或用全身控制时，`M, H` 的计算与 QP 规模会同步上升，0.02 ms 的结论**不可外推**。

> 上表所有数字均为论文报告值，**未在本地复现**，可视为 `UNVERIFIED`（除"8901/10⁶ ≈ 0.89%"为本文换算）。

## 5 · 数据与评测

> 本文无训练集、无 benchmark 数据集。评测 = 仿真 3 条轨迹 + 真机 3 条轨迹 + 状态估计消融 + 动态插孔，共 4 组实验。

### 5.1 仿真设置与任务条件

- 平台：Gazebo + ROS Noetic，7-DOF 模型与控制器接口基于 `franka_gazebo`；在机器人与世界之间插入**可控 6-DOF 虚拟关节**模拟船体运动；IMU 由 `imu_sensor` 插件生成；真值位姿直接取自 Gazebo 物理引擎。动力学参数用 [29] 辨识的 URDF。
- 基座运动条件（关键）：**直接取自浅水条件下受波浪扰动的实测 AUV 运动**，峰值线速度达 **0.32 m/s**、角速度达 **24 deg/s**。
- 任务：① 固定点稳定（10 s）；② 圆周（`r = 0.15 m`，30 s）；③ 8 字（`x = 0.15 sin(t)`，`y = 0.225 sin(t)cos(t)`，30 s）。

### 5.2 基线（⚠ 层级必须分清）

| 基线 | 原文定性 | 补偿所在层级 | 机制 |
|---|---|---|---|
| PI | "standard kinematic feedback controller" | 运动学 | `q̇_c = J†R_W^B[ẋ_d + K_p e + K_i∫e dt]` |
| Woolfrey et al. [10] | 用 AR 模型预测基座位姿 + MPC | 运动学 | 把全局参考投影成动态局部目标，MPC 算基座系速度 `u` |
| Xu et al. [15] | 估计**关节速度扰动** `q̇̂_dist` 并在速度指令上补偿 | **速度级动力学补偿** | `q̇_c = J†u₀* + q̇̂_dist`（扰动估计与补偿都在速度环，依赖底层速度伺服） |
| PI+EVOLVER [13] | **"enhanced kinematic controller"**；EVOLVER 是 Koopman 算子观测器 | **运动学（+速度级扰动观测）** | 用历史末端位姿估计基座**扰动线速度** `v̂_dist`，在笛卡尔速度指令里减掉 `Δ = [v̂_dist, 0]ᵀ` |

> **术语澄清（易错点）**：`[13]` **不是**速度级动力学补偿——它估的是基座扰动的**线速度**（Koopman 观测器），本质仍是运动学/速度指令修正；真正"动力学意义上"的速度级补偿是 `[15]`（估关节速度扰动 `q̇̂_dist`）。而 `[16]`（滑模）与 `[17]`（观测器）才是把基座惯性力当外扰在动力学里补偿。

- 基线参数在真机上按原论文设置整定，调参细节在补充材料（本稿未见）。
- 本文增益（表 I）：`K_p = diag(500,…,500)`（6 项）、`K_d = diag(40,…,40)`（6 项）、`K_p,ns = diag(50×7)`、`K_d,ns = diag(20×7)`、`λ = 0.001`。

**读法（含易错修正）**：

- 若真能直接测基座位姿，位置 RMSE 可到 **0.2307 mm**；本文方案在**无直接基座位姿**条件下是 **6.013 mm**。两者比值 **6.013 / 0.2307 ≈ 26 倍**（换算值，约 **1.4 个数量级**）——**不是两个数量级**。物理含义：精度损失约一个半数量级，换来"不装基站/不依赖船载位姿传感器"的可部署性。
- 去掉 FK 伪量测最伤位姿（6.013 → **10.52 mm**），说明该伪量测提供绝对位姿约束、抑制长期漂移；去掉 IMU 最伤速度/加速度（角速度 0.03485 → **0.09643 rad/s**，线加速度 0.2035 → **0.3227 m/s²**），因为陀螺直接测角速度。
- 角速度对角速度量测消融不敏感——同因（陀螺）。
- 参考真值获取：动捕平台标记帧到机器人基座之间的常值刚体变换离线标定一次后全程固定；速度/加速度参考由位姿微分 + 滤波得到。**"参考本身是微分+滤波"这一条件必须计入，因为线加速度 0.2035 m/s² 的 RMSE 里含参考噪声。**

### 5.6 约束激活 / 载荷不确定性 / 插孔

- **约束激活扫描**：归一化关节速度 0→1、基座运动缩放 0→7；缩放因子 1 时指令速度 `[0.05,0.05,0.05]ᵀ m/s`、`[0.1,0.1,0.1]ᵀ rad/s`，加速度 `[0.2,0.2,0.2]ᵀ m/s²`、`[0.3,0.3,0.3]ᵀ rad/s²`。等值线取 `‖δ_c,f‖ = 100 N`（约等于 Panda 的力上限）。结论：归一化速度/基座缩放空间里**大范围内约束不激活**（`δ_c,f = 0`），激活后随基座缩放单调增大。
- **运动强度 vs 跟踪误差**：基座频率递增时误差上升；运动缩放 **1.0 与 1.2 时无约束激活**，更高缩放时激活比例快速上升，且最大误差增长更陡。
- **`λ` 敏感性（关键定量）**：缩放 **2.4** 时把 `λ` 从 **0.001** 增到 **10**，最大跟踪误差从 **32.37 mm** 升到 **92.08 mm**——印证 §2 第 6 步：`λ` 只在约束激活时起作用，越保姿态越牺牲主任务。
- **载荷不确定性**：末端附加未建模载荷 **0 → 2.5 kg**，控制器仍用标称模型，标称末端质量 **0.73 kg**；误差随载荷上升，但分布集中 → **主要是稳态误差而非振荡**（`δ_d` 慢变）。讨论节补充：实测中带 **0.3 kg** 未建模载荷（六维力传感器引入）仍能完成插孔。
- **动态插孔**：销 `Ø35 mm`、孔 `Ø37 mm`、深 `45 mm`，径向间隙仅 **1 mm**，孔口 **10 mm** 倒角；腕部六维力传感器。基座运动缩放 &#123;0, 0.4, 0.6, 0.8, 1.0&#125;；0/0.4/0.6/0.8 各 5 次试验；**PI+EVOLVER 在 scale 0.8 全部失败**（销卡死、接触力触发保护停机）故未测 scale 1.0；scale 1.0 时本文与导纳各 **15 次**试验。成功判据 = 达到规定插入深度且不卡死。

## 6 · 能力与失败模式

### 能做（有数字支撑）

1. **基座大幅摇摆下的高精度跟踪**：仿真固定点位置均值 **3.30 mm**（最大 **6.54 mm**），真机 **4.73 mm**（最大 **12.27 mm**）；圆周/8 字真机均值 **4.70 / 5.43 mm**。
2. **力矩级柔顺 + 精度同框，不需模式切换**：误差动力学式 27 表明只要 `δ_d, δ_c` 小，末端就是设计好的质量-弹簧-阻尼。
3. **接触任务可靠性**：1 mm 径向间隙、6-DOF 基座运动下 **15/15 成功**（导纳 12/15），`F_xy` 均值降 **45.1%**、最大降 **49.5%**。
4. **约束可行性有保证**：关节位置/速度/力矩全进 QP 硬约束，加速度边界由式 9 的状态预测映射。
5. **无直接基座位姿测量也能重建基座全状态**（IMU ⊗ 末端位姿），并能直接给出 `a_B, α_B` 供前馈。

### 不能做 / 会失效

1. **约束激活 → 阻抗失真（最本质的失效）**。`δ_c ≠ 0` 时误差动力学被污染；`λ` 从 0.001 到 10 使最大误差从 **32.37 mm** 涨到 **92.08 mm**（scale 2.4）。作者明确写"current formulation is mainly applicable when the inequality constraints are inactive or only mildly active"。
2. **模型不确定性 → 稳态误差**。载荷 0→2.5 kg 单调恶化；作者称大载荷需在线辨识/自适应。
3. **姿态跟踪不占优**。真机固定点旋转均值 2.02 deg，劣于 [10] 的 0.91 deg；作者归因于摩擦与参数不确定导致的稳态姿态偏差。
4. **QP 不可行**：10⁶ 随机样本中 **8901** 例不可行（力矩越限）；论文未给不可行时的降级策略。
5. **感知未闭环**：末端位姿来自**动捕**，非机载视觉；"视觉噪声与延迟未考虑"，作者列为未来工作。
6. **无法反映机械臂对船的反作用**：Stewart 平台只复现预定义基座运动；作者承认重载机械臂会影响小船姿态。
7. **奇异位形**：式 24 的化简依赖 `J J† = I`，推导明确要求"away from kinematic singularities"。

### 隐含假设 (Hidden Assumptions)

| # | 假设 | 若被违反会怎样 |
|---|---|---|
| A1 | 基座与末端位姿可在**惯性系**下获得，且精度足够（本文用动捕，最好情况位置 RMSE 0.2307 mm） | `η` 与 `τ_base` 的前馈直接吃误差；`δ_d` 变大 → 稳态误差 + 阻抗偏离设计值 |
| A2 | 机器人动力学参数已辨识（URDF 来自 [29]），载荷已知 | 载荷 0→2.5 kg 误差单调上升；仅 0.3 kg 以内被实测验证 |
| A3 | 关节远离运动学奇异 | `JJ† ≠ I` → 零空间投影与式 24 的化简失效，任务空间二阶项污染 |
| A4 | 每个控制周期 QP 可行 | 8901/10⁶ 样本不可行；无解即无控制律 |
